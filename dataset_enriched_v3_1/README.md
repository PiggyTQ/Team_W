# 国内重点职业扩充版基础数据集

版本：3.1.0-domestic-enriched-base；整理截止：2026-10-12。以原来的基础快照为底，实际补充国内 AI、数据、安全、运维岗位。准确入库数量、公司数量和检查结果见 `audit/quality_report.json`，职业覆盖见 `data/occupation_catalog.json`。

本版主样本 3,515 条，国内 2,859 条，占 81.34%；新增 233 条来自 163 家公司。新增 AI 52 条、数据工程 43 条、数据分析 34 条、安全 53 条、运维 50 条、网络通信 1 条。共 228 个能力词条、20,574 条技能提及证据、172 份分组画像。新增记录均具有完整的平台发布时间；范围为 2026-07-31 至 2026-10-12（UTC），不代表企业原始发布日。13 项工程检查通过，人工标注准确率仍未评估。此版替代 dataset_final 作为后续开发入口，旧版留作比较。

## 使用入口

直接读取 `data/website_base.sqlite`，或导入 UTF-8 的 CSV/JSON。优先使用主表 `data/jobs_base_80cn.csv`，它的国内记录占比不低于 80%。`jobs_cn.csv` 和 `jobs_cn_new_specialties.csv` 都是主表的子集，不能重复追加。完整国际参考库另存 `jobs_international_reference.csv`，部分记录已经在主表中，联合使用须按 job_id 去重。

|网站功能|数据文件或数据库表|边界|
|---|---|---|
|职业探索|occupation_catalog|职业目录和学习建议，不是就业保证|
|岗位证据检索|jobs|原始供给与新采集记录分别保留来源；当前有效状态需看 posting_status|
|技能匹配解释|job_competencies|原文提及和证据位置，不自动推断为硬性要求|
|国内职业画像|occupation_profiles 中 market=CN|历史与新采集便利样本；未通过双人标注评估|
|细分方向探索|occupation_track_profiles|区分大模型应用、视觉、SRE、DevOps 等；细分样本仍可能较少|
|学习计划|action_templates、learning_resources|项目编写的可修改建议，链接不保证持续有效|
|职业标准知识|official_knowledge_sources、official_knowledge_facts|事实摘要与链接，不能计入招聘样本数量|
|学生能力确认|student_profile_schema.json|仅有结构，没有真实学生数据|

## 新采集方法与来源

从国家大学生就业服务平台公开搜索页及详情页进行一次有限、低频读取。不登录、不绕过验证码或权限、不安装周期任务。公开搜索页使用的查询参数和详情页字段用于采集；查询词、页数、失败及剔除记录在 audit 中。平台 robots 地址返回 HTML 的 404 页面，未取得有效 robots 指令；这不等于获得转载许可。

先按具体职位标题筛选，再检查描述中是否存在可支持该技术方向的职责或技能。去除明显销售、售前售后、教师培训、数据标注和非 IT 设备运维标题；不足 80 字、缺少公司或标题、不具备技术描述的记录不入库。新旧页面均解析，嵌入的职责/任职资格 JSON 分开转成文本，福利字段不混入资格要求。

同一公司、标题和描述完全相同的跨校园重复发布合并，不把招聘人数当作岗位条数。相似但不完全一致、企业不同法律实体或多个城市的职位仍可能相关，因此不能将全部记录看作独立市场观测。

本次接受 237 条可读候选，最终剔除 2 条海外地点、2 条不符合目标职业职责的记录，入库 233 条。语义审阅修正了部分“AI 数据工程师”和通信算法的归属，理由单独保存在 audit。审阅由助手完成，不能算作人工金标准。计量与数据分析交叉岗位保留了审核提示。

国家大学生就业服务平台是发布平台，并非每条记录的原始供稿方。每条新增记录同时保留 origin_name、origin_category 以及公开详情链接，区分平台直接供给、高校/教育机构转载和第三方转载。页面中的 company_name 是发布方声明，未联系企业独立核验。

233 条中，高校/教育机构转载 189 条，第三方转载 43 条，平台直接供给 1 条。因此它们不能全部表述为官方独立验证的招聘信息。采集时均能读取详情且未发现下线标注，状态记为 visible_unverified；没有把它们改为 employer_verified 或 active。

## 日期、状态与薪资

- published_at 来自公开岗位列表的发布时间戳，platform_updated_at 来自其更新时间戳。保存 UTC 时间和明确的 date_basis；不能据此认定为企业最早发布日。
- last_verified_at 是本次成功读取详情的时间；不能解释为企业确认仍招人的时间。
- closed 表示页面明确标注下线；visible_unverified 表示页面可见且未发现下线标注，企业招聘有效性未确认。旧记录仍为 historical_unverified。
- 新记录薪资按平台列表声明的 K/月转为 CNY/月，不据此折算日薪、年薪或预测学生收入。平台字段和正文可能冲突，使用前应对目标岗位复核；面议保存空数值。
- 旧国内记录缺失年份，保持 published_at 为空；不会用本次整理日期补猜年份。

## 质量和可用于什么

岗位、公司、来源、日期和描述是真实公开页面的采集字段；职业归类与技能抽取属于规则处理，仍会出现语义误差。description 是规范化和联系信息脱敏后的描述。技能 evidence_start/evidence_end 针对这个字段，以 Python Unicode 字符位置计数、结束位置不包含；JavaScript 使用 UTF-16 时须转换，不能直接当字符串索引。

所有非否定抽取均标记为 mentioned，置信度为空，等级未指定。出现一个技能名称，不说明该岗位硬性要求所有候选人掌握该技能；专业清单、福利、工具示例和“至少一种”尤其需要语义核验。否定规则同样需要审核。词典覆盖不完整，提及数不能解释为真实能力水平。

新增样本让 AI、数据、安全和运维具备可追溯的国内岗位证据，可以开始构建探索、解释和匹配原型。至少 30 条只是本项目用于区别“小样本”的工程标记，不是可靠性或统计代表性的证明。数据工程与数据分析分别统计；实习、校招和有经验要求的岗位分组，不把资深要求直接套给学生。

`evaluation/new_specialties_review_sample.csv` 和原 300 条审核样本尚未人工标注。没有实测准确率，也没有证明全国需求、就业概率、薪资趋势或实际晋升路线。职业转移文件仅为技能重叠候选。

## 使用权限

新增记录是公开可访问的真实招聘信息，但尚未逐源核验全文转载、商业展示或模型训练的许可。旧赛题 CSV 也没有提供相应授权说明。因此主库用于团队本地研究、开发和审核；正式展示视图依旧保守关闭。公开来源、robots 状态和网站复用许可分别记录，不互相替代。

正式网站可先展示自主编写的职业介绍和学习计划。开放数据可以按照适用的开放条款使用，不一定需要另签合作协议；具体来源如要求注册、署名、备案等，应按其要求实施。将来可为数据库加入允许长期开放许可的审核规则，不能统一把“书面合作授权”作为唯一途径。
