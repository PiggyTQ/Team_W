# 提出恢复方案并核对合成观察

- 任务编号：restore-task-01
- 输入：input/incident.md、input/timeline.csv、input/monitoring.csv及字段说明；也可用等价JSONL。
- 操作范围：离线桌面推演，不在生产服务器执行命令。

1. 列出已知影响、近期变化和缺失信息。
2. 提出至少两种行动选择，例如停止继续发布、核对版本和兼容性后考虑回到已知版本、继续保留现场观察；写明前提与停止条件。
3. 写出恢复步骤和回退条件，区分准备执行、假定执行、已在给定合成记录出现。
4. 按本题阈值计算业务错误率并检查两个连续完整窗口；不能只看/health返回200。
5. 记录观察范围和复盘改进，不据时间先后直接认定根因。

提交 recovery_plan.md、verification.md、postmortem.md。验证文档引用I编号与窗口时间，注明阈值来自本练习。备份或依赖状态没有提供时列待核对，不承诺“无损恢复”。
