# 从离线日志整理异常时间线

- 任务编号：log-task-01
- 输入：input/app_logs.jsonl 或等价app.log，二者任选，避免双重计数。
- 范围：2026-10-01，09:00起约十分钟的合成demo-api日志；不连接真实主机。

1. 确认事件数、请求数、时区和可用字段。
2. 按时间和request_id关联开始/结果，找出ERROR与WARN。
3. 给出异常起止、对应事件ID和相关请求，不只粘贴截图。
4. 对超时至少列两种替代解释：依赖处理变慢、网络延迟、客户端超时设置等均可作为待验证假设。
5. 写清区分这些解释还需要哪些记录。

提交 timeline.csv或timeline.md、hypotheses.md、limitations.md。工具可选文本搜索、表格、Python或SQL；本人完成与工具辅助要分别说明。没有给出根因证据，不能写“已定位攻击/入侵/服务器故障”。
