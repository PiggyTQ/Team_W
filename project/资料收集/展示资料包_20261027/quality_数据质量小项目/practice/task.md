# 用可追溯步骤整理一份企鹅样本表

- 任务编号：quality-task-01
- 输入：input/penguins_exercise.csv 或同内容JSONL；data_dictionary.md。
- 原始公开数据：input/penguins_source.csv；原始字节保留，CC0数据，来源 SRC-001/002。
- 问题：各物种在本练习文件中有多少条记录，体重字段可用多少条，如何解释处理后的均值？

## 要做的事情
1. 先保存输入副本，记录行数、字段和缺失标记。
2. 按字段说明寻找重复、格式差异、未知类别和无效体重，并引用record_id。
3. 逐项写处理决定；不能把NA当作零，也不能猜岛屿或性别。
4. 生成各物种记录数、有效体重数、均值与排除数。
5. 写个人贡献、工具辅助与结论限制。

## 提交
- issues.csv 或 issues.jsonl：行号、字段、问题、处理和依据。
- summary.csv 或 summary.json：物种、总记录数、有效体重分母、均值及单位。
- method.md：方法、不同合理选择、本人贡献、未知项。

表格工具、SQL或Python任选；采用不同重复规则时须解释并重新报分母。建议首次展示按本包固定口径核对，不把结果扩大成所有企鹅的生物学结论。
