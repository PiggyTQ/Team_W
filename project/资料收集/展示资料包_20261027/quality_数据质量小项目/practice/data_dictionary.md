# 字段与统计口径

原始字段来自 SRC-002，原始文件有344行、8列。`NA`表示未提供，不是零。练习文件新增 `record_id` 作为行引用，并注入2条重复记录、1条负体重、1个未知岛屿名称和1个物种格式差异；注入清单在教师参考目录，修改值不是真实观测。

|字段|含义|处理约定|
|---|---|---|
|record_id|本练习唯一行号|用于证据定位，不加入业务重复键|
|species|物种标签|本练习归一到 Adelie、Chinstrap、Gentoo；只处理明确的大小写/空格差异|
|island|采集岛屿标签|未知标签保留，不能从物种推定岛屿|
|bill_length_mm|喙长度，毫米|NA保留，不能用0替换|
|bill_depth_mm|喙深度，毫米|同上|
|flipper_length_mm|鳍肢长度，毫米|同上|
|body_mass_g|体重，克|计算均值时只用已提供且大于0的值|
|sex|样本性别标签|NA不根据体型或物种推断|
|year|资料内的采样年|仅描述文件中的年份，不改成本次下载年|

重复定义：八个原始字段完全相同的练习记录。这个定义仅用于本文件的教学处理，不代表真实科研中相同测量必然是重复个体。均值分母为各物种有效体重记录数，记录总数与有效数同时展示。
