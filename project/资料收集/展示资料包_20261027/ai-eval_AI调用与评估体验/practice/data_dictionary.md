# 离线案例字段

case_id是案例引用编号；instruction是用户要求；context是本题唯一可用的事实资料；candidate_answer是项目编写的候选回答；generation_method明确未调用模型；criteria_ids对应本课F01—F04。源文件不含参考判定，判定放在reference目录。

F01：事实是否与给定资料一致；F02：是否新增或断言无依据事实/操作；F03：是否遵守语言、资料范围和确认条件；F04：不确定时是否保留未知。逐条可标满足、待补充、无法判断、不适用。

task_verdict只概括任务结果：例如实际是否仍在招聘未知，但“肯定仍在招”的措辞越界仍可明确指出。不要把这两个判断混成一个分数。
