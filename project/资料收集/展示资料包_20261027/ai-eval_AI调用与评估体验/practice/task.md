# 对12条预录回答逐项记录依据

- 任务编号：ai-eval-task-01
- 输入：input/eval_cases.jsonl；案例全部由项目编写，未调用模型。
- 环境：任意文本编辑器，或以JSON查看器打开；不需要API密钥。

1. 每条先看instruction，再划出context中真正提供的事实。
2. 对F01—F04逐项记录满足、待补充、无法判断或不适用，并引用原文片段。
3. 将“现实情况未知”与“回答无依据地肯定”分开标注。
4. 选择两条错误回答，改写成保留资料范围的版本。
5. 记录规则能检查什么、不能代表什么。

提交 judgments.jsonl 或 judgment_table.md：案例ID、逐项结果、证据片段、理由；另交 revisions.md 两条修改及依据。没有运行模型，不填写延迟、token用量或真实模型准确率。
