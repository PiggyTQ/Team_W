# 首页阻尼与慢速切换 v25

2026-10-19。根据用户“阻尼不够大，同页面切换不要那么快”的试用反馈，调整现有动效参数，页面结构与内容沿用。

| 项目 | v24 | v25 |
| --- | --- | --- |
| 弹簧阻尼 c | 20 | 30，提高50% |
| 阻尼比 ζ | 1，临界阻尼 | 1.5，过阻尼，跟随与回位更沉稳 |
| 出口初始位移增益 | 0.55 | 0.35，相同输入下推进更少 |
| 持续拉开阈值 | 280px | 400px |
| 新内容滑入 | 240ms | 520ms |
| 旧内容退出 | 100ms | 220ms |
| 交接延迟 | 60ms | 120ms |
| 完整同页切换 | 300ms | 640ms |
| 新段落进入 | 420ms | 650ms |

质量m=1、刚度k=100保持。仍按`m·x''+c·x'+k(x−target)=0`计算，使用过阻尼减慢跟随；出口橡皮筋函数更新为`R(d)=56×0.35d/(56+0.35d)`。快速切换继续可以中断，持续输入可以离开模块，没有增加等待锁。减少动态效果与手机原生惯性保持。

此轮只调整动效参数，按项目约定保存受影响区域实际截图，不另做页面结构设计图。
