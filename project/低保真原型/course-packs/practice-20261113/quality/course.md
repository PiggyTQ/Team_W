# 数据质量小项目

交通分析组准备发布一份碰撞记录简报。你负责判断这张表能否支持按限速分组的描述统计，并提交一份同事能复算的质量记录。

质量问题清单、处理口径、分组统计和发布建议

练习源自英国交通部 STATS19 的 16 条公开记录，练习表加入教学改动。样本只含向警方报告的道路伤害碰撞，无法据此比较道路风险。
