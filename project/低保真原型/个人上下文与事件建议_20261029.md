# 事件驱动的个人上下文与站内建议

本轮后端已于 2026-10-29 按用户授权部署，运行资料在 `/srv/career-growth/personal-context-20261029-03/`。新增三张表并重启一次账户服务，没有切换前端，没有替换账户库或费用账本。DeepSeek 继续关闭，本轮没有付费模型调用。新增接口尚未连接前端建议卡或通知入口，因此现有网页不会自动展示这些新建议。

## 已实现

所有已保存的工作区变更和 13 类业务命令，共用工作区仓储的事务钩子。关键状态变化时，在同一事务内更新上下文并记录事件；失败回滚业务记录与上下文，重复命令不重复记事件。已有账户在首次读取或后续保存时初始化，不批量读取其他账户。

触发范围：主目标、时间预算、确认材料的状态/版本/技能/内容摘要、确认教育资料、任务状态/版本/依赖/提交与检查结果、复盘版本，以及显式保存的偏好版本。草稿输入、聊天文本、阅读位置和浏览操作不参与上下文基线。没有时间轮询触发模型，也没有后台模型队列。

上下文仅保存当前结构化状态、对象引用和必要的内容摘要散列，不复制材料正文、聊天历史、私人反思或偏好正文；原始资料仍保留在既有业务对象里。事件记录变化类型和版本，不存旧材料正文，最多保留 30 天及最近 1000 条、接口查询最近 100 条。事件与建议反馈纳入既有账户数据导出；清空工作区同步删除三类记录，删除账户按外键级联。

## 个性化建议

根据当前状态生成可解释的站内建议：待确认材料回到逐项核对、未选目标先比较职业、缺少材料保留未知、预算占满先核对安排、依赖未完成先处理依赖、受阻任务记录困难、完成成果核对材料、完成后补一次复盘，以及在目标和材料已有但无活动任务时预览小范围行动。

每条建议有稳定规则编号、理由、对象 ID/版本与现有页面入口；不生成适合度评分、录用概率、技能掌握结论或虚构的经历。建议不会自动创建任务、改目标、确认材料或发送消息。最多返回 30 条。

建议基线绑定账户内的上下文代次、修订、规则版本及当前获准知识摘要。用户可以标记已读、忽略或不相关。旧基线反馈返回冲突，不能作用于新建议；资料变化、知识变化以及清空后重新建立都不会复活旧建议状态。读取与规则计算不调用 DeepSeek。

## API

沿用现有会话、账户绑定和同源/CSRF 校验，不接受客户端 owner。

| 接口 | 内容 |
| --- | --- |
| GET /api/agent/personal-context | 当前上下文、版本、建议基线和建议列表 |
| GET /api/agent/suggestions | 同上，方便建议入口读取 |
| GET /api/agent/context-events | 本账户最近 100 条变化事件，无正文 |
| POST /api/agent/suggestions/feedback | `{adviceKey,suggestionId,status}`，状态为 read / dismissed / not_relevant |

新增三张表：personal_context_heads、personal_context_events、personal_suggestion_feedback。复用现有 SQLite 完整备份，不替换用户库或费用账本。

## 模型的上下文范围

模型请求增加 `contextSignals`，仅由本次明确授权并实际装入请求的材料片段和计划摘要计算：所选材料数量与技能、授权计划的目标、时间余额和任务数量。它不读取完整个人上下文库，也不外发未选择材料或私有偏好。Prompt 版本更新为 career-readonly-v5，以便后续评估区分版本。

模型仍须由用户主动触发，并满足开关、名单、外发同意及预算校验。本轮没有实现自动付费生成或付费答案缓存，也没有开放跨会话完整记忆。规则建议随事件更新，与模型生成分开。
