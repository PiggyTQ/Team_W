## 后续维护，避免再次漏翻

- `npm run i18n:check`自动检查当前组件、属性、数据和动态模板片段的完整词条；生产构建自动执行此检查。
- 新增站点文案或更新公开内容时，先提取去重，补译新增部分，复用现有构建缓存，再生成版本。人工修正写入`src/i18n/reviewed-en.json`，优先于机器译文。
- 当前提取、公开内容构建及稳定编号维护分别由`scripts/prepare-bilingual.mjs`、`scripts/compile-public-translations.py`、`scripts/finalize-bilingual.mjs`负责。构建脚本只读取承诺的站点代码、公开知识库和公开课程表；不得扩展到个人工作区。
