# U01 滚轮递进路径 v4

2026-10-17。替代v3的静态四节点加短连线方案，只修改首页“从了解一份工作到做出自己的成果”。三张入口卡牌、成果舞台和十方向展廊保留。沿用四个首页聚合阶段，不新增正式页面、能力结论或业务状态。

## 新格局

桌面使用一个稳定舞台，视线随滚动沿路径向右移动。起点先突出第一节点，后续阶段尚未显示；连接线先延伸，下一节点逐步显现，再成为当前焦点。已经过的节点留在左侧供回看，反向滚动沿同一路径恢复。

每个节点包含有区别的线性图标、序号、阶段标题、产物摘要与小型成果结构：方向比较、材料与未知、行动和产物、报告结构。它们是过程示意，没有虚构本人材料、完成率或能力数值。当前节点用深色圆形、约1.24倍图标缩放、略放大的整体结构和清晰边界共同强调；不是只把数字换成深色。

1. 了解与比较：先看日常任务，留下候选和关键疑问。
2. 确认与分析：本人贡献、材料出处、已有支持与未知分别记录。
3. 计划与实践：在可承受投入内完成小范围尝试，记录产物与限制。
4. 复盘与表达：连接选择理由、行动成果和下一步，保留版本。

这四段是首页说明的聚合，不替代产品中的职业探索、经历确认、差距分析、目标计划、任务成果与报告更新链路。“当前节点”表示正在浏览的说明，不表示本人已完成。

## 滚轮映射与渐进揭示

- 在宽度≥1024、高度≥700、非减少动态效果，且实际舞台高度能完整放入窗口时开启固定。固定距顶42px；核心推进距离为1.65个窗口高度，另有舞台自身高度，不叠加每节点一整屏的强制停留。
- 四节点中心间距420px。纵向推进0—1映射为路径位置0—3，轨道向左移动，使视线沿路径向右。没有滚轮拦截、自动播放、时间轴排队或强制吸附。
- 下一节点在距当前连续位置约.85到.55段时由透明显现；进入自己的强调区间时内容已完全可读。图标随接近焦点由1到1.24倍，整体节点由.94到1.04倍；离开后平滑缩回。
- 连线随滚动同步延伸，序号、快捷入口选中和下方说明在当前节点切换时更新。未来尚未显现的节点不可获取焦点；顶部四个直达入口始终可操作。
- 快速滚动直接响应当前位置，向上可逆。结束后正常进入工作方向区，不把滚动当业务完成事件，也不自动跳入登录或生成结果。

实现使用原生滚动监听和requestAnimationFrame，只改transform/opacity及离散选中状态；没有新增动效依赖。尺寸变化重新测量，卸载清除监听和待执行帧。窗口高度不足则清除轨道变换和额外滚动长度，避免卡住页面。

## 等价操作与返回

顶部四个快捷入口可直接跳选；底部前后按钮有首尾边界；画布获焦后支持左右键、Home/End。节点按钮采用当前项可Tab进入的方式，避免从末节点Tab后突然跳回第一节点。用户也可点击已显现的节点回看。

“查看这一段合成示例”沿用原案例弹窗，关闭或Esc回原阶段与滚动位置。头部“继续看工作方向”可以随时离开整段。手机、较窄/较矮窗口使用全部可见的普通节点网格/纵向路径，每个节点都有独立示例入口，无需找到整段末尾才操作。系统减少动态效果使用同一静态阅读路径。

本轮已核对减少动态效果的CSS与matchMedia分支，未实测操作系统偏好的运行时切换；不将代码核对说成设备验收。
