# 全站文案优化 v36

2026-10-19。已落实到本地实现，未部署线上。

## 核心表达

面向大学生的 IT 职业规划工具。帮助用户比较职业方向、分析准备差距、安排每周学习和项目，再整理职业报告与求职简历。

首屏主标题：**选 IT 职业方向，把准备落实到每一周。**

副文案：比较职业要求，找出准备差距，安排学习与项目实践，再把成果整理成职业报告和简历。

主操作：开始探索 IT 职业。次操作：查看规划成果示例。

## 表达方法与参考

查阅日期：2026-10-19。以下是表达方法借鉴，不借用宣传数据或服务承诺。

|参考|观察|本项目的采用方式|
|---|---|---|
|[Teal](https://www.tealhq.com/)|标题与操作直接点出简历、岗位跟进等具体对象|用职业比较、差距清单、本周计划、报告、简历说明成果；不采用其效果数字|
|[roadmap.sh](https://roadmap.sh/)|以职业和技能组织路线、课程与项目入口|学习页先解释学什么、用来做什么，地图说明先学什么再做什么|
|[Notion](https://www.notion.com/)|用具体动词和使用场景解释功能|按钮说明将执行的操作，正文说明用户能完成的任务|

## 覆盖范围

206 组短语、219 处替换、22 个界面与导航源文件；新增对应英文文案，另更新页面标题和搜索摘要。详细修改前后对照见[文案变更清单](检查记录/全站文案优化_v36/文案变更.json)。

覆盖公开首页首屏、五种规划成果、三种起点、流程、职业展廊、学习/AI/报告案例、说明和结尾，以及工作区、经历与教育、职业比较、差距评估、地图、阶段计划、日程、学习中心、站外实践、AI、岗位、报告简历、账户设置相关文字。

|旧表达|新表达|
|---|---|
|找到想探索的方向，走出有依据的下一步|选 IT 职业方向，把准备落实到每一周|
|规划，会留下什么？|把职业规划变成五份具体成果|
|个人画像与职业评估|我的经历与职业准备|
|四维依据面板|从四个维度查看职业准备|
|图或等价列表|查看方式|
|实践验证：外部行动|记录站外学习与实践|
|添加本人岗位输入|手动添加岗位|
|轮到你的下一步|从了解一个 IT 职业开始|

术语原则：时间预算在说明中优先称“每周可用时间”；证据在普通说明中明确为课程、项目、实习或相关材料；产物在面向用户的说明中优先称“项目成果、作品、提交内容”；未知保留为状态，配合“待补信息、暂时无法判断”解释。业务状态、路由参数、原始数据和用户输入不作全局同义替换。

隐私、授权、未知、本人确认与能力核验的区别保留；模拟AI、合成案例、未接真实招聘源的边界保留。管理审核和数据契约中有准确含义的专业名词不为文风统一而改写。未更改正式 PRD 或原始职业数据。
