# 工作区首页：功能入口与继续任务 v16

## 首页的职责

U03应同时回答：网站能做什么、我现在从哪里开始、怎样回到已有记录。此前五步横条重复了侧栏入口，统计与多组摘要占据首屏，功能目的不够明确。本轮保留一个有原因的下一动作，并补完整功能目录。

依据：07 当前布局第4节规定按资料状态展示下一步与三种起点，15 原型启动规格的U03要求一个下一动作及原因、目标/材料/任务/报告摘要；16 Teal增补将岗位简历、本人求职进展和结构化检索纳入现有模板。用户本轮明确要求移除首页重复流程条，当前实现遵循该指示。业务页的流程导航保留。

## 新布局与入口

| 区域 | 用户目的 | 实际目的页 |
|---|---|---|
| 继续我的事 | 按依据更新、候选确认、已有任务、目标或初次探索给一个下一动作 | 原评估页或同一任务ID |
| 当前准备范围 | 看目标、预计预算、材料与报告状态 | U07周安排 |
| 职业成长 | 探索、经历整理、差距分析、计划、学习实践、职业报告六个等大入口 | U05 / U04 / U07 / U08 / U10 |
| 求职准备 | 岗位研究、本人机会、岗位简历三类用途独立 | U05不同模式、U10简历模式；薪酬为附属入口 |
| 工具与账户 | 地图、AI咨询/检索/侧栏、背景偏好/权限/反馈/数据控制 | U06 / U11 / U12 |
| 回到已有记录 | 回同一任务、复盘、已保存报告版本和学习目录 | U07或U09按S1/S2分流、U10、U08 |

首次进入仍有方向未定、已有目标、已有作品三种起点。没有记录时展示清晰空态，不补造统计、能力分或任务。所有卡片整体为链接，避免卡片内嵌套多个无效按钮。页首分区导航帮助快速定位。任务工作区从真实任务进入，管理工作区保留角色隔离，不在学生首页混入审核入口；不新建主模板或强制走完整流程。

## 验证与文件

浏览器检查23个不同目的地址可进入对应页面，原任务保留ID，企业与岗位/我的机会为不同标题和模式。首页Workflow与固定FlowNavigation数量均为0。英文文案已同步。390px手机检查页面375px可用宽度与滚动宽度一致，网格为两列；求职入口与工具区域自动纵向布局。新用户三种起点、任务与报告空态以独立服务端渲染核对，未清空用户现有数据。31项既有测试通过，构建通过。未宣称真实登录、AI、招聘数据或服务已实现。
