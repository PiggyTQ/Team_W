当前状态：用户于 2026-10-30 明确授权“允许上线，AI 和外部服务保持关闭”，本轮已部署并完成生产验收。运行资料在 `/srv/career-growth/backend-platform-20261030-04/`，静态版本为 `/srv/career-growth/releases/backend-platform-20261030-04`。本轮没有调用 DeepSeek、发送真实邮件、上传私人备份或开通付费服务。用户已说明没有邮件服务、异地存储和管理员账号，预计首轮 20 人以内。

## 本轮完成的工程工作

### 个人建议接入

工作台新增独立的 `PersonalSuggestions`，通过已有组件插槽嵌入，沿用当前视觉。展示根据服务器保存状态生成的下一步建议、理由、对象引用和现有页面入口，支持忽略、不相关和主动重新读取。普通草稿保存复用当前结果，关键状态保存后更新；没有轮询，没有自动模型请求。等待保存、冲突、读取失败、反馈失败和账户切换都保留明确状态，旧账户和迟到响应不复用。

页面修改可以移动插槽或更改样式；接口调用、并发响应处理和反馈约束由独立控制器维护。[接口与前端协作约定](server/PLATFORM_CONTRACT.md)。

### 运行监测与真实稳定性问题

全站请求按固定路由和状态类别记录次数、耗时桶、最大耗时与中止请求，增加内存、进程峰值 RSS、事件循环延迟、哈希队列及后台清理失败状态。指标不包含 URL 参数、动态对象 ID、邮箱、IP、请求头、材料和聊天正文。

`/api/ops/metrics` 需要独立运维令牌，未配置/令牌错误返回 404；前端不持有该令牌。operator 管理角色可通过受会话保护的独立接口查看同类脱敏指标。默认是单进程 5 分钟窗口；探针保留最新状态，未声称长期指标仓库已经接入。

新增本机探针与每分钟 systemd 计时器候选，检查服务、数据库可读、5xx 比例、内存、事件循环、后台清理、邮件失败、备份成功回执和 TLS 证书到期。站外通知适配可配置，未配置则只输出检查结果，不向外发消息。备份脚本在所有校验完成后原子写入成功回执，不能仅以旧备份文件存在冒充备份成功。

修复两处实际问题：密码哈希原先超过 2 个同时请求就拒绝，现在保留同时执行 2 个、最多等待 20 个及 10 秒等待上限；原来所有账户请求共用 IP 登录额度，现在正常会话刷新不消耗匿名入口 IP 额度，注册、登录等仍有 IP 限流，业务操作仍有账户限流。返回的 Retry-After 改为对应窗口的剩余时间。

### 邮箱与账户恢复

新增可关闭的邮件适配、AES-256-GCM 加密待发队列、重试上限、15 分钟令牌、散列令牌存储、凭据版本绑定、一次性消费和旧会话撤销。账户删除级联清理令牌、队列和验证记录。未配置时验证/找回明确返回不可用，不能伪造邮件发送成功。

提供通用 HTTPS 邮件网关适配，固定服务端地址与令牌，禁止请求重定向；具体服务选择后可能需要适配该服务的请求协议。它不是已经接通某家供应商的声明。实际送达、退信、发件域授权仍需真实邮件服务后验收。数据库中的待发内容加密，恢复时需要另行保管的队列密钥。

前端补齐验证与重置链接入口。真实浏览器首次发现同一 `/auth` 下只改变地址片段时重置表单不打开，已改为应用入口接管 `hashchange`，按 token 重建表单并清除地址片段。失败截图与根据工具输出整理的失败说明保留，说明中明确原 JSON 报告已被重跑覆盖；没有将补记说明冒称原始报告。

### 管理权限与内容发布

新增 editor/reviewer/publisher/operator 职责、服务器 CLI 授权、受保护管理页面及 API。没有自动指定任何真实用户为管理员。学生修改前端角色或直接调用管理接口都会被拒绝。

公共知识包经过结构、用途、来源、切片散列和技能标准校验后保存为不可变草稿；经审核、发布后才切换业务检索入口；撤回当前包后使用空的撤回版本，不自动回退旧知识。原有 46 条原创知识原样登记为 baseline，保留工程/AI 辅助编辑审核属性，没有新增“专家认证”。知识入口由规则流程和启用后的模型服务共用，避免管理页面与实际检索脱节。

课程可以发布已有内容或停止新增使用；旧课程内容版本和学生成果保留。所有写操作校验对象版本、明确确认和幂等编号；业务记录、管理回执和审计同事务提交。管理回执保留 30 天、操作审计保留 90 天。原始课程包导入/新课程正文制作继续使用已有服务器工具，本轮没有声称实现浏览器课程内容编辑器或视频上传平台。

### 备份与发布准备

新增流式加密备份与认证解密工具；错误密钥不能产生可用恢复文件，不覆盖已有目标。远端上传默认关闭，需明确配置并使用 `--upload`。此项已验证本机加解密与原有 SQLite 恢复，尚未证明异地存储实际持久保存或异地整机恢复。

26 个运行源码/配置文件形成增量候选。只读获取了服务器 10 个明确列出的源码基线，未读取环境文件、私钥或生产用户记录。发布脚本逐文件校验基线和候选散列，先备份、独立构建与合成 API 验收，成功后才更新服务及静态版本。并行页面变动使基线变化时停止，不覆盖其他任务改动。

候选发布继续复用原账户库、知识库和费用账本；新增 10 张表，初始化公共知识 baseline。没有替换数据库或重置费用。监测配置使用独立 root 私密令牌，与 DeepSeek 密钥分开。
