## 可操作的业务

- 企业与岗位：服务器分页、关键词、地区、十职业方向、国内/国际分区查询；查看职责要求、薪酬原文、来源、采集及平台日期、技能提及、具体条件候选。保留否定、优先、备选等原句，不把提及升级为必须。
- 岗位详情可加入本人机会，保存来源编号、版本和快照；用户笔记和求职事件仍仅自己可见，刷新、重新登录后恢复。可并排比较最多三个岗位字段。
- 查询条件可以保存到账户，在检索页载入修改；不自动开启通知。旧的知识/私人研究卡筛选条件保留兼容。
- 职业详情可展开已有完整画像、细分方向、职责阶段、学习重点、职业关系、实践交付、自查标准及来源。计划页可将实践建议带入原有任务预检，不直接修改目标、预算或任务。
- 地图页可查看入库技能词典；学习页可展开21个外部实践模板、6个资源链接。模板只提供实践建议，不能替代课程正文或自动核验。
- 个人评估：用户主动更新时，先保存账户记录，再由服务端从该账户已确认材料生成 D1 对照。按本人明确选择的技能标签精确关联，不从自由文本推测能力；保留引用编号、材料版本、知识版本、未知及未独立核验状态。不产生分数。
- 报告页可由服务器按当前账号保存的目标、确认材料、任务及待补条目拼接 Markdown 并下载；未选择目标明确写“尚未选择”。排除撤回、未确认材料，不调用 AI，不制造个人结论。已有报告编辑、打印与账户 JSON 导出继续保留。
- 设置与数据页可只读查看来源范围、真实入库数量与版本；人工审核管理流程按用户要求跳过，没有假装管理员已经审核通过。

`GET /api/catalog/summary`、`profiles`、`profiles/:id`、`skills`、`jobs`、`jobs/:id`、`relations`、`resources`、`actions`、`facts`、`references`、`sources`、`profileSources` 提供实际目录查询。
