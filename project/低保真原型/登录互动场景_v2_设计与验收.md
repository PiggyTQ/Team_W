# 登录互动场景 v2 · 2026-10-23

用户否定v1的材质混搭、角色过小、角色与场景关系含糊以及插画对互动空间的限制，只认可密码遮眼机制。本轮重做左侧主体，采用实时三维场景；原型登录、注册、找回及入口恢复继续保留。v1的代码、图像与截图只作被否定版本的历史证据，不作本轮批准依据。

## Direction contract

THESIS：职业探索伙伴成为场景主体，与职业路径板一起迎接用户。取消静态3D环境叠加CSS平面小人的做法。

OWN-WORLD：统一蓝色与象牙白磨砂材质、圆润体块、一台相机、一组灯光和真实投影；角色胸前指南针呼应现有产品标志。白色登录表单保持清楚克制，变化仅限U02。

STORY：伙伴与路径板说明“认识方向、行动、成果”的产品用途；邮箱焦点回应用户，密码时用真正三维手臂遮住双眼，点击场景打招呼。场景不是本人进度或评估数据。

FIRST VIEWPORT：桌面保留左场景右表单，但主角色占约半个场景高度，副角色与它同台、同材质。场景下方就地状态取代叠在角色上的气泡。1280×720主提交可见；1000px及以下为上下结构，平板场景400px；手机场景292px高，表单自然滚动。

FORM：code-led，确定性的Three.js几何、物理材质和关节姿态，非栅格插画拟动；保留用户认可的遮眼机制。没有concept-seed输出，技能引擎不可用，未宣称该流程门禁通过。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 实现与证据

`LoginScene.jsx`管理加载与无WebGL回退；`login-scene-engine.js`管理同一三维场景中的角色、手臂、眼睛、路径板、台面、灯光、投影、纹理和资源释放。`LoginPage.jsx`只传递实际表单状态并保留原处理函数。

细指针注视与邮箱焦点转头；密码焦点或明文显示时两位角色遮眼；点击/键盘触发挥手。普通姿态静止，动作插值期间按需绘制，眨眼定时触发短渲染；页面不可见时暂停，卸载释放WebGL资源。减少动态效果直接切换姿态，不追踪、不挥手、不眨眼。设备像素比上限1.75。

无WebGL时使用同一实时场景的普通/遮眼实拍作为静态回退，不恢复v1混搭图。两张PNG是浏览器截图来源，不是imagegen图，也不是新插画。

实际截图均位于[登录同质3D场景_20261023](检查记录/登录同质3D场景_20261023/)：1440-zh.png、1280-zh.png、820-zh.png、390-zh.png、320-en.png、390-zh-bottom.png、320-en-bottom.png、1440-密码遮眼.png、1440-减少动态遮眼.png、1440-找回结果.png。手机是实际视口截图，底部另拍内部滚动。

`scripts/check-login-page.mjs`七组回归覆盖五视口中英布局、WebGL实际加载、无横向溢出、默认不擅自挥手、输入互动、失败重试、原入口恢复、注册同意、找回不建会话、Esc、减少动态效果、密码不存储与无WebGL两态回退，明细见该目录verification.json。独立审查和文档代理因额度限制未完成，已按技能降级流程由当前线程核对并同步，记录见[有限自查](.impeccable/review/login-v2-self-review.md)。不宣称独立设计审查或用户审美验收通过。

旧审查指出的低对比度占位/落款文字已加深为`#626e83`/`#5f6a7f`；找回、说明摘要及说明动作的命中高度统一44px。技能上下文与检测器因引擎不可用未运行，不写成通过；没有真机和辅助技术验收。

最终验证：v2的7组浏览器检查、原有`tests/guide-login-v53.mjs`的5项登录引导回归和`npm run build`均通过，无页面运行时错误。既有204项模型测试已在本任务先前通过，后续未改业务模型。构建输出含普通/遮眼两态回退图，已确认不再包含被否定的v1插画。Vite仍提示既有应用和Three.js场景大分块；Three.js动态加载，未声称完成全站包体优化。
