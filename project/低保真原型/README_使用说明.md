## 三分钟上手

1. 从公开首页选择“方向未定 / 目标已定 / 已有作品”，使用任意格式正确的示例邮箱和至少四位模拟密码进入。首次设置可跳过，恢复原入口。不要输入真实密码或敏感个人资料。
2. “演示设置 / 场景”可载入 PT01—PT07 合成场景、切换 S1 / S2，或选择三种管理职责。切换场景会明确确认替换本机示例。先从 PT01 手工走主线；PT06 适合查看尝试、反馈、修订与成果回流；PT07 适合查看报告更新。
3. 顶部“覆盖索引”列出全部 27 个视图、43 项需求及 14 条链路。它是原型检查工具，不是新增产品页面。管理页按演示职责拒绝访问；这不是生产鉴权。

## 推荐浏览主线

职业探索选择 2—3 个方向 → 比较、记录理由与疑问 → 确认目标或先做独立验证 → 个人评估手填经历 → 原文逐项确认 → 显式创建模拟四维差距快照 → 目标计划 / 学习实践的统一预检 → 确认总预算 → 执行任务 → 记录产物与本人贡献 → 本人自检 → 记录有限范围完成 → 选择成果版本 → 回个人评估确认 → 返回原任务 / 复盘 → 报告中心创建 / 更新 / 选择片段导出。

- **S1**：开始任务留在 U07 的同页任务详情，用本人记录保存外部行动；跳过、取消不等于完成。
- **S2**：有原创合成任务内容时进入 U09；笔记、阅读、提交版本、检查、任务完成、声明确认分别记录。示例中选择“自检记录”只记录本人核对，不是实际运行或独立核验。
- **预算调整**：先保存临时方案或预览应用；模拟另一端版本变化会阻止旧方案应用。下降预算时延期或缩小未来任务，保留已完成成果。
- **岗位支线**：U05“企业与岗位”查找与研究合成示例 → 主动加入“我的机会”（或直接输入本人允许处理的原文）→ 私有研究卡 → 准备任务进入同一预算 → U10 岗位简历选确认经历 → 本人手填投递 / 面试 / 结果事件并选择材料快照 → 下一行动回计划。浏览不收藏，收藏不代表申请；原型不投递、不发信。
- **检索支线**：U11 自然语言检索 → 确定性示例规则生成筛选草稿 → 本人修改并确认 → 选择职业知识 / 无源获准岗位 / 私有研究卡范围 → 结果或空态 → 放宽条件 / 保存条件。保存不自动开通知。
- **管理支线**：B02 用途与语义分审 → B03 标准 / 许可 / 依赖检查与模拟发布；B01 接收具体反馈 → 保存处理回执 → U12 本人可查。

## 状态和输出

本机 `localStorage` 保存示例，刷新与返回保留材料、计划、任务、会话、报告和草稿。该存储不是加密账户数据库。需要隔离演示可用独立浏览器配置；可在设置导出本地 JSON 或重置。

报告可下载明确标注的本地 TXT 片段，私人反思默认排除；主动开启后仍须逐条勾选。简历提供打印预览，打开浏览器打印后可“另存为 PDF”；不连接真实 PDF 生成服务。关闭打印对话框不代表导出成功，界面不会把它记为已投递。

所有职业内容、任务与 PT 场景均为合成 / 原创示例；用户录入的文本标为本人记录。图像和视频统一引用纯黑占位图，无装饰动画。姓名、性别、联系方式不参与分析。未知不按 0 分处理，不提供招聘数量、薪酬聚合或个人能力 / 录用结论。

## 统一前进与返回（2026-10-16）

学生主线和相关支线新增底部常驻流程操作栏：左侧明确返回目的地，右侧明确下一步，中间说明资料或任务状态。经历填写、原文确认、差距分析以及任务尝试、贡献、完成回执均有连续入口。报告可回实践或工作区；岗位简历与求职进展、AI 与原工作页可以往返。

前进只切换页面，不提交表单、不确认经历、不运行模拟分析、不创建或完成任务。填写内容按原页面规则保留；需要保存候选、提交尝试、另存报告时，仍须点击原有业务按钮。无资料或无任务时，操作栏说明缺项并给出补充入口。

桌面操作栏单独占用布局行，手机底部固定并自动预留内容空间。已验证首次探索、缺项、草稿保留、有效/取消/S1任务、报告与简历支线，以及桌面和手机的底部可达性。运行：node tests/flow-navigation-check.mjs。

外部实践入口：在目标计划的总览或执行列表点击底部“下一步：进入实践验证”，进入实践目标→记录行动结果→整理行动复盘→职业报告。也可点击顶部第4步。手编外部任务继续使用计划模板中的模式，平台内任务使用原任务工作区。进入下一页不会自动完成任务；实际结果、贡献与反馈仍由本人填写。

AI工作台布局更新：返回原页面、前往目标计划（或职业目录）的入口位于页面右上角。AI页面不显示五阶段导览和底部前进栏。聊天框支持Enter发送、Shift+Enter换行，消息可独立滚动；问题起点只填写草稿，发送后显示模拟回答。手机可通过“讨论与历史”展开会话管理。全站职业成长入口连续排列，技能地图与AI移至辅助工具区。

地图与聊天入口更新：职业与技能地图按需使用，不再显示主线五阶段导航或前进栏。可选择关系类型、图/列表和节点，右侧查看用途、材料与操作；技能节点可只阅读、生成预算预检草稿或继续原任务。自述“已学习”不等于能力核验。地图的方向、过滤和选中项随网址保存。

AI空会话使用居中的问题输入和简短问题起点，没有可滚动的空聊天框；发送后才显示消息区。“历史讨论”位于顶部，打开抽屉后可查找、切换、改名、归档与删除，关闭后不占据聊天宽度。功能与正式规格的对照见“地图与聊天完善说明.md”。

可视化与日程：工作区可查看当前材料、任务、复盘及预计预算；目标计划顶部“查看本周日程”或“执行→日程”进入周/日视图。点击任务编辑日期；取消不保存，清空后保存可回到未排期；原任务成果与预算保留。

职业评估在“个人评估→职业评估”显示四维依据、材料引用和历史版本。先确认材料，再明确创建/更新模拟快照；首次没有比较版时不画假趋势。有两个同职业同规则的版本后，可选择基线查看依据变化。记录数与预计投入均不代表能力分数或真实学习时长。详细判断见“可视化与持续评估设计分析.md”。

用户设计例图与后续图片同步约定已归档：../设计参考与同步/设计参考与图片同步约定.md。包含六张原始例图、逐图备注、对应页面、当前低保真截图与完整Web设计图待办。完整Web结构改进须同步设计图、实现截图和说明，遵循项目AGENTS.md。
