## 现在需要填写的一步

在你已经登录的服务器终端中运行：

```bash
python3 /etc/career-growth/set-ai-key.py
```

按提示粘贴 DeepSeek API Key 两次，每次按回车。输入时不会显示字符，这是正常行为。若终端无法关闭回显，工具会拒绝继续。请只粘贴密钥本身，不加引号或变量名称。不要将密钥、包含密钥的文件内容或截图发到聊天中。

成功时显示：

```text
Key saved privately. AI remains disabled. No service was restarted.
```

之后在聊天中回复“已填好”即可；不需要发送密钥值。需要自行检查时可以运行下列命令，它只返回是否配置，不显示密钥：

```bash
python3 /etc/career-growth/set-ai-key.py --status
```

## 存放方式与启用边界

`/etc/career-growth/ai.env` 由 root 所有、权限 0600，目录权限 0700；位于网站源码与网页目录之外。填写工具以原子写入方式更新，仅接受交互终端输入，密钥不进入命令参数或命令历史。填写或更换密钥都会保持 `AI_ENABLED=0`。

`/etc/career-growth/career-auth-ai.conf.pending` 只是待启用的 systemd 配置草案，目前没有安装到运行服务。此次没有部署 AI 代码、修改正在使用的服务配置、reload 或 restart。密钥填写完成也不会自动产生付费调用。

接下来先核验配置状态、知识范围和预算账本，再安排受控真实测试。网页接入和生产部署仍按各自影响评审执行。

## 人民币八元预算如何控制

本轮累计预算是 **8.00 元人民币**，不是每天 8 元。已在本地代码实现独立 SQLite 账本，计划位置为 `/var/lib/career-growth/ai-budget.sqlite`；该新代码尚未部署，当前也没有付费记录。

所有本项目的真实调用，包括单独烟测，都必须在 HTTP 请求发出前事务预留费用；额度不足、账本不可用、预算配置高于 8 元、切换不支持的模型或费率过期时拒绝请求。重启、换用户、跨日和改预算标识不会重开额度。失败、超时、取消和未知用量不退预留；有用量统计也只记录，不返还预算。因此应用会保守地提前停止，可能在真实费用尚未达到 8 元时就用尽预留。

首轮仅允许 `deepseek-flash`，关闭思考模式，每次最多 1600 输出 tokens，不自动重试。按 2026-10-28 核对的[官方人民币峰值价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)的两倍估算，输入采用实际请求 UTF-8 字节数加协议余量作为保守 token 上界。费率校验有效至北京时间 **2026-11-04 00:00**，到期阻止新调用，重新核价也不重置累计账本。

这是固定协议和已核价假设下的应用预算限制，不是供应商账户层面的账单硬限额，无法约束其他程序使用同一密钥的费用。建议此次使用本项目专用密钥，实际扣费再与供应商账单核对；账本不得删除或更换来继续消费，增加额度需重新授权。
