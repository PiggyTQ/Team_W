# 职业方向自动播放 v32

2026-10-19。用户要求截图中的“先看工作内容，再考虑方向”进入视口后自行横向播放，取消滚轮驱动。

## 实现

职业展廊改为独立轮播组件。卡片区域至少55%进入视口后，按从左到右的方向顺序自动展示；每4200ms推进一张，横向滑动1100ms，停稳时主卡居中。播放至第十张停止，可点击重新播放。

删除展廊原来的固定舞台、额外纵向滚动距离和方向卡片松手吸附坐标。滚轮正常向下浏览页面，不改变职业卡片位置。上方四节点流程及下方案例章节保留原有交互。

提供暂停/继续、上下张和下拉跳选。手动选卡或查看摘要会暂停；键盘焦点进入卡片阅读区、弹窗打开、页面隐藏、展廊离开视口时停止自动计时。鼠标停在卡片上不会阻止首次自动播放，避免用户滚到这里却没有动效。减少动态效果关闭自动播放和横向过渡，保留手动选卡；手机适配卡片宽度，页面不横向溢出。

保持灰阶、400字重和全黑图像占位。用户截图仅说明目标板块与交互，不扩充产品业务范围。
