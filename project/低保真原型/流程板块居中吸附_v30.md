# 流程板块居中吸附 v30

2026-10-19。针对用户再次反馈“从了解一份工作到做出自己的成果”应松手后归位最近一张，完成交互细节修正。沿用灰阶低保真，无新增参考图片。

## 问题与修正

实际读取用户的本地预览：窗口为667×815，鼠标精细指针，之前流程为普通列表，吸附未开启。v29只在宽度1024px以上启用流程固定轨道，且高度测量只随宽度更新，未覆盖当前预览。

- 流程固定轨道覆盖520px以上、600px以上高的鼠标窗口；手机触摸和减少动态效果仍自然阅读。只有整块实际高度适合当前屏幕才固定。
- 流程顶部改为 `(视口高度−实际板块高度)/2`，卡片横向居中，整个流程板块上下居中。轨道、板块入口吸附、最近节点计算和按钮跳转共用同一顶部坐标。
- 最后一次滚动140ms后，以现有临界阻尼弹簧归位最近节点，允许反向输入和新滚轮立即打断。入口附近停止也可补完到第一张；末端继续滚动正常离开。
- 增加舞台高度观察，字体、内容或窗口变化后重新测量，避免错误退回列表。关闭受控滚动模式下的浏览器滚动锚定，防止重排后落点偏移。
- 为短窗口压缩节点空隙，保留完整卡片和底部操作；窄鼠标窗口仍用横向轨道，节点图标、标题和成果卡中心一致。
