# U01 问题卡牌、流程路径与十方向展廊 v3

2026-10-17。仅调整公开首页三个区块，产品模板、业务状态与数据规则不扩充。灰阶、统一字重400、全黑媒体占位继续保留。用户本次明确授权这三个区块采用解释和选择动效，其他操作页不随之增加装饰动画。

## 整页节奏与方案选择

首屏静态讲用途 → 成果单舞台解释产物 → 问题卡牌中心展开供选择 → 四节点路径轻量连接 → 十方向横向展廊 → 学习路线、AI、报告与隐私继续自然阅读。

十方向选择桌面横向展廊，避免十张高卡片连续占据十多屏。它是当前首页唯一的滚动固定展示段，问题卡牌只展开一次，流程线只作短连接，不把每一段都做成长时间固定的舞台。若后续给成果舞台增加滚动固定，须重新评估整页滚动成本，不直接叠加两个长固定段。

## Roveia 参考核对

用户指定 [Roveia 首页 What We Do](https://www.roveia.com/)。已保存[公开页面](../参考调研_20261017/Roveia_WhatWeDo/homepage.html)、[含区块逻辑的内联脚本](../参考调研_20261017/Roveia_WhatWeDo/what-we-do.inline.js)、[实际入口取样](../参考调研_20261017/Roveia_WhatWeDo/实际参考_区块入口.png)。浏览器取样展示宽卡片连续伸向右侧、下一张部分露出；没有将参考站的健康营销内容或成效数字带入本产品。

源码中该区块在宽度≥992px时：纵向滚动驱动 `.services-cards` 的 x；位移为卡片总宽减窗口宽并考虑两侧偏移，线性推进；从 `center center` 开始固定，以卡片总宽作为滚动距离，`scrub:1`，尺寸变化重新计算。取样与源码证明的是横向推进，不是滚到单卡就自动放大的效果。参考截图不是完整逐帧录像。

采用其宽卡、相邻预览和纵向映射横移；本项目自行实现原生滚动映射，没有复制全站平滑滚动、依赖或图像。卡片放大方案本轮未选：在三张立体入口和上方成果舞台之后，再让十张卡逐一放大，节奏过重，且不利于并排比较。

## 三张入口卡牌

桌面有共同的中心起点，进入可视区后扇形展开。左卡Z轴−9°、Y轴12°，中卡Z轴1.5°、Y轴−3°并略向前，右卡Z轴9°、Y轴−12°；透视1400px、非零偏移柔和投影共同说明前后关系。卡牌保持正常可读比例，不添加浮动循环、光标跟随或假数据。

展开是低频首页解释动作：CSS transform、640ms、`cubic-bezier(.23,1,.32,1)`。展开后切换选取为240ms；选中卡拉近、上移、转正，其他卡保持扇形。键盘触发立即切状态，手机使用轻微倾角的自然列表，系统减少动态效果时取消空间过渡。

|卡牌|当前选择效果|进入原流程|
|---|---|---|
|方向未定|抬起并显示已选取|`/careers`，了解与比较|
|目标已定|抬起并显示已选取|`/assessment?tab=四维与差距`，核对已有材料与差距|
|已有作品|抬起并显示已选取|`/assessment`，整理本人贡献|

点击卡面只改变本区选中状态，不替用户确定目标，不启动AI。底部文字入口才导航，使用原模拟认证；取消认证后保留选择。三张卡的入口始终可用，不要求先选卡。

**自由拖拽抽取尚未实现。** 后续结合用户待提供的参考细化：指针按下保留原槽位，拉出达到明确距离后才进入待确认态；未达阈值、指针取消或Esc回原位；确认进入沿用原入口；不因路过另一张卡更改入口。不依赖拖动，按钮和键盘必须保留等价操作。真实手势加入时再选支持速度连续性的弹簧方案并测试触屏，当前不把点击抬起称为完整拖拽抽卡。

## 从左到右的流程路径

> 此小节记录v3历史。用户再次提出滚轮推进后，路径已升级为[滚轮递进路径v4](首页滚轮递进路径说明.md)：后续节点逐步显现、当前节点放大、可逆推进。卡牌和十方向展廊仍沿用本文对应说明。

四个节点保留现有首页聚合逻辑：了解与比较 → 确认与分析 → 计划与实践 → 复盘与表达。底层仍连接正式产品的经历确认、差距、计划、任务成果和报告更新；不是减少正式流程。

桌面节点共享一条水平基线，连接线逐段展开，箭头明确阅读方向；三段连接360ms、依次错开180ms，总约720ms，内容本身不位移。点节点更新下方说明，点“查看这一段合成示例”进入对应例子，关闭回原节点。手机改纵向节点与连接线。标识说明这是浏览路径，不冒充本人完成进度，不用实心节点编造已完成状态。

## 十方向展廊

所有十个原创方向一次可达，不再默认只显示六个。宽卡包含全黑图像占位、方向及细分、主要任务、常见产物、摘要按钮，沿用已有职业数据。

固定仅在宽度≥1024、高度≥720、非减少动态效果且**整个舞台实际高度能放进窗口**时开启。舞台距顶42px；卡片318px、间隔24px；纵向有效距离等于轨道溢出宽度。进度钳制0—1，直接映射 `translate3d`，没有滚轮事件拦截，没有自动播放。只在滚动/尺寸变化时请求帧，卸载清除监听和内联变换。

方向下拉可直跳十项，前后按钮和画布左右键、Home/End提供等价浏览；首尾禁用，不循环。Tab进入离屏卡片时调整舞台使焦点可见。摘要弹窗取消后仍回到本展廊，不创建收藏或本人材料。最后一个方向之后正常进入后续内容；头尾都有“继续看学习路线”锚点，可以跳过。

小屏、较矮窗口、放大导致容纳不足或减少动态效果时，取消固定和横移，十张卡以普通网格/手机列表排列；仍可下拉跳选、打开摘要。已实测1200×600和1100×720回退为列表。减少动态效果的CSS及matchMedia路径已代码核对，未在本轮工具中实测操作系统偏好的动态切换。
