# 首页品质复核 v22

日期：2026-10-18。范围：U01 公开首页的精修。仅本地代码，未上传 CloudBase。此文不是全站15模板的新功能验收或获奖认证。

## 判断依据与设计主线

保留已经确认的灰阶、统一400字重、系统字体、黑色媒体占位，以及成果15态、三张平级卡、横向流程、职业展廊和同一案例三章节。用户既有参考站 Pier Gorelli 与 Roveia 的借鉴继续按项目设计参考约定管理，不复制其品牌资产。此次为既有视觉体系精修，不重新随机选择品牌方向，不加入外部图片或视频。

主线：职业问题成为可回看的规划材料；用实际可操作的合成产物证明每一段的用途。没有依据的数字和能力结论保持未知。

参考的公开评审维度：[Webby 官方 Judging Criteria](https://www.webbyawards.com/judging-criteria/)。Awwwards、Webby、FWA作为品质目标，不给未经独立评审的站点贴获奖标签，不用自评分数冒充实际用户研究。

## 八项复核与改进

| 维度 | 发现及处理 | 验证/边界 |
| --- | --- | --- |
| 排版 | 首屏标题提升到40—64px；正文与说明拉开层级；主要内容14—17px | 1440、768、390、320px中英文检查；保留系统字体与统一字重 |
| 留白 | 章节共用48—88px响应式间距，标题和正文保持同组 | 保留用户确认的上下分区与全宽横向问答 |
| 视觉层级 | 仅开始操作使用深色主按钮；学习/产物/下一步的层级更明确 | 不增加功能入口或改写事实文案 |
| 色彩 | 继续灰阶，用#252525/#595959及白色纸面区分主次 | 不以颜色替代状态文字；不引入品牌色 |
| 动效 | 展开收拢保持1秒；选取240ms，与长展示动画分开 | CSS实际时长1s/0.24s；原生连续滚动不变，减少动态效果保留 |
| 微交互 | 导航下划线、主动作箭头反馈、统一焦点轮廓、44px方向按钮 | 问答展开、卡片取消/切换可用，控制台无error |
| 响应式 | 修复语言切换遮挡导航；宽屏与手机各自排版 | 三个主要尺寸及320窄屏无整页横向溢出；小笔记本展廊641px高，720px视口内恢复scroll模式 |
| 原创性 | 继续使用方向比较、材料、差距、任务、报告这一产品自身叙事 | 不添加虚假案例、成绩、品牌图片或无依据图表；品牌视觉仍待后续阶段 |

## 实施文件

- src/landing-quality.css：只作用于公开页，避免业务工作区视觉串改。
- src/LandingJourney.jsx：区分选择反馈和滚动展开时长，离开/重返后恢复1秒展开收拢。
- src/main.jsx：加载公开页精修样式。

## 实测与修正

首轮桌面/手机检查后修正导航与语言切换碰撞。复核发现提高字体后720px高展廊退成列表，已在小笔记本媒体规则中压缩图片和内部间距；复测stage=641px，top=42px，bottom=683px，恢复横向滚动模式。宽屏1440×900、平板768×1024、手机390×844、最窄320×740检查无整页横向溢出，320px英文主按钮仍在首屏可见。

生产构建通过；43项现有测试通过；本轮浏览器未记录error。未进行真实手机硬件帧率测量、真实用户可用性研究或独立奖项评审，不能据此承诺没有进一步提升空间。当前低保真最明显的视觉完成度上限仍是用户指定的系统字体、黑色占位媒体及未进入正式品牌阶段。
