# 记录使用说明 v7

> 历史方案。用户要求两块独立，现由[全宽独立板块v8](内容与资料独立板块说明_v8.md)替代。

2026-10-17，U01 局部改进。替代 v6 中“探索可以继续，决定权始终在你”的独立说明块；学习、AI、报告与 FAQ 功能保持原范围。

原问题是案例结束后又出现口号式大标题、分类标签和大段解释，内容层级突然变重。现在改为报告后的 **这些记录，会怎样使用？**，作为同一案例画布下方的补充说明，不再占用左侧独立标题区。

- 沿用报告的右侧宽度、灰阶底色、边框和文字样式；中等及窄屏随案例恢复全宽。
- 来源范围、确认与核验、资料处理三条规则直接可见；详细内容按需展开，一次只展开一条，可再收起。原有规则和模拟边界全部保留。
- 左侧案例目录随报告结束，避免在说明区停留半截目录。这里不是新增流程步骤，不增加序号或本人进度。
- 底部保留“查看数据与隐私说明”，增加直达“常见问题”的明确出口。`#trust` 旧锚点继续有效，报告出口和顶部导航均可进入。
- 仅原生折叠箭头使用160ms转向；减少动态效果取消过渡。没有新增滚动动画或真实权限操作。
