# 首页滚动揭示 v23

2026-10-19。U01 公开首页局部动效设计与实现。本地预览：http://127.0.0.1:5184/；尚未上传 CloudBase 或替换线上版本。

首屏标题在约 1.05 秒内逐字上浮显现；成果入口的右侧画布由两侧收口随滚动展开，左侧说明和主要操作保持完整；三入口标题、案例承接、使用说明与结尾标题随滚动逐字由浅变深，向上可以回看。正文保持直接阅读。现有卡牌展开、15 态成果、四段路径和十方向展廊继续工作。

灰阶、字体、400 字重和现有业务内容沿用。中文按字、英文按词；无新增依赖。使用 GSAP 与已有 ScrollTrigger，标题滚动进度依据实际视口位置计算，避免前面的固定舞台改变文档高度而使后半页动画错位。主要动效使用 transform 和 opacity；画布使用 clip-path 裁切，是局部重绘效果，未进行真实设备帧率测量。

手机和平板标题进入时使用短时错峰，不增加固定滚动；系统开启减少动态效果时，完整标题、完整画布直接显示。读屏只读一次完整句子；聚焦成果区立即显示完整画布。窗口尺寸、语言和动效偏好变化时重建对应动画，卸载时清理观察器、监听器和 GSAP 上下文。
