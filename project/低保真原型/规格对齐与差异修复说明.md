## 使用入口

- 报告：职业报告 → 创建预检 → 选“职业探索/阶段准备报告”或“咨询摘要”，选择内容。打开已有报告 → 按新依据建立草稿 → 逐章处理；导出时私人片段逐条勾选。
- AI：选择/拒绝资料范围 → 勾选确认片段及版本。发送后，回答下方可保存笔记；顶部“本人笔记”可查看，删除前说明影响。
- 成果：完成回执 → 选择成果版本 → 增加技能条目 → 分别填写支持范围和位置 → 本人逐项确认。
- 实践：目标计划 → 实践验证 → 记录行动结果。实际类型、日期、方式、出处与反馈不会由系统补造。
- 删除：账户与数据 → 导出与删除。材料范围与本机演示账户范围分开；已下载文件不能远程收回，真实后台和备份不在原型内。
