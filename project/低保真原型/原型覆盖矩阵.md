## 14 条链路合同

- FL01 公开入口、认证与返回意图：U01 → U02 → U03 → U12。取消与恢复：认证取消回同锚点；对象失效或阶段不可用回U03解释，越权拒绝；退出清私人缓存。
- FL02 材料输入、冲突确认与返回回执：U04 → U09 → U12。取消与恢复：解析失败可手填，取消无晚到覆盖；未确认/冲突不作为确定事实；未开放U09则回U07/来源。
- FL03 职业理解、比较与暂未决定：U05 → U07。取消与恢复：无结果可重置过滤；未决定可暂存/退出；不按最高分强迫选择。
- FL04 准备分析、差距分流与纠错：U04 → U07 → U12 → B01。取消与恢复：依据不足不输出完整总分；反馈不直接改事实；规则变更不当能力进步。
- FL05 双地图、技能节点与先修解释：U05 → U06 → U07 → U08 → B03。取消与恢复：无关系不造线；建议未知不禁阅读；必需交付按标准，资源不可用可替代/存草稿。
- FL06 目标、计划、方案与S1手工执行：U03 → U07。取消与恢复：超额或循环拒绝静默应用；版本冲突重预览；完成成果保留，跳过不计完成。
- FL07 自主实践开始预检与阅读分流：U05 → U06 → U07 → U08 → U09。取消与恢复：无主目标可独立；预算未定/超额先存草稿；取消返回来源，S1不跳U09；纯阅读不建任务。
- FL08 尝试、检查、修订、成果与确认：U04 → U07 → U08 → U09。取消与恢复：检查服务故障可重试不判能力；必要标准不符待修订，不能伪标完成；无运行器不说运行成功。
- FL09 复盘、下一行动与提醒：U03 → U05 → U07 → U12。取消与恢复：无行动不补造过程；提醒默认站内可关；偏好变化不自动改能力。
- FL10 企业岗位研究、目标关系与准备同步：U03 → U04 → U05 → U07 → U12。取消与恢复：岗位过期不删通用成果；归档先看共享任务；改主目标另走预览，不隐式切换。
- FL11 薪酬参考及数据不足出口：U05 → B01 → B02。取消与恢复：缺样本显示不足；面议不是零；私人JD不混公开统计；缺换算条件保留原口径。
- FL12 报告中心、更新合并与选择导出：U04 → U05 → U07 → U10 → U11 → U12。取消与恢复：取消不覆盖旧稿；失效引用阻导出，私人反思默认不选；失败可重试，删除权限各处生效。
- FL13 AI侧栏与独立页、提议的闭环：U03 → U04 → U05 → U06 → U07 → U09 → U10 → U11 → U12。取消与恢复：卡片按类型到U05/U04/U07/U10，未开放S2任务只草稿；基线更新重预览；AI故障手动主线不阻断。
- FL14 内容发布、依赖撤回、反馈与职责：B01 → B02 → B03 → U12。取消与恢复：缺用途/循环/依赖失效阻发布；撤回使相关引用/新结论失效，晚到作业不回写；反馈不直接改事实。
