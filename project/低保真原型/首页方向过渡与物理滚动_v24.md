# 首页方向过渡与物理滚动 v24

2026-10-19。用户要求：新内容出现时使用上滑或下滑，滚动具有依据力学公式的拉扯感。本轮只更新 U01 动效，保留灰阶与产品内容。接替 v20 的原生直滑/出口轻微缩放方案；v23 的逐字揭示与画布展开继续保留。

## 内容切换

下一项：旧内容向上退出，新内容从下方进入；上一项方向相反。应用于五成果十五状态、成果解释、四段路径说明、学习工具、AI 示例问题与答复、方案解释、报告片段和问答展开。滚入后半页的新段落也会上浮进入。

切换使用 WAAPI 的 transform 与 opacity。旧内容 100ms 退出，新内容延迟 60ms 后以 240ms 进入，总计 300ms；首次进入没有延迟。二者错开以减少文字重影。快速切换从当前画面位置继续，清理上一份视觉副本。实际交互始终由 React 当前内容承担：退出副本 inert、aria-hidden、不接收鼠标、移除所有 id，结束或卸载即移除。读屏不会重复读旧内容。

## 拉扯与回位公式

滚轮输入先改变目标位置，再由质量—弹簧—阻尼系统跟随：

`m · x'' + c · x' + k · (x − target) = 0`

`a = [k(target − x) − c·v] / m`，随后分步积分速度和位置。采用 m=1、k=100、c=20；阻尼为 `2√(km)`，即临界阻尼，使滚动有跟随与停稳过程，同时避免滚动位置越过目标后倒摆。用不大于 1/240 秒的积分小步；长帧的累计积分时间最多 50ms。实际滚轮输入180px的浏览器采样是首帧9px、中间143px、最终180px，证实并非一次直线跳到目标。

模块出口增加非线性橡皮筋位移：

`R(d) = sign(d) · 56 · (0.55|d|) / (56 + 0.55|d|)`

距离越大，新增位移越小，拉扯幅度渐近56px。其导数用于滚动阻力：`gain = 0.55 / (1 + 0.55d/56)²`。累计输入达到280px后放行，持续滚动能够离开，不要求停顿或等待锁。可视内容的位移和最多1.4%的伸展也用同一弹簧系统跟随；输入停止110ms后，目标回零并阻尼恢复。这里的110ms用于识别停止输入，不是锁住滚动。

反向输入立即取消尚未完成的前向目标；点击、键盘、锚点、滚动条拖动和外部定位均可中断跟随。内部可滚动区域先用自己的滚动范围，耗尽后只把剩余输入交给页面。没有对滚轮事件做计时节流。

物理跟随用于宽度至少1024px、高度至少720px、精细指针且允许动态效果的桌面。手机保持系统触摸惯性；减少动态效果时取消物理接管、拉扯和上下位移，内容直接呈现，偏好变化立即清理当前动画。

## 实施与验证

- `src/content-transition.jsx`：统一方向过渡与无交互退出副本。
- `src/scroll-physics.js`：橡皮筋函数和弹簧数值积分。
- `src/HomeScroll.jsx`：滚轮目标、惯性跟随、出口拉扯、段落进入和打断清理。
- `LandingIntro.jsx`、`ScrollJourney.jsx`、`LandingTail.jsx`：接入内容上下切换。

构建通过；46项单元/模型测试通过，包含30/60/120Hz收敛、非线性阻力、回位稳定性；8项本轮浏览器行为与运行时检查通过，上一轮9项首页浏览器检查也通过。结果见[本轮记录](检查记录/首页方向过渡与物理滚动_v24/验证结果.json)。桌面和320/390px检查无整页横向溢出。未实测真实手机硬件帧率。
