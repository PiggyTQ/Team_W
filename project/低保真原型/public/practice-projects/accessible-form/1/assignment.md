# 可访问表单与状态恢复

活动协调员需要可使用的报名表单。实现标签与键盘纠错、等待、失败与重试；等待时修改输入，要取消旧响应的影响，避免覆盖或清空新输入。

## 材料与流程
先对照 input/dictionary.md 阅读完整输入 input/fixture.json。实现所需源码/配置，本机执行 verify.mjs，定位错误并修订，保存输出。准确命令见 RUN.md；reference 目录是公开教学参考，与脚手架分开。

## 产物契约
