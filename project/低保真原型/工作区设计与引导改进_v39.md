# 工作区设计与引导改进 v39

2026-10-19。基于当前 v38 继续，范围为学生工作区，不改公开首页、滚动吸附、横向循环及鼠标拖动。保持灰阶、系统字体和400字重。真实服务仍未接入。

## 调研与取舍

本轮检索 Linear、Notion、NN/g、Carbon、GOV.UK、Atlassian 的官方资料；以下是设计参考，不代表接入它们的产品或组件。

| 官方资料 | 借鉴 | 本项目落点 |
| --- | --- | --- |
| [Linear My issues](https://linear.app/docs/my-issues) | 按当前关注的工作组织，而非平铺功能 | 首页优先待处理依据、待确认材料与可继续任务 |
| [Linear Display options](https://linear.app/docs/display-options) | 内容与显示方式分离 | 功能清单按职业成长、求职准备、工具与账户切换；不更改业务数据 |
| [Notion sidebar](https://www.notion.com/en-gb/help/navigate-with-the-sidebar) | 稳定导航、就近返回已有内容 | 保留原侧栏路径，首页提供最近任务、报告、续读入口 |
| [NN/g Onboarding tutorials](https://www.nngroup.com/articles/onboarding-tutorials/) | 需要时提供帮助，避免初次灌输 | 内页指南可展开、可收起，不遮挡操作、不强制完成教学 |
| [NN/g Progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/) | 先展示主要操作，再提供次要信息 | 操作在前，详细步骤在后；顶部账户工具集中到菜单 |
| [Carbon Empty states](https://carbondesignsystem.com/patterns/empty-states-pattern/) | 解释空白原因并给出有意义的操作 | 共用空状态先给动作，再按需展开步骤；不显示虚构完成度 |
| [GOV.UK Complete multiple tasks](https://design-system.service.gov.uk/patterns/complete-multiple-tasks/) | 动词命名、真实状态、支持跨次继续 | 成长路径显示本人记录数量和待处理项；不把浏览视为完成 |
| [Atlassian Empty state](https://atlassian.design/components/empty-state/) | 无内容时告诉用户接下来能做什么 | 原文队列、复盘、任务版本等共用空状态保持明确入口 |

不照搬企业项目管理软件的密集看板，也不添加强制向导、评分、虚构趋势或新的业务流程。Atlassian 旧 onboarding 组件已标为弃用，本轮不引入包。

## 调整前观察

实际桌面1440×1000及手机390×844检查六个页面。截图位于 `检查记录/工作区改进_v39/调整前/`。

- 首页主操作之后有六张成长卡、三张求职卡、多列工具与多个空记录，重要程度接近，阅读顺序不明确。
- 手机顶部搜索、提醒、账户操作占用过多高度；内页五步流程横向截断，还有底部流程条。
- 内页已有说明不少，但缺少随当前页和材料状态变化的简洁提示；空状态先读三段步骤，才看到按钮。
- “已有经历可以复用”在没有经历时也出现，应显示真实空白或待确认状态。

## 实施方案

空间主张：稳定侧栏 + 简洁工具栏；主栏先做当前一步，右栏看相关背景，功能目录在后。手机按同样阅读顺序排列。

1. 首页保留现有优先级（依据变化→材料待确认→有效任务→目标准备→探索），首次可自行切换三种起点。选择仅切换说明和入口，不写入目标或材料。
2. 目标与周预算保留实际数值，只有有待确认材料时强调处理入口；任务/报告/续读按真实记录提供恢复入口，无记录不堆多个空框。
3. 功能目录使用三个明确的分组按钮与紧凑链接清单，所有原路径仍可到达；不把求职准备强制成成长的后置步骤。
4. 内页将重复五大块导航收为本页指南：默认只显示当前目的；展开后给出材料要求、产物、状态提醒和可选成长路径。覆盖职业目录/岗位、个人评估各页签、计划/执行/复盘、学习、任务各页签、报告/简历、地图、AI、账户。
5. 顶部账户工具用原生可展开菜单，手机保留独立导航和搜索；原有权限、搜索范围及退出确认保持。
6. 共用空状态把操作提前，操作步骤可以按需展开。已有保存、预览、预算确认、材料确认流程不改变。

## 实施与检查结果

已实施。首页由多组同权重卡片改为主行动、相关背景、记录恢复与分组目录；内页的重复大流程条改为默认收起的状态指南，覆盖29个页面/页签。未改公开首页动效实现、材料权限、总预算及报告版本规则。

- 初次进入有三种起点，按钮切换带180ms轻微上移过渡；只切换说明和入口，不写入用户目标。
- 待确认/冲突/重复材料、依据变化、受阻和暂停任务分别给出可恢复入口；优先继续进行中的有效任务。
- 首页续读直接恢复已保存章节，不再先跳到资源目录。无真实记录时不堆多个空报告/空任务框。
- 账户与工具收为菜单，支持点击外部关闭、Escape返回触发点；手机导航可展开再收起。
- 主要共用空状态把动作置于步骤前；指南可随时重看。AI页展开指南时允许内容滚动，不挤压讨论和输入区。
- 新增界面文案同步英文；个人内容仍按原始文本保留。没有新增强制教学、模拟完成度或能力评分。

- `npm test`：58项通过，含8项新引导状态测试。

- [工作区页面与交互检查](检查记录/工作区改进_v39/页面检查.json)：10组检查通过；29个页面/页签×1440/1024/390三种宽度均无整页横向溢出，覆盖中文、英文、菜单、起点、草稿、状态与章节恢复。
- [AI指南专项](检查记录/工作区改进_v39/AI指南检查.json)：三种宽度均通过，展开时标题/输入区无重叠，收起再展开保留草稿。
- 既有流程前进与返回、任务编辑/预算/暂停恢复、首页横向拖动、文字浮现的回归记录在 `检查记录/工作区改进_v39/回归/`。保留历史验收图片，回归输出另存本版本目录。
- 旧检查适配：可见标题选择跳过折叠指南的隐藏标题；“先带缺项复盘”按v36当前按钮改为“先整理已有探索记录”。首页轻滚70ms固定帧断言首轮失败（反向已移动34px，期望超过40px），独立诊断确认四次20px可吸附到下一卡，反向最终回原卡。该断言改为300ms内观察实际反向移动，未修改滚动力学实现。
