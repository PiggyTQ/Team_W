# 首页主题停靠与拉扯 v26

2026-10-19。根据用户指出“问题入口”和“从了解工作到成果”是不同主题，本轮将主题间的连续慢滑改为明确的停靠、拉扯蓄力和释放。保留v25较慢的内容切换、过阻尼跟随，以及既有灰阶内容与布局。

## 最终行为

1. 滑到当前主题的阅读位置后，视口停稳；一次大幅滚轮也不会直接穿过下一个主题。
2. 再向下滚动，文档位置保持不动，只对当前画布做有阻力的向上拉扯与轻微伸展。底部提示“继续下滑，进入下一段”，细线展示蓄力。
3. 持续拉扯后释放，弹簧将视口送到下一主题的入口。到位前的同向输入不累积到下一段，避免一次滚动连续跨过多个主题。
4. 到下一主题后重新阅读。流程、十五态成果、十方向展廊的内部仍按连续滚动推进，仅末端停靠。

应用边界：首屏、成果舞台、问题入口、四阶段流程、职业方向、案例引导、学习、AI、报告、开始前说明及结尾。结尾没有后续主题，不设置退出关卡。

卡牌主题桌面停靠时标题、三卡与说明保持可读，下一步释放到流程首节点。长内容允许先滚完尾部再停靠；展开FAQ改变高度后重新计算阅读边界。布局坐标使用offset位置，避免段落进入动画或拉扯位移改变停靠点。

## 力学与门控

- 继续使用质量—弹簧—阻尼积分：普通跟随m=1、k=100、c=30；释放到下一主题时m=1、k=144、c=28，形成明确的过渡。
- 拉扯仍采用`R(d)=56×0.35d/(56+0.35d)`，上限渐近56px、伸展最多1.4%。这些只作用于画布，不让滚动位置逐渐漏到下一个主题。
- 到站输入不计入蓄力。实际停稳后保留240ms阅读缓冲；后续累计输入至少600px、持续至少380ms且至少3次输入才放行。每次输入最多计100px，一次大滚轮不能直接解锁。
- 超过800ms没有继续输入，再滚动会重新蓄力。停止输入140ms后画布阻尼回位，当前主题仍停靠，不自动跳转。
- 向上滚动、键盘、锚点、点击和滚动条操作可以立即中断。弹窗、输入框和内部可滚动区域保持直接操作；内部滚完后只转交剩余输入。
- 手机、窄/矮视口、非精细指针和减少动态效果保持原生滚动。没有在工作区挂载该控制器。

这是用户本轮明确要求的主题停靠，接替v24/v25“阻力增加但位置仍持续前进”的方案；与历史v19每个成果步骤都逐步停靠不同。
