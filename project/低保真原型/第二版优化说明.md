# 第二版低保真优化记录

日期：2026-10-16。直接对照用户指定的《大学生IT职业规划与成长网站设计说明书 PRD3.5》正文及其 13 张结构示意图，同时保留正式 Teal 增补。文档内容作为产品规格，未当作额外操作授权。

## 这次解决的问题

上一版偏重功能编号和可点入口，页面结构过于相似。虽然规则和状态存在，用户不容易从界面理解要求、本人材料、差距、行动和输出的联系。本轮围绕“我来解决什么、当前在做什么、做完得到什么、下一步去哪”调整信息结构，而非扩充功能或替换产品范围。

|原问题|第二版变化|对应 PRD|
|---|---|---|
|首页抽象、首屏主要是黑色占位|五阶段同一案例可直接切换：职业要求 / 我的材料 / 差距与未知 / 本周行动 / 成长报告；三种用户问题作为起点|U01 公开首页及首访成果|

## 范围与兼容

仍是 15 个主模板、27 个视图与原 43 项需求，没有新增产品中心。原路由键和本机存储保持兼容；U04 可见标签按 Word 说明书调整为资料与经历 / 提取与确认 / 职业评估 / 我的画像。模拟登录、AI、解析、分析、检查和管理发布继续明确标识。所有媒体仍使用纯黑 SVG，占位不冒充真实图像；保留统一字重与灰阶，没有装饰动画。

原版文件快照位于 `检查记录/优化前源文件/`。正式 PRD 和原始数据集未修改。按照此前本地原型范围继续在现有目录实施；检查 Sites 后没有现有托管站点，本次未向外发布项目资料。

## 可复核检查

- `npm run build` 与 4 项共享规则测试通过。
- 原有浏览器回归：20 组结果记录，覆盖 15 模板、27 视图以及认证、确认、预算、尝试回流、报告、岗位、AI、反馈和发布阻断。
- 新布局专项：11 组结果记录（含运行时错误捕获），覆盖首页五阶段、目录/详情、独立评估范围、先修分支、项目预检、导航隔离、岗位时间线、AI 草稿、报告读写和桌面/手机。
- 1440px 桌面与 390px 手机对主要页面截图检查。已修复手机职业详情因网格最小宽度导致的整页溢出及搜索按钮挤压；手机端把筛选与比较篮改为可展开面板，先显示目录或职业详情；最后复测无整页横向溢出，未捕获运行时错误。
- 这些结果证明原型交互和所测布局可用，不证明真实用户理解、服务端权限、AI 正确性或就业效果。下一步仍应请学生不带讲解完成任务，观察能否独立理解网站用途和下一步。
