# 首页前后衔接改进 v6

2026-10-17。替代 v5 后半页布局。范围仍为 U01 公开首页与职业展廊出口，不增加正式模板、后台服务或本人数据状态。

本次解决的主要问题：v5 学习、AI、报告各自能操作，但像三个独立功能演示；前半页的卡牌、路径与展廊没有接到一个完整案例。隐私与 FAQ 又重复了说明块布局，结尾像额外插入的横幅。

## 重新接成一段探索

职业展廊的“继续看学习路线”和“跳过方向”现在先进入过渡段：**看过工作，再把疑问变成一次尝试。** 说明接下来以数据分析为例，避免把读者刚看过的任意方向冒称为数据分析。

中段统一为左侧约 1/3 章节路径、右侧约 2/3 内容画布，延续前半页成果舞台的宽度、灰阶底色、纸面、边框、序号和字重。三个章节用同一条案例线连接：

1. **选工具与任务**：以合成数据质量问题为例，SQL 查询与表格工具任选其一，查看用途、产物和限制。
2. **比较时间与方案**：时间问题带入上一段所选工具，播放预录答复，比较缩小范围或延长周期等方案。
3. **留下阶段记录**：同一案例的三个报告片段；行动片段显示所选工具及相应产物示意。

这不是自动生成或更新本人报告。工具选择只改变公开示意；方案按钮只比较解释，不把“看过方案”当作实际计划或已完成行动。所有模拟、资料范围、未知和核验边界继续标明。

三个章节有连续连线与清楚的“接着看 / 回看”入口；左侧目录随正常滚动强调当前章节。数字代表阅读位置，不是本人完成率。没有新增长时间固定段，不拦截滚轮，不隐藏后续内容；可直接点任意章节。读者从顶部导航直接进入某一功能时，仍有案例与工具上下文。

隐私与 FAQ 恢复为同一比例的安静阅读带。结尾移除独立灰色横幅，以路径终点、留白和“轮到你的下一步”呼应开头；可以开始自己的探索、回选三个起点或回到顶部。

## 交互与适配

- 桌面侧目录在视口内保留，随自然滚动改变当前项；离开案例整体区域后自然结束。
- 宽度不超过 1000px 时目录回到内容上方；桌面窗口高度不超过 700px 时不固定，避免目录被裁切。
- 手机为正常纵向内容，保留连接线和每段前后入口，不强制逐屏播放。
- 保留既有局部切换 220ms / 键盘直接切换、减少动态效果 100ms 透明度；结尾 600ms 轻量缩放，减少动态效果静态。章节强调直接更新，没有额外动画等待。
- 示例工具在当前首页挂载期间共用；弹窗取消和章间返回保留。没有新增持久化或跨刷新保存承诺。
