# 项目、材料、评价和变式契约

本文件定义实施必须产出的内容；任务书和模板中的null、false、待核为真实初始状态，不能直接作为已发布教材导入。

## 一项项目包

允许不同目录命名，但应有清楚可追溯的任务说明、输入/字典、脚手架、产物约定、提示、参考、自动检查/量规、来源及完整性manifest。原始输入、摘录/派生/合成、参考结果分开存储。示范和独立任务有不同身份，不能将独立答案默认展示或放进学习侧AI可读上下文。

每项至少包含：业务使用者、目的/约束、主/相关职业、确切技能、前置建议、运行条件、投入估算及是否实测、实际输入、可自主判断处、必须交付的文件或结果、验收方法、失败反例、未覆盖范围、后续路线、维护责任与变更记录。不得要求所有项目都四章、四步、一个视频、两个角色。

完整材料不塞进150行预览表。代码、SQL、HTTP、配置、数据、日志和压缩包按实际类型支持有界上传/下载；校验大小、扩展名/实际格式、文件名、MIME、归属和摘要。若解压，拒绝绝对路径、目录穿越、符号链接和异常膨胀等不安全内容。保留原上传身份隔离和权限。

## 来源记录按具体素材建立

来源记录至少包括：sourceId、发布者、题名、原文URL和实际文件URL、材料类型、已读章节/文件、支持与不支持范围、国家/地区或产品语境、上游版本/tag/commit、原文日期、访问/复核时间、所用许可及URL、适用文件、版权/归属/NOTICE、改动说明、第三方例外和是否可缓存/改编/再分发。

实际素材再记录项目版本引用、包内路径、原始文件名、格式/编码、字节数、SHA256、字段/行数/时间范围、原始/派生/合成/私人材料身份。派生过程记录原输入摘要、脚本版本、筛选/规范化、种子、错误注入和输出摘要。自身计算哈希不冒充发布者签名。

网页已读、权利核对、文件取得、解析、参考复算、实验运行、内容审阅和真人试学分别记录，不用一个verified覆盖全部。

| 权利类别 | 采用要求 |
| --- | --- |
| CC0 | 仍记录来源/版本；数据许可不能套给插画、徽标等 |
| CC BY | 按实际素材保留作者、来源、许可和改动说明，不暗示背书 |
| CC BY-SA | 翻译/派生按适用相同方式共享处理；数据与代码独立，不能改称本站独占素材 |
| OGL | 核实际材料声明、归属和第三方例外；页面声明与完整条款核读分开 |
| MIT | 复制/实质采用代码时保留版权许可；数据/手册/图片另核 |
| Apache2 | 保留适用声明、许可及原NOTICE，修改有记录；依赖与另行文件另核 |
| NC/ND/自定义 | 先核实际用途与改编/商业条件，不能默认翻译后内置或公开下载 |
| 无许可/范围不明 | 保留候选/外链参考，采用原创输入等完整替代；不能用公开可读代替权利依据 |

source-candidates.json仅为候选和边界。实施时访问失败不把状态改“已读”；合法快照、实际镜像与原发布者分开标记。若完全用本站原创合成输入，不编造外部URL或假称真实企业数据；方法参考仍按实际阅读引用。

## 材料必须落盘并可复现

- HTTP成功后检查内容而非仅状态码，拒绝错误HTML冒CSV/JSON；LFS指针不当文件。
- Range片段只能标片段，不能给“完整文件已核”状态。
- 压缩包与实际采用文件分别记录摘要，预览标明筛选规则。
- 旧DfT小样本不替代新的多表材料；UCI/SQuAD前轮内存解析也不证明本实施包已有文件。
- 合法缓存的固定版本可作离线输入；不能再分发则完整自建替代，重做参考，不保留官方原数据标签。
- 首次安装联网与离线运行分别说明。资源/耗时未实测保留未知，不填0。

## 评价契约

每项任务书的plannedDeterministicChecks是应实现的目标，不是已经执行。真正执行后保存检查器、环境、输入/提交版本及摘要、时间、通过/失败/未运行/超时、日志和范围。用户自报运行结果另标，不自动签发平台独立验证回执。

数据可核字段、主键、关联基数、逐行/汇总和内容对照；程序/API可核指定输入输出、权限、边界、重试与故障；界面核实际流程、状态和键盘；规则核实际时序和数值；文档核证据链接、版本、可重复操作及已知结果。没有运行能力时公开其检查范围，不显示伪成功。

开放部分用可观察量规，例如问题与产物是否对应、证据支持到哪里、选择及替代方案、未验证范围、接手者能否使用。评价要指向产物位置；关键错误不能靠平均分掩盖。本人贡献、AI帮助和模拟协作如实记录，不由语言流畅程度推断能力。

参考计算要独立复算或执行。每项至少一个代表失败输入；每种适配器至少走正确、错误、缺项、修改后重评与过期评价。SQuAD类型先检预测ID集合完整；外部公开测试不当作未泄漏独立检验。

不要求任意在线代码沙箱；采用本地材料/测试时提供真实可运行包、精确命令与依赖，实施者先复现。若平台实际执行用户代码，应放隔离环境并设资源与网络边界，不在业务服务权限下直接执行。

## 受控变式契约

变式要记录parentProject/version、实例ID、规则版本、允许参数范围、种子、输入/期望/检查/量规摘要、相对原任务新增的判断、可复用产物和独立性范围。参数合法还不等于业务合理；应验证可满足要求、参考生成器一致、负例确实失败。

至少制作三个实证家族：

1. 数据：新增重复/冲突或一对多关联，两个有效参数组合能复算；导致无法定义唯一统计对象的未处理组合应拒绝或明确要求澄清。
2. 代码/API：重复请求、库存/占用和并发约束，验证效果与测试；违反业务边界的参数或身份组合明确拒绝，不能仅随机改数。
3. 配置规则：阈值、持续窗口及请求范围的教学参数，两个有效时序与一个非法规则组合。数值仅为合成情境约定，不宣传通用生产阈值。

其他项目具备可维护变式说明，可后续拓展。AI超出已审规则提出新任务/事实/材料时进入待审队列，不自动发布或静默改现有实例。

## 依赖与成本

每项目明确浏览器/文件离线/本机CLI/隔离容器/外部服务方式、版本/锁依赖、安装和运行联网、已知内存磁盘、账号/租户/组织权限/密钥及可能计费动作。默认提供不依赖付费模型/云的可用路线。低配置证据包必须真实齐全，并说明只能验证什么；合成轨迹不称真实采集。
