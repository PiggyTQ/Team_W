## 问题与实现

原三个入口只对同一张六行表排序，选中的行挪到顶部并改变背景。用户无法从内容或版式分清三个层面。本轮改为真正的三个内容面板：

| 层面 | 当前具体比较 | 呈现方式 |
|---|---|---|
| 工作方式 | 本例问题与输入、处理步骤、关键判断、复核与协作 | 双方同维对齐，步骤路线、输入块与复核区分层 |
| 交付成果 | 原案例第一份实际产物、使用者、用途、验收及其他产物 | 文件头与原表格／代码／简报预览；验收独立对照，不只罗列名称 |
| 入门实践 | 材料、小任务、预期小产物、检查方式与同例入口 | 材料清单、步骤、产物区及实际实践链接 |

六行泛化摘要不再在三个面板反复出现。双方表头标明职业、代表案例与A/B；维度索引、任务正文、文件内容和来源说明使用不同层级。保留当前暖白／浅蓝／深蓝／黄色品牌、角色与全站导航。

## 业务与资料边界

- 继续保存原`work / outputs / starting`关注点，沿用`taskInputDiscussion`处理授权失效；双方选择及交换仍走`chooseComparison`，保留职业组合对应的原讨论。
- 只读取本次`items`提供的双方`publicContent`。只读本地化，不按职业ID另取最新版，不改来源stamp或旧资料版本。
- 旧版本缺少实例结构时保留原摘要／产物名称，不用新版产物补齐；缺一方、同一职业或资料缺失时不显示完整双向矩阵。
- 同例体验链接固定为`/careers?career=ID&section=practice`。相关技能课程是另一套练习，不能冒称同例。本页不标记技能掌握、不写入目标，也不默认选入私人材料。
- 原产物预览来自已有公开教学案例；不新增虚构经历、适合率、能力评分或就业保证。入门面板不展开未请求的教学对照正文。
- 历史、本人笔记、新讨论与原问题输入保留，未改后端协议、预算保护或费用账本。
