### 达标时序

| 阶段 | 实际时序 | 行为 |
| --- | --- | --- |
| 水纹 | 0–310ms | 靠根的浅溪中两圈轻微水纹，随后消退 |
| 传导 | 80–570ms | 柔和拖尾短亮线沿根、主干及目标枝条走，分叉只走该目标路径 |
| 芽苞舒展 | 540–800ms | 原芽苞保持到光抵达附近再舒展消退 |
| 双叶展开 | 560–890ms | 两片新叶从自己的叶柄位置展开，附近短枝逐渐泛绿 |
| 单芽反馈结束 | 980ms | 临时光线移除，双叶和通过状态保留 |
| 整枝返绿 | 900–1280ms | 最后一芽展开后，目标枝从与主干连接处向枝梢返绿 |
| 整枝叶簇 | 980–1500ms | 同枝最多五簇，按 65ms 间隔从各自叶柄处展开；其他枝不动 |
| 整枝反馈结束 | 1550ms | 临时反馈移除，已长出的叶簇保留 |

只有服务端确认的首次通过才入队。检验位于树下，反馈等待树重新进入视野才播放，避免在屏外消耗；队列及去重限制同一达标重复播放。重复回到树上、刷新、重新进入或切换职业，不因已保存的进度重播。启用减少动态效果时直接呈现最终状态。
