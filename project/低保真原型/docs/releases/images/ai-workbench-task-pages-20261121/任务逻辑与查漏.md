## 页面与共用能力

以下路径是**设计建议**，尚未登记为实际可用路由：

| 入口 | 页面职责 | 首要行动 |
| --- | --- | --- |
| `/assistant` | 自由提问、跨模块梳理、已有讨论续聊 | 直接输入问题，或进入下列任务页 |
| `/assistant/next-step` | 澄清近期目标、时间取舍与任务优先顺序 | 选本次要推进的事情和相关原任务 |
| `/assistant/compare` | 理解两种职业的工作差异与个人取舍 | 明确比较双方和最关心的问题 |
| `/assistant/expression` | 把一个实际产物的事实、贡献与限制讲清楚 | 选一个产物，说明用于何处 |

三页共用现有讨论、来源解析、上下文授权、近期问答、笔记、建议身份、绑定草稿、版本/事务/幂等和失效保护；不共用满屏泛资料目录。后续实施须登记路由、标题、导航与恢复逻辑，验证直接访问、刷新、浏览器前进/后退和旧 `/assistant` 链接。

任务页的准备区简短、明确；开始对话后缩成可修改的对象摘要。不要把第一页做成另一个大表单。历史、本人笔记、新讨论与返回自由聊天保持可达。

## 梳理我的下一步

### 首屏

显示当前主目标或“尚未确定”，让用户写清本次想推进的事情。时间采用**本次讨论的假设**，例如“本周可投入多久／还没想好”，不能默认改写账户每周预算。本人尚未提供时间时保持未知，不能填0或从“本科在读”推断可用时长。

用一到三张相关原任务卡选择讨论对象，显示任务名称、当前状态、预计投入和已记录截止日期；未记录的字段清楚留空。可通过“换任务／再选一项”查看其余任务，不首屏列出全部课程、技能稿、复盘和报告。相关性筛选必须有可解释依据，不声称已读全账户或已为用户选定优先级。

### 流程与结果

当前目标＋本次时间假设＋一到三个相关原任务 → 对话澄清困难和优先顺序 → 比较继续、缩小范围、延期等取舍 → 用户选择具体建议 → 复用现有绑定稿 → 原计划页编辑、影响预览、本人确认。

聊天只展示必要建议与原因、采用后的主要影响及原页入口。预算、目的/范围、状态、日期、依赖和保留任务的正式核对继续使用既有原业务页。周/月/年目标、日历时段与自动重排整周不在本页实现；本次假设只有经过原计划确认才成为正式预算或任务改动。

### 空状态

- 没有目标：允许先描述困惑，或进入职业比较；不默认指定数据分析。
- 没有原任务：可以聊清第一步，提供“到目标计划安排第一项行动”。现有讨论草稿 API 调整的是原任务，不能把它画成已支持创建首个任务。
- 时间未知：追问或允许暂不确定；没有可靠预算就不宣称已完成预算内排程。
- 任务受阻或依赖未完成：先展示当前事实与待澄清项，不擅自开始、恢复或完成任务。

## 比较职业方向

### 首屏

左右两个明确的职业选择位 A/B，使用当前十职业目录。下方是一个关注点输入或少量可选关注点，例如日常做什么、产物是什么、核心方法、工作条件、学习起点。本人确认材料和偏好是可选补充，不作为查看公开职业差异的前置门槛。

双方选择完成后，先呈现少量同维、可读的公开差异，附真实来源入口，再进入围绕关注点的对话。不要用技能节点数量、无依据分数、适合/不适合标签代替比较。

### 流程与结果

A/B＋关注点 → 同维公开资料比较 → 对话澄清个人取舍与未知 → 留下候选方向、要验证的问题和一个可自主探索的入口。

结果可去职业详情、对应技能树或原目标页；仅查看或保存讨论不修改主目标。用户在原目标页明确决定后，才沿用原流程变更目标。没有本人材料时仍可比较工作本身，不给个人胜任率、录用概率或能力判断。

### 空状态与资料缺漏

- 两方都未选：显示职业选择和搜索，不预填一组假比较。
- 只选一方：保留该方，另一方显示“再选一个职业”；不得推断用户想比较谁。
- 两方相同：就地提示换一个，保留已输入关注点。
- 某维没有可靠资料：明确“该项资料待核对”，不能用另一职业或通用模板补造。

当前 `server/agent/discussion-context.mjs` 第17–22行的职业投影主要是技能分支与课程。新比较页需要进一步复用现有职业详情中的日常任务、流程、典型产物、环境及出处，并核对这些字段能否在同一维度对照；这是需要补充的资料投影，不能假定当前 `career` 来源已具备全部比较内容。

## 整理成果表达

### 首屏

先选一个项目、任务产物或已有确认经历，以一个对象卡合并呈现已有名称、状态、产物原文、本人贡献和局限摘要。用户可改选对象；不把同一项目的 `output`、`contribution`、各步骤等底层片段平铺成多个同名复选项。

说明用途，例如项目回顾、简历或面试，并写一句最想讲清的问题。用途用于组织措辞，不启动第二个简历编辑器或报告编排台。用途状态属于后续需登记的任务页状态，不能未经校验直接塞入现有严格契约字段。

### 流程与结果

单一产物＋主动选定的贡献片段＋用途 → 核对实际做法、观察到的结果、本人贡献、辅助方式与未知 → 对话与表达草稿 → 用户选定草稿 → 原个人评估形成待确认候选并本人确认 → 原报告/简历页面选用。

表达须保留原文依据和限制，不能由“过程有记录”推断项目完成，也不能把团队总成果都写为本人贡献。已经确认的材料可以用于措辞讨论；需要改事实时回事实源，不在聊天里覆盖原确认记录。

### 空状态

- 没有产物：提供记录已有经历、继续当前项目的入口，允许先描述实际做过的事。
- 没有本人贡献：明确追问负责哪部分，不凭项目名称补写。
- 作品尚未完成：可以整理阶段性进展和未验证部分，标题和结果保持“进行中”；不生成“已交付／已达标”文案。
- 只有作品标题、没有正文：提示补充可核对原文，不把标题扩写成真实经历。

## 来源按对象组织，授权按必要片段生效

选择器的第一层是具体任务、作品或比较双方。选中对象后展示必要内容摘要及本次实际选用的片段，用户可以取消某片段、查看原文、换对象或增加确有必要的补充。

对象聚合只改变呈现，不改变读取范围：选一个项目不等于自动选中其全部 `part`，更不等于外发授权。继续保持最多12个实际引用，明确聚合卡对应的片段与数量；超过限制须让用户取舍，不能隐式截断。公开职业依据与私人作答、贡献、复盘分别辨认。

站内选用和外部处理继续分开授权。外发前明确本次选中的对象/片段与同主题近期问答，沿用现有指纹、最多六条必要问答、取消/晚到保护。正文、私人问答及全部来源内容不进入 URL。

普通阅读不靠多层 `details` 导航。来源可用一个“查看选用内容”面板，内部按对象列出片段；真正低频原文仍可按需展开，但不能通过嵌套折叠把选择对象这个核心动作隐藏起来。

## 状态与链路查漏

| 情况 | 必须保留的行为 | 设计中不能暗示 |
| --- | --- | --- |
| 模型关闭 | 选对象、读真实资料、保存问题、站内资料核对与原业务入口仍可用；说明 AI 当前未启用 | 固定规则正在理解自由问题、预录答复是真实模型分析 |
| 模型开启但未授权 | 保留问题，提示核对本次范围；不扩大旧授权 | 进入任务页已同意发送全部对象 |
| 没有数据 | 给本任务的具体下一步；允许暂不确定 | 空值为0、无材料等于不会、虚构待办或完成成果 |
| 来源修改、撤回或删除 | 相关回答、笔记、授权、草稿按实际依赖失效；旧稿保留原来源标记 | 旧稿可继续默认挂到新对象，旧正文仍有效 |
| 任务切换 | 三任务独立状态和会话身份；保留未发送问题，不把另一任务的来源/草案带过来 | 只改意图标签就完成任务页切换 |
| 草稿恢复 | 按账户、讨论、来源指纹、原对象与版本恢复，标明有效、失效或已应用 | 刷新会重写原计划、自动确认候选或重复应用 |
| 只选一个职业 | 保留已选方，等待补另一方，允许继续了解单方 | 自动猜测另一职业或生成双向结论 |
| 无贡献或未完成作品 | 追问实际负责部分，阶段成果保留状态与限制 | 项目完成、独立能力认证、虚构数字 |
| 私有任务路由 | 登录/账户读取完成后才能恢复私有会话与对象；失效/越权标识有清楚恢复入口 | 直接访问或刷新绕过鉴权，猜ID能读他人资料 |
| 预算/时间未知 | 本次假设与账户预算分开，待确认才应用 | 从学生身份推算时长，未知自动填0 |

还需在后续实施时逐项确认：浏览器后退回到原选择与对话；直接访问三个新路径可恢复页面；历史会话从原入口仍可打开；改选对象后的草稿与来源失效行为一致；中英文切换不改用户原文；长名称和多片段不挤压主要输入区。

## 可复用与需新增的边界

**可复用：**现有 `plan/direction/expression` 意图、同对象会话复用、来源指纹与授权、建议身份、绑定草稿、原业务页编辑/影响预览/确认、本人笔记与历史管理、学习现场 Tutor。当前 `DiscussionWorkbench.jsx` 第78行已有有效建议形成草稿，第81行已有草稿回原业务页入口；不能为分页面丢掉这些链路。

**需新增或调整：**三个任务页的实际路由与导航登记、各自准备区/空状态/对话上下文、对象聚合选择、本次时间假设与表达用途的可靠状态归属、公开职业同维资料投影。具体契约扩展应在后续实施时审阅，不在本轮假称已实现。

**继续留在原业务页：**新建首个正式任务、完整任务编辑、具体时段与周期目标、经历事实确认、报告/简历编排和导出、练习执行与最终检验。独立 AI 三页负责把问题与建议交接过去，不吞并这些功能。

本轮只完成源码和交接的只读设计分析以及本文件。未运行网站测试、构建、浏览器或真实模型；历史验证与发布记录均不冒称本轮实测。
