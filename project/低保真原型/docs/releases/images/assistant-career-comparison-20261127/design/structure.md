# AI职业对照三层：实施前结构

本文件与structure.svg是待实现结构，不是网页截图。用户参考01指出三个入口只有排序变化、正文相似、表格无视觉层级。

保留双方选择、交换、原work/outputs/starting状态和讨论身份，改为真正的三个可切换内容面板：

1. 工作方式：代表任务的问题与输入、具体处理步骤、关键判断与复核、协作。
2. 交付成果：第一份原产物的表格／代码／简报预览，交给谁、解决什么、验收看什么；其他产物为次级清单。
3. 入门实践：给定材料、具体小任务、预期小产物与检查方式；链接同一职业的同例体验，不冒称技能检验。

视觉：沿用站内浅蓝任务头、暖白工作纸、黄色重点。双列职业表头明确A/B、职业及本例范围，左侧维度标签形成对齐索引；流程、文件预览、实践清单使用不同结构，避免单一段落矩阵。

数据：只使用本次items提供的双方publicContent投影；本地化是只读展示，不按职业ID另拉最新版本。两方或资料缺失时保持明确空态。来源版本／出处继续可查，个人材料不默认读入；不更改目标或能力判断。

验证：本机演示与临时账户；两方选择／交换、三层内容差异、键盘、刷新恢复、资料及讨论隔离；中英文1366／1616／2560桌面和实际产物可见性。
