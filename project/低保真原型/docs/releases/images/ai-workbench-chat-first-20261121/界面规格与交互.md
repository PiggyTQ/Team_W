## 01 自由聊天初始态

核心文案：
- AI 工作台；历史讨论；本人笔记；新讨论。
- 和芝识分子聊聊
- 从一个问题开始，一起理清方向与下一步。
- 说说你现在想理清的事…
- 本次资料
- 梳理我的下一步 / 比较职业方向 / 整理成果表达。
- 资料由你选择，建议由你决定是否采用。

起点只形成可修改的问题或打开必要上下文选择，不默认发送、扩大资料范围或强制新建主题。自由提问始终可用。跨技能学习问题可直接问，不另加学习中心。

资料按需展开可读目录，优先当前对象，最多12项；可查看原文和来源位置，不直接铺JSON。比较职业时明确选择双方，保持双方资料校验。

## 02 按需总结与后续建议

由用户主动请求后产生，不在每次进入时自动读取全账户、诊断短板。

“已经有的”只描述材料确实支持的产物或有效检验范围；“还需澄清”区分未记录、待确认、练习受阻、冲突；“可以先尝试”给2—3个具体选项。

图片中“项目里的本人贡献还没写清”，实现时优先写：
**“本次选中的资料尚未写明本人贡献，可以先补充说明。”**
不能推断用户没有贡献或全账户从未记录。

依据可展开原文；存为笔记不改事实。追问只是可选动作，发送遵守真实状态。需要行动时，相关回答下才出现一张草稿摘要，绑定具体建议、原对象、来源版本，标记尚未应用。

复杂编辑交回原计划、个人评估或报告/简历页；普通问答不常驻结果工具。没有真正生成草稿时，不能用预录数据假装完成；手工整理须如实标注。

选A起稿再换B，旧稿保留A来源及失效说明，不默认挂B；服务端同样拒绝错误来源。确认前展示所有实际写入字段差异，包含范围/目的。成果只形成待确认候选，本人确认后进入原报告/简历链路。

## 03 学习侧栏

- 实践页不显示树；原材料、编辑区、执行、保存、复核和主动检验保留。
- 侧栏参考宽360—400px，展开时重新分配主区，不遮代码或按钮。
- 标题芝识分子；当前：SQL 表关联 · 独立任务；展开讨论；关闭。
- “你已附上：作答、实际输出”仅表示用户主动选入本次上下文，**不等于外发授权**。
- 首次给操作线索，不给最终修正SQL或未公布检验答案。“再讲一点方法”“如何自行核对”作为自然追问。
- 展开独立讨论复用主题、对象与必要问答；返回恢复同一稿、阶段、模式和位置，晚到结果不能写入新对象。
- 检验时复用已有答案保护，可关闭或限制辅导，不从评分数据泄露未公布答案。

### SQL设计示例语义

orders：K=50、L=50、M=20；lines：K=12、K=8、M=5。

```sql
SELECT o.order_id, o.order_amount,
       l.line_amount
FROM orders o
LEFT JOIN lines l
  ON o.order_id = l.order_id;
```

实际结果应为 K/50/12、K/50/8、L/50/NULL、M/20/5 共4行。查询可运行，但不符合“每单一行”，故本题检查需要修正；这不是运行失败。

**图中的“进入检验”只定位入口，不决定其可用状态。** 本例未完成独立核对与复核时，按既有门槛禁用或就地解释缺项，不允许绕过。运行、保存和最终检验为原动作，AI提示不自动改稿或授叶。

## 图外必须补齐的真实服务状态

| 状态 | 行为 |
| --- | --- |
| 模型未启用/账户未开放 | 一次轻量提示“AI 暂未启用，问题可保留”。模型发送不可用，允许写/保存/恢复问题，打开真实站内线索或资料。固定规则不能冒充理解问题的聊天。 |
| 已启用但尚未授权 | 输入可写，发送时就近完成必要确认，不默认外发。 |
| 请求中 | 显示真实状态与取消，保留问题。 |
| 失败/取消 | 输入、附件、原稿保留；取消后晚到不回写。 |
| 来源变化/撤回 | 按依赖使旧回答、笔记、草稿、预览和授权失效，保留历史位置但不泄露受限正文。 |
| 草稿预览 | 明确尚未应用，只有本人确认才调用业务服务。 |

黄色箭头仅确定视觉样式，不代表当前模型已开放。本轮未测真实回答质量。可由确定规则可靠产生的资料概况需标为“站内资料概况”，不冒充模型推理。

## 桌面与输入

- 1700/1920px允许材料、作答和侧栏并列，代码需保持可读。
- 1366px压缩空态角色高度，材料可收起或移到作答上方，适度收窄侧栏；不硬挤三列再缩小字体。
- 沿用主阅读滚动；侧栏消息可滚动、输入固定底部，不让每个材料块形成多层滚动。
- 中文输入法组合时Enter不发送；Enter发送、Shift+Enter换行，取消与图标按钮有名称和键盘焦点。
- 英文扩展、长来源名、长代码不溢出；本人原文不随语言切换改写。
- 本次不做移动端设计或验收。
