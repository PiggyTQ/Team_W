# 职业详情章节层级：实施前结构

本文件及structure.svg为待实现结构，不是实际网页截图。参考本轮用户截图，以及站内分支学习、综合项目工作区和报告的已有视觉。

问题：代表案例的主题、范围、导语、问题、输入、判断、复核均接近同级正文；右侧大表与左侧裸文不平衡。其他章节也缺少“当前主题／工作内容／产物／后续操作”的视觉差别。

设计：保留现有暖白／深蓝／浅蓝／黄色、图标、1440px正文边界和六页签。每章以紧凑的浅蓝任务头确立主题；正文按用途选择不同版式，不把每段都变成同款卡片。

- 全貌：工作路线为主，分工说明为次，职业边界在浅蓝旁注。
- 案例：一个主题头＋任务简报工作纸（委托方／问题／输入）＋产物预览；判断与复核另有独立区域；完整产物以文件页展示，右侧为使用与验收。
- 准备：技能连接具体工作，再用独立质量区域说明需要观察什么；本人依据另列，不作能力评分。
- 成长：责任变化路线、协作交换清单、环境与常见错误，避免平铺成同级段落。
- 体验：输入与任务、预期产物与检查、材料与本人工作稿、下一步行动分层。保留原保存／清空／撤销／对照及本机恢复。
- 来源：发布者与范围在摘要可见；正文、日期、权利说明分组。原来源ID、URL、版本和核读状态不改写。

本轮仅展示层重组；没有增加职业事实、虚构结果、外部服务或生产操作。
