## 设计依据与实际状态

依据 `images/ai-workbench-chat-first-20261121/` 内的还原实施提示词、界面规格、链路复核及三张独立效果图实施。`concepts/` 仍是设计阶段生成图，`actual/` 才是本轮隔离环境的真实浏览器截图。两者不互相替代。设计阶段的静态复核作为历史依据保留，不将其未执行状态当作本轮结论。

页面遵循同一暖白、浅蓝、深蓝、黄色和既有角色：正文最大 920px，独立页以问题输入和对话为主，顶部保留历史、本人笔记及新讨论。意图、职业和资料放在按需打开的“本次资料”内，普通岗位筛选继续归职业探索，旧查询链接保留迁移。

学习侧栏使用同一个讨论组件，宽度 380px，1366 桌面宽度降为 360px。练习材料排列在作答上方，保留独立的编辑、运行、保存与最终检验。侧栏内部阅读与输入分区，长资料不再把输入框挤出视口。单课最终检验阶段不开放助手，不发送未公布答案。

## 四项原功能缺口的处理

| 原缺口 | 本轮处理 |
| --- | --- |
| 建议没有真正形成草稿 | 模型的具体建议可以携带严格限定的计划/经历草稿字段。服务端校验对象范围后签发建议身份；点击该条建议才转换草稿，随后跳到原计划或个人评估编辑、预览与确认。没有结构化建议时不会假装已生成，可显式选择从原记录手动起草。 |
| A 草稿跟着 B 资料走 | 草稿在原有建议表保存，绑定账户、讨论、来源指纹、具体建议和原对象。切换来源、修改、撤回或删除后只保留标识清楚的旧稿，拒绝继续保存/预览/应用。回到未改变的 A 可恢复；改变后的 A 仍失效。旧 `workbenchDraft` 保留只读回看，不自动迁移为可信绑定草稿。 |
| 范围未进入确认区 | 原任务影响预览明确列出范围原文前后变化，以及工时、日期、状态、预算、保留任务和依赖。普通任务编辑器也补充标题、范围、日期和补充交付说明的预览。 |
| 固定提示冒充聊天回答 | 外部模型关闭时仅保留问题，不生成助手消息。“资料概况”和分层“本步提示”为显式站内动作；旧规则消息及检索回退标明来源。 |

草稿不会自动写入业务。预览仍通过既有任务依赖、预算与规范化校验；应用检查工作区版本、草稿版本、来源和十分钟预览有效期，使用原有事务及幂等回执。经历应用只形成待确认材料，不形成完成、能力结论或长叶。

## 业务衔接

- 同一讨论只带同依据最近六条必要消息；建议作为未确认文本发送，不提升为事实。无附件的自由问题不读取个人记录，仍需本次范围及外部授权。
- 当前技能、练习模式、项目步骤、显式选择的作答/输出/复核等沿用原身份和来源解析。来源正文不进 URL；草稿链接只有不透明身份。学习原稿、模式、章节位置和返回滚动位置保留。
- 四个项目保留公开本步提示，原独立问答接口从现场界面移除，改由共享学习侧栏展开同一讨论。原步骤作答与保存逻辑保留。
- “本次资料”选用与外发授权分开；资料改变、撤回、账户切换、取消与晚到响应仍受上下文保护。
- 来源以可读段落、字段或实际输出表格展示，不再向用户展示序列化 JSON。本人原文不随语言改写。

## 本轮实际验证

使用临时 SQLite、隔离合成账户和本地注入供应商。没有调用真实模型或生产数据；测试供应商产生的回答只证明请求、关联与业务链路，不能作为真实模型质量或真实职业建议的验证。

| 场景 | 已实测链路 |
| --- | --- |
| SQL 受阻 | 原始 SQL 实际运行得到四行且需要修正 → 主动选择作答与运行输出 → 站内分层线索 → 展开同一讨论并连续追问 → 返回原稿修改 → SQLite 运行三行并完成复核 → 原技能检验先失败后通过；辅导不授叶。 |
| 每周三小时 | 选原目标与两个原任务 → 注入供应商给出可编辑具体建议 → 选中建议 → 原计划页展示范围前后差异和预算 → 本人确认 → 原任务身份保留、各为 1.5 小时，无新增副本；刷新显示回执。 |
| 成果不会表达 | 选产物与本人贡献 → 具体建议形成绑定候选稿 → 原个人评估页编辑与确认预览 → 新材料仍待确认 → 原确认命令确认后进入报告，简历原有可用材料模型才接纳。 |
| 其他 | 四个综合项目步骤往返同一讨论；非 SQL 决策表提示分层；输入法 Enter 不提交；关闭侧栏回焦点；无模型问题保存和刷新；英文 1366 桌面不横向溢出；旧检索链接迁移。 |

- 相关测试：**103 / 103 通过**，包括 A/B 切换、来源修改和撤回、草稿编辑冲突、特定建议重复转换、原任务幂等、有限追问、取消、账户/授权变更、晚到响应及原技能成长规则。
- 全量测试：**534 项，530 通过、3 失败、1 跳过**。三个失败均在既有 `agent-budget-integration.test.mjs`，原因 `AI_BUDGET_PRICE_EXPIRED`；与本轮草稿/页面修改无关，保持费用保护原样，未删测试或放宽价格有效期。
- 双语完整性与服务模式构建通过。保留现有大包体积和登录资源静态/动态同时导入警告。
- 界面机械检测：0 项反模式；35 项提示为当前全局旧设计文档与本次指定的颜色、圆角、字号差异。本轮界面附加规范记录在 `DESIGN.md`，没有为消除提示更改全站设计或关闭检查。
- 实际桌面尺寸：中文 1700×1100、英文 1366×960；未检查移动端。

可复现检查：`checks/ai-workbench-chat-first-20261121/desktop.mjs`。日志、测试结果和桌面几何/字号记录也保存在该目录。

## 关键实现与剩余边界

前端：`src/DiscussionWorkbench.jsx`、`LearningDiscussion.jsx`、`DiscussionDraftReview.jsx`、`TaskArrangementFields.jsx`；接入 `main.jsx`、技能学习、四项目和普通任务编辑器。后端：`server/agent/discussion-drafts.mjs`、`discussion-workflow.mjs`、`discussion-context.mjs`、`service.mjs` 与鉴权后的讨论接口。

目前仍不做自动整周排期，不会把自由文本猜测成业务写入；未提供结构化建议的回答只能讨论或存笔记。真实外部模型效果未测试，线上仍保持原状态。费用定价快照更新、真实模型试用和生产发布均需另行授权与有效外部条件。
