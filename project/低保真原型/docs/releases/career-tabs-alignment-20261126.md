# 职业探索：统一对齐、机会内容与横向章节

2026-11-26。本轮在现有 dev 工作区继续修改；保留其他账号的未提交工作。仅本地实现和验证，未部署、提交、推送或操作生产账户。报告V2仍为撤回状态。

## 本轮实现

1. **机会页对齐**：标题、四模式导航和正文改用同一最大1440px居中容器。空态和已有机会不再单独左侧限宽，解决宽屏留白失衡及标题错位。
2. **统一模式导航**：职业方向、比较、企业与岗位、我的机会始终放在共享标题行右侧。比较页不再把导航作为独立左侧节点。非法职业参数仍展示带标题的列表。
3. **机会页增加实际内容**：可见的原创岗位原文，示范如何读出交付物、区分必要／优先要求、留下尚未明确的条件。明确标为非在招示例，不写入本人数据；添加研究卡、浏览岗位及整理本人材料均连接原功能。
4. **职业详情横向切换**：六个标题等宽分布在一行，只有当前章节可见。复用现有报告的飞机指示器，指示器250ms横移，正文180ms轻微横向进入；快速反向会取消旧动画。减少动态或键盘操作不做位移动画。原报告组件的默认行为保持。
5. **连续阅读与草稿**：URL保存当前章节；来源链接切到来源页并展开／聚焦条目。旧产物与实践hash、刷新、前进后退及非法章节均处理。所有章节保持挂载，以hidden控制，体验输入、保存队列和撤销状态不会因切换而卸载。

不改职业公开资料版本、技能成长、目标确认、材料确认和预算规则；新增示例是站内原创教学内容，不是招聘事实或本人经历。
