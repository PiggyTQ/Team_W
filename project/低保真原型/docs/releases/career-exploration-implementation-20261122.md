## 实际交付

列表保留搜索、候选来源与方向分组；详情不再占用局部筛选列，保留全站导航。每个职业首先说明主要工作、典型产物与协作，再展开同一案例的输入、处理判断、复核、具体交付内容、能力准备、责任成长、难点和小体验。关键案例和产物默认可见，许可及SQL全文按需展开。

收藏、比较篮与目标确认独立。返回列表恢复关键词、来源、分组、正文滚动和原卡片焦点；直接访问、刷新、后退和非法参数有回退行为。详情可加入、移出、打开比较，不依赖筛选栏。目标仍走原预览确认服务，不由阅读或比较自动修改。

合计10条独立任务链、22份有内容的原创产物预览。各小体验给出输入、具体操作、预期产物和检查方式，链接现有同职业技能节点；数据分析另可继续完整数据质量项目。阅读和本机演示不会发放掌握或创建任务。

数据分析使用603条原创合成原始记录，按registration_id最新状态去重，排除测试与撤回，再按注册日期和渠道计数。SQL实际执行和前端汇总一致：4月官网160/社群100/短视频60，5月120/100/60，总计320→280，减少40条、12.5%。单位是报名记录而非独立人数；没有访问量、转化率及采集核对，不能认定原因。
