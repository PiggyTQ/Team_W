## 资源中心

让内容与页面标题使用相同左右边缘，解除嵌套的1280px居中限制。浅蓝与奶油黄的横幅包含简短引导、现有笔记本角色插画和真实目录数量。筛选作为独立的紧凑工具条。职业路线用三张带编号、阶段、产物与入口的项目卡串起；跨职业项目以独立卡组呈现。沿用Roundline图标，白色卡面、细暖边框、深蓝标题与黄色主要行动。全方向仍按职业分组，保留现有筛选、继续任务、来源和本地试用状态。

宽屏利用工作区可用宽度；较窄桌面按容器实际宽度降为两列，再降为单列。只扩大布局，不无限拉长正文。没有真实学习进度时不绘制伪进度百分比。

## 项目详情与实践

顶部为项目标题、简短情境、阶段/估时/状态；其后两栏主次约为2:1，主栏说明任务和交付，辅栏放下载与开始操作。使用输入→制作→核对的流程提示，让用户清楚材料与答案不同。估时是编辑对学习、实现、调试和整理产物的预计投入，不是JSON阅读时间或自动计时。

原“本次完整输入”是固定练习数据/测试情境，改为“练习材料”，先显示可读摘要及用途；原始JSON按需展开，保留字典、原文件与完整包下载。说明用户需要填写或导入requiredFiles中的产物，并从任务书/起始文件开始。公开参考另设入口，明确它是参考答案。

实践区保留编辑、导入、隔离预览、草稿、检查、提交、自检与归档。解释每种文件用途和检查结果，区分文件存在/格式、固定输入的结果值核对、本人本机执行、人工或真实浏览器检查；不可将源码非空或HTML结构检查宣传为程序执行通过。检查失败需能定位待改文件；修改后必须重新检查。旧四项目只调整页面宽度与比例，不改变其任务/版本/证据规则。
