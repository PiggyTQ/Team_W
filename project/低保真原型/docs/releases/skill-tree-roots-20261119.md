## 用户本轮明确要求

1. 先呈现 GPT 生图设计，用户同意后再还原到 web。
2. 保留原树轮廓、枝条走向和节点位置。原页面的账户技能进度继续作为唯一数据来源。
3. 单节点首次达标：可先在水边播放一圈浅水纹；带柔和拖尾的短亮线从靠水根部出发，贴根、主干及目标枝条的曲线运动，分叉只进入目标路径。抵达后芽从叶柄处向外展开一两片嫩叶，邻近枝条逐渐泛绿，亮线消退，新叶保留。总时长约 0.8–1 秒。
4. 整枝达标：先展开最后一枚芽，再从该枝与主干连接处向枝梢逐段返绿。叶簇从各自叶柄位置分批展开，方向随枝条错落；其他枝条维持状态，完成后保留新叶簇。包含单芽过程的总时长约 1.3–1.6 秒。
5. 每次达标仅播放一次，平时静止；保留现有减少动态效果支持。

## 第二版提案：粗壮枝干、自然芽苞、渐进草地（2026-11-19）

用户反馈：询问初始铺满绿草或随树逐渐变绿的取舍；认为现有枝干不够粗壮，枝头水灵珠不协调，要求更好的设计。此反馈允许调整枝干厚度及节点造型；原四主枝走向、分叉关系和节点位置仍保留。

- [第二版 GPT 生图效果图](images/skill-tree-roots-20261119/concepts/02-robust-tree-buds-preview.png)；[完整提示词](images/skill-tree-roots-20261119/concepts/02-prompt.txt)。以第一版预览和原 ash-tree 素材为参考，使用内置 image_gen 工具生成。第二版同样为**待用户确认的设计提案**，不是网页实拍或已批准资产。
- 加粗重点为根盘、主干、四条主枝及其衔接处，细枝自然收尖；提示词建议主干加粗约 22–26%、主枝约 30–35%，这些是设计意图，不是图像测量结果。
- 助手推荐以顺枝梢方向生长的合拢叶芽代替球形玻璃珠：低饱和青灰/鼠尾草绿芽苞、短叶柄与枝条相连；未达标保持合拢，达标后从原处展开一两片叶，整枝完成才增加错落叶簇。该方案尚待用户审美确认。
- 助手推荐地面随累计达标逐渐变绿：初始少量草芽，土壤和溪流清楚可见，后续增加草丛与苔色，最终仍有裸土、根部和水面留白。用户当前是在询问取舍，并未最终选择渐进草地；不得将此建议当成已批准实施要求。

- 本地源码 `.skill-map` 最大宽度 1400px；`.skill-growth-stage` 与桌面枝名层最大宽度均为 980px，原舞台比例为 1835/1074。
- 原树素材在舞台中占 1635/1835 宽，因此 980px 舞台对应约 873px 的素材图片框，去掉素材透明边缘后可见木材/节点还略窄。
