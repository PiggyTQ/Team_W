# 职业探索、比较与岗位研究：本地改进与验收

2026-11-26，沿用现有dev / 867fff3与全部未提交修改。只完成本地实现与检查；未部署、Git提交/推送或操作生产数据库、费用账本。原账号/登录、36实践、技能树、报告及AI工作台既有工作保留。

## 页面变化

1. **十方向更好读**：从具体问题出发，直接说明怎样处理、交出什么、与谁协作及先尝试哪件事。工作分三段，具体分工和相邻职业边界另有区域。原代表案例、产物、准备、成长、体验、来源和完整范围仍可查阅。
2. **比较先有内容**：首次按站内工作关联给出两个方向及理由，允许更换与加入第三项；已有有效选择/URL优先。三条关键差别＋六个同维内容入口替代大段文字巨表。取舍笔记、旧依据提醒、本人原文、目标预览和预算预检保留，不自动改主目标。
3. **表格与岗位更清楚**：产物表改善数字对齐和合计层级；岗位对照按职责/条件、来源/时效分组。横向筛选和紧凑岗位卡替换宽筛选侧栏，首屏直接可读岗位摘要；清空查询后的旧关键词恢复问题也已修正。
4. **机会接上行动**：空态保留一个明确添加入口；已有记录通过原文/来源、同一准备任务和本人事件三个入口查看。实际保存、预算任务、面试记录和归档仍独立，归档不删除任务或事件。

## 实时岗位的取舍

本轮没有获得可核验、允许本站使用的BOSS第三方职位推荐API和合作授权，因此不接入实时推荐，不用爬虫或未公开接口。页面提供固定BOSS官网跳转和本人主动保存来源的路径。现有历史样本、本站合成示例及私人机会明确分开，不能把它们称为实时在招。

[官方接入研究与界面参考](career-exploration-experience-20261126/jobs-access-research.md)包含实际打开的Apple比较、GitHub Primer和Stripe岗位页，以及BOSS/Greenhouse查阅范围与失败项。借鉴信息组织，不复制品牌资产或招聘数据。

## 保留与限制

职业事实和公共比较的原内容版本、案例数据、SQL/图、许可、旧讨论、笔记版本及本人确认/预算/成长规则保留。新阅读摘要标注它依据的现有字段与来源ID，没有给旧资料静默换版本。相关工作推荐是可修改的站内建议，不是适合率或招聘保证。原岗位快照未经本轮在招核验；私人输入不进公开目录。

正式实时来源需另取得官方接口、授权、时效/撤回机制、额度及运营安排。本轮未启用任何外部服务。职业内容的领域审读、真人阅读/选择体验仍待实际参与者验证。
