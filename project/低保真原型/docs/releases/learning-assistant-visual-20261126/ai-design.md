# AI 工作台与三个任务页：实施前设计

2026-11-26。本文件为实施前方案；reference/assistant-target.png 是用户指定恢复的图二，ai-design.svg 是结构示意，均不是本轮浏览器实拍。

## 本轮观察与原因

同一 /assistant 在真实账户构建使用 DiscussionWorkbench，在本机演示使用 AssistantChat。前者已有居中角色、输入及三项任务链接，后者仍是旧的左右两栏、四项填入示例问题。assistant-studio、assistant-fit 与 learning-assistant-reference 中旧 empty-chat 样式进一步将演示入口放到右侧。不是讨论数据消失，而是两条呈现路径及各自布局不一致；本轮不据静态源码推断是哪次部署造成。

## 恢复效果

- 保留左全局导航和现有顶栏；页面顶行左为 AI 工作台，右为历史讨论、本人笔记和新讨论。
- 奶油白画布中间使用现有透明笔记本角色，配“和芝识分子聊聊”、简短副标题。正文不是另一个带边框大面板。
- 下方是独立大输入面，内部底行左侧本次资料、右侧黄色发送。空输入、模型关闭、未授权、保存及发送状态继续真实反馈；模型关闭显示保存问题，不伪装已发送。
- 输入面下是三项横向起点：梳理我的下一步、比较职业方向、整理成果表达；它们进入既有独立路由，不再在旁边重复四张示例问题卡。
- 服务和演示首页共用上述视觉，但保留各自真实行为。演示保留模拟服务标记、咨询模式、失败演示和原消息链路；低频选项按需展开。

## 三个独立任务页

延用同一奶油白、海军蓝、淡蓝与黄色；顶部任务图标/标题、返回工作台和三项管理操作。下一步及成果表达用一张材料选择工作面和一张宽讨论工作面，按实际空间重排；职业比较保留同维表及完整阅读，把讨论作为其后的同一工作面。输入/资料/结果保持相同语言，原对象、原任务、临时假设、授权、草稿预览确认及返回链路不改。

宽桌面欢迎输入面约1040px；页边与管理顶行一致。较短桌面减少欢迎留白；窄屏管理按钮可换行，角色缩小，三项起点与任务双栏降为单列，不压缩正文、截断比较或制造横向溢出。Tutor 的 discussion-compact 不在本轮覆盖范围。

## 验收交接

根代理统一使用 Node24 构建及隔离账户验证。需分别检查服务/演示自由首页、三个路由、空输入、保存问题、资料范围、历史/笔记、新讨论、已有消息、任务对象切换及业务返回。实拍另存 actual，不将本设计或历史发布结果冒称本轮实测。本轮不部署或启用外部模型。
