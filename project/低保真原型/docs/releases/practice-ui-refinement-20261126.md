# 资源中心与项目工作区优化（本地完成）

2026-11-26，基于 `dev / 867fff3` 上已有、尚未提交的36项目扩展继续修改。本轮只完成当前用户授权的资源中心、项目说明与适配优化；没有部署、提交、推送或修改真实账户数据。

## 页面与交互

- 资源中心解除嵌套限宽，与页面标题共用左右边缘；使用既有笔记本角色插画、Roundline图标、浅蓝与奶油黄引导区、独立筛选工具条。职业路线改为带阶段编号的项目卡，显示具体任务、交付产物、估时与真实发布状态；保留36项、十方向筛选、跨职业项目、继续任务和历史入口。旧四项目的简述来自现有任务书，不再显示泛泛的“沿用记录”。旧项目卡片估时与其实际任务范围采用同一数据。
- 新项目页用“读懂材料 → 制作产物 → 核对并交付”解释流程，清楚列出文件用途。下载、任务书、开始预算预览与来源均可达；预算按钮前移。输入改为可读表格与真实记录数量，最多预览4条/6列，超出时明确标注部分预览。原始JSON默认收起，完整数据和字段字典仍可下载。缺字段显示“未提供”，与显式 `null`、0、false分开。
- 原“本次完整输入”是固定练习数据与测试情境，不是答案。用户需制作项目约定的结果、说明、源码/查询/界面/配置。公开参考单独展开并说明用途。本机验证可能还使用包内 `solution.mjs`；网页列出的是上传产物，不是全部本机文件。没有重新冻结或改写旧材料身份。
- 估时是理解材料、学习、制作、调试、整理的编辑估算，不是数据阅读时间，也不自动记作实际用时。尚无真实学习者用时校准。
- 检查项改为可理解的中英说明，失败可直接定位并聚焦对应产物文件。仍如实区分文件存在/格式、固定输入结果核对、本机执行、浏览器检查及开放评价；本站不执行上传源码。改稿后必须重新检查；提交、本人复核、归档的顺序与原有规则保留。
- 旧四项目与讨论父容器解除限宽，正文和任务主栏优先利用可用面积；侧栏按剩余空间分配并设上限，角色选项在足够宽时并排，小容器再堆叠。新旧页面不再共用报告页的 `growth-overview` 样式类。小屏标题、状态和估时改为上下排列。
