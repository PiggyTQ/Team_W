# 英文工作区导航比例调整（2026-11-27，本地）

用户要求检查英文工作区中侧栏过窄、菜单拥挤的问题，参考成熟产品的比例后直接调整。实际工程继续使用 `git_file/project/低保真原型` 的 dev / 867fff3 与共享工作区已有修改；本轮未部署、提交或推送。

## 现状实测与比例选择

改前在1366、1616、1920、2560四档桌面中，最终生效侧栏均为220px。英文“Personal assessment”和“Learning and practice”被挤成两行；1366×900中底部三个主要导航入口需要在栏内滚动。仅修改早期224px规则无效，后续工作区样式还会覆盖为220px。

参考[Atlassian Navigation System的SideNav](https://atlassian.design/components/navigation-system/layout/code)默认320px与[IBM Carbon v10 UI Shell](https://v10.carbondesignsystem.com/components/UI-shell-left-panel/style/)的256px规范，并结合[Atlassian Grid](https://atlassian.design/foundations/grid)对导航和内容空间的区分。Carbon数值明确对应v10；下表为本站按实际文案、伙伴区和正文空间作出的设计选择，不是上述规范规定的统一比例。

| 视口宽度 | 展开侧栏 | 该档典型桌面的正文宽度 | 侧栏占比 |
| --- | --- | --- | --- |
| 721–1023 | 240px | 768下528px | 31.3%（紧凑窗口） |
| 1024–1279 | 256px | 1024下768px | 25.0% |
| 1280–1599 | 280px | 1366下1086px | 20.5% |
| 1600–1919 | 296px | 1616下1320px | 18.3% |
| 1920及以上 | 320px | 1920下1600px；2560下2240px | 16.7%；12.5% |

正文宽度为工作区外框的实际剩余宽度，内部继续保留各页面阅读限宽。宽屏侧栏上限320px，避免跟随屏幕无限放大。中英文共用相同尺寸，切换语言时不横跳。

## 实际调整

- 导航文字15px、图标独立22px槽、图文间距12px；长词组按空格自然换行，主要名称完整可读。常用桌面中的八个主要导航入口均可见。
- 菜单常规至少48px高；窗口高度不超过1050px时使用至少44px行，伙伴区改横向紧凑排列，保留读书、休息、隐藏和互动。更矮窗口仍可独立滚动主导航。
- 主区和底部流程栏继续使用既有侧栏宽度变量，顶部搜索与展开侧栏右缘对齐。Logo图像保持原尺寸；折叠后为完整Logo预留实际宽度，修复旧24px品牌槽使搜索覆盖字样的问题。
- 折叠轨道保持76px，保留刷新偏好、键盘快捷键、英文提示和焦点。720px及以下继续使用既有移动抽屉。
- 职业探索按正文容器适配：可用宽度不超过900px时，标题与模式页签上下排列，筛选区移到卡片上方；紧凑桌面筛选使用两列字段和横向分组。640px以下页签两列、职业卡片单列，避免窄卡片将英文拆成字符列。

本轮修改位于 `src/workspace-navigation-proportions.css`、`src/main.jsx`最后的样式导入，以及 `src/career-workspace.css`的窄容器规则。没有改变职业文案、目标、学习进度、项目材料、岗位记录或AI协议。
