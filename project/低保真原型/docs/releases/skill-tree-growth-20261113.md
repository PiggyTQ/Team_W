# 职业成长树 · 2026-11-14

地图把四根主枝画在一棵半透明银蓝色的树上。枝条比主干更醒目，树后的页面底色从暖白过渡到冰蓝。十个职业共用插画骨架，每个职业独立显示自己的分支、技能名称和通过记录。动画只在用户看到新长成的叶子与年轮时短暂播放。

枝梢的蓝色露珠可以打开学习资料。检验通过后，对应露珠长成三至四片绿叶，枝条从树心向外按分支进度染上青绿，树心每通过一项就多着色一圈年轮。横向学习路径、分支计数和树下的职业计数使用同一份账户进度。桌面可点选整棵树，窄屏从树下切换分支，图中保留已长成的叶片和当前分支的露珠。

交互构图借鉴了游戏里用树承载探索的方式，以及用植物生长反馈进展的方式。树、露珠和叶片均为本项目生成的透明图层。[At Fate’s End](https://thunderlotusgames.com/games/at-fates-end/) · [Botany Manor](https://www.botanymanor.com/)
