# 职业探索体验改进：本地实施

2026-11-26。在现有dev / 867fff3及未提交工作上改进，保留同期实践成长、分支学习与AI等其他改动。本轮不部署、不提交或推送，不操作生产账户、生产数据库或费用账本。

## 取舍与实现

### 看懂职业

十方向新增基于现有已核职业资料的双语阅读摘要：先问一个具体问题，再说明怎么解决，直接展示典型产物、协作对象和首个体验。主体为三段具体工作与产物、常见分工、容易混淆的相邻方向。原工作流程、范围、代表案例、真实产物示例、准备、成长协作、体验与来源仍可阅读；没有把全部职业改成同一组工具名。

新`career-reading-guide.js`记录原字段映射、来源ID及当前公共资料版本。仅为阅读层摘要，没有重写历史公共资料、AI引用或旧讨论的内容版本。已有案例数据、SQL、图表、来源许可、材料关联与技能检验规则保留。实例表格改善列对齐、行分隔、数字和合计层级，不增加评分。

### 比较先展示差别

取消首屏大勾选表与整页长段落矩阵。初次没有足够选择时，按当前职业、已有选择或主目标给出两个有关联的方向及理由；这是**站内工作关联规则**，没有调用外部AI，也不是个人适合度结论。

已有合法URL与2–3项选择优先；显式空/单选保留本人操作，可一键采用建议。顶部画像、三条关键差别、六个同维度入口用于看清具体工作差异，可替换或加入第三项。取舍笔记、旧依据提醒、本人原文、目标预览、短验证与返回列表保留。修正了已有笔记刷新后输入控件名称会混入正文的问题，显式aria-label保证键盘及辅助技术识别稳定。

### 企业与岗位

演示模式两个原创合成示例与服务模式历史岗位样本分别呈现。筛选改为横向工具区；卡片直接区分职业、组织、职责摘录、地区、来源/采集日和待核信息；按工作/要求及来源/时效分组对照。保留查询条件、无结果恢复、分页、详情、保存去重与来源快照。

合并重复标题，外站说明压成一行，未选择时不占用空比较条。正常保存状态继续供屏幕阅读器使用，失败仍可见。1366中文和1616英文首屏已实际断言首条职责位于固定底栏之上。

当前未取得可核验的BOSS第三方职位推荐API与本站使用授权，**本轮不接实时推荐，也不使用抓取或未公开接口**。提供固定BOSS官网跳转，不携带账户/私人资料或查询参数；用户可主动把岗位原文和来源存入本人研究卡。未把历史数据或合成示例标成实时在招。Greenhouse官方Job Board API是未来可研究的企业招聘板来源，尚未为本项目接入；它不等于中国综合招聘市场。详见[官方接入研究](jobs-access-research.md)。

### 我的机会

空态改为紧凑的“添加岗位研究卡”起点及研究→准备→本人事件路径，不再重复占用大块提示与添加按钮。已有机会显示可点击的原文/来源、同一准备任务、本人事件；状态只来自实际记录。既有编辑、预算预检、续同一任务、简历、事件修订、归档与恢复回调保留。私人原文不随界面语言改写；本站原生合成示例可以切换英文，已保存的来源快照保持原字节内容。
