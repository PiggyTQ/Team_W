# 技能分支学习：实际教学与阅读布局重建

完成：2026-11-27（设计与编写从2026-11-26开始）。本地 `dev / 867fff3` 加共享工作区既有修改；本轮没有提交、推送、部署或操作生产账户。

## 解决的问题与最终效果

用户指出的核心问题成立：旧页面往往只列“该注意什么、哪些结论不能推广”，没有教会如何从输入走到结果。上一轮的浅色视觉没有解决这一点。

本轮为现有123技能编写新的双语教学包，保留职业/分支/技能ID和旧评测版本。119个通用课以新正文呈现：概念与因果解释 → 输入自足的完整示范 → 有操作材料时对照原实验 → 新情境判断、逐项反馈、具体反例与开放迁移。SQL关联、决策表、事件交接、服务信号四门专课保留原有交互示范，在末段接入新的迁移练习。

示范默认可读，含至少三步和每步解释；不再把主要推演藏在折叠入口。新情境判断的三个选择各有理由；修改选择会撤销上次反馈，保存的反馈只适用于同一题目版本。开放作答可以保存并按参考做法/条件自查，不按篇幅或点击次数判为掌握。阅读和随堂核对不授叶，最终检验仍使用原业务规则。

以用户图中的“信任边界与威胁建模”为例：讲清资产、数据流和授权边界，给出上传API、元数据与私有存储的完整合成材料；以五步说明主体来源、名称/内容/存储控制、下载对象授权及证据表。新增可切换上传/下载的请求路径示意，直接对照控制位置；再用跨用户下载与头像替换/删除验证理解。

布局改为顶部技能路线、同宽目标区和连续主阅读区。主要正文采用合理行长；步骤、材料和反馈按内容增高。来源与先修/范围收在正文后的按需说明，不占一整列与短正文并排。整体延续现有浅蓝、暖白和黄色重点的品牌视觉，学习阶段没有树木占位，检验回到原成长树旁。
