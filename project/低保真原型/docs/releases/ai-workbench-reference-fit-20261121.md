# AI 首屏还原与按需 Tutor（2026-11-21）

> 发布状态更新：2026-11-21已按用户指示随[合并版本](combined-release-20261121.md)上线。下文“仅本地/未部署”与测试日期属于发布前历史记录，当前状态以合并回执为准。


本轮按用户新提供的三张图调整已有 AI 工作台与学习辅导布局。仅本地实现与桌面验证；未部署、提交或推送，未启用外部模型、邮件或付费服务，未修改真实账户、数据库、累计费用账本、课程内容或职业报告。

## 设计与结果

- 首屏恢复清楚的比例：较大的原角色、深蓝欢迎标题、1040px 输入面，以及带图标和短说明的三个横向问题起点。顶部仅保留页面名称、历史、本人笔记和新讨论；普通保存状态保持可读给辅助技术，错误保存状态仍直接显示。操作引导保留在讨论历史内。
- 角色插画直接复用原透明 PNG，不生图替换、不重画 Logo。附件采用现有图标系统扩展的回形针；三个起点仍绑定原意图和资料选择，保持原处理链路。
- 学习页右上角为 `芝识分子 Tutor` 入口。关闭时只有现有顶部栏里的按钮，没有正文按钮行、侧栏占位或预留列。没有默认展开。
- 点击后才将同一讨论接入页面右侧停靠区，并让正文重新排布；再次点击、关闭按钮或 Escape 收起后恢复全部正文宽度。键盘焦点返回入口，未保存问题、原始练习、实际输出及原讨论均保留。
- 侧栏从整个工作区内容的顶部开始，不再嵌在某个学习小块里。桌面宽400px，1366宽度时360px；输入框与状态独立于可滚动阅读区，随视口高度调整。资料和提示仍须主动选择，最终检验阶段不开放 Tutor。
- 四个综合项目复用同一入口；原实践内部的问询快捷动作与账户工具内的 AI 入口也指向它，不另开重复助手。

设计图里的向上箭头表示发送；模型关闭时当前应用保留“保存问题”的真实行为与图标，未将其伪装成可以正常调用模型。

## 本轮实测

使用临时 SQLite 与隔离合成账户，实际浏览器为 headless Microsoft Edge。中文1616×973与英文1366×960；无手机验收。

- 中文首屏输入面1040px，顶部标题y=106px，输入面y≈499px；三个起点在首屏内完整显示。中英文无横向溢出。
- SQL 练习关闭 Tutor 时正文1309px，展开后887px，右侧400px与22px间距；再次关闭恢复1309px，学习块垂直位置不变。侧栏y=137px、底部y=957px，在973px视口内；输入面保持可见。
- 顶栏点击、Escape关闭并回焦点、再次打开保留问题与讨论身份、展开独立工作台再回原稿、关闭时原 SQL 实际运行及错误反馈保留，均通过。
- 四个综合项目逐一验证默认关闭、打开重排、关闭恢复原宽度。
- 原完整链路再次通过：SQL辅导→原练习→原检验；三小时具体建议→原任务草稿/完整影响预览→本人确认→原ID更新；成果候选→本人确认→报告和简历材料。链路测试仅使用可控本地供应商，不能代表真实模型回答质量。
- 相关自动测试59/59通过，覆盖会话取消/晚到响应、草稿来源、有限追问、技能练习及最新课程章节兼容。未重复运行与本轮布局无关的全量套件；前轮的费用定价快照失败属于历史结果，不冒称本轮重测。
- 双语完整性检查8947条、exactMissing=0；服务模式构建通过，原包体积/登录资源导入警告保留。
- 单次界面检测0反模式，58项旧全局设计尺度提示；本次参考图明确要求更大的首屏字号/图标和停靠区，局部规范已同步，未关闭检查。
