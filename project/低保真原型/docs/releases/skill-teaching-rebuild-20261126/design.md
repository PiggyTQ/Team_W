# 技能学习教学重建：实施前设计

用户截图 `reference/current-lesson.png` 是问题现状。上轮主要改颜色，未解决短正文、长资料栏和教学过程不足。

## 教学效果

逐课补充原创双语教学单元，覆盖现有123个技能，不新增职业/技能ID：

1. 先解释概念及因果关系，说明为什么一种做法能解决本课问题。
2. 给自足的合成输入，逐步写出操作、每步中间结果和最终结果，主要示范直接可读。
3. 给一个与最终检验不同的小情境，让用户判断；错误选择解释具体错因，正确选择解释适用依据。
4. 给开放迁移任务、可对照的一种做法和明确自查条件。自由文字不以长度判为掌握。
5. 用具体错误示范讲清边界。方法资料收在正文之后按需查阅，不能让来源列表占掉主教学区域。

保留原实际SQL、决策表、事件交接与告警工作区，新增教学判断与其共同工作，不替代最终检验。阅读、课堂答题和个人自查不直接长叶或授予职业能力；保留旧位置、便笺、练习与检验记录。

## 页面效果

学习采用一条清楚的主阅读流，分支目录从左侧短栏移为顶部紧凑路线；宽屏也不再出现“左几句说明、右一长列来源”的两块错配。当前技能目标和产物、课内目录、讲授/示范/新情境练习沿同一阅读边缘排布。资料、先修和范围为按需说明；主体用合理行长，长篇示范按真实内容增高，不凑齐卡片高度。

`concept/method/examples/mistakes/sources` 旧位置标识保持可读，前台改为自然的教学阶段名称，资料不再成为稀薄的主章节。小屏路线和目标自然换行；Tutor打开后按剩余空间重排，检验时仍回原树旁。

本文件与structure.svg为实施前方案；实际页面与验证之后另存。本轮不部署。
