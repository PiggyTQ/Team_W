## 内容修订与版本

- 对照 [八条建议](career-content-evidence-20261123/proposed-corrections.json) 的旧值逐项采用。测试比较和 AI 对照指向 R2 的 7999/8000/8001 分，R1 仍使用 99.99/100/100.01。测试严重程度、修复顺序和发布责任分别说明。
- AI 先分类无依据、错引及服务失败，再要求检索结果、提示和调用记录定位原因。当前合成题继续使用原有待审输出和原文。
- 工程案例明确目标存储支持事务或发布机制，主练习复核四个 ID 的 channel 并判断 b18 发布条件。事务方法参考与编排方法分别关联。
- 数据分析删除固定负担比较。操作说明明确按 ID 取最新状态，再排除测试和非 active，最后分组。原 SQL、数据和图保持原样，图表核对口径限定为本例的零起点数值轴。
- 详情、普通比较、AI 工作台和服务器公共资料共享职业版本和案例摘要。英文由同一内容模型投影。归档完整旧投影 `src/content/career-profiles-20261122-audit.json`，其指纹与历史版本相符。旧比较笔记保留，需对照当前版本才带入目标理由；旧授权依据变动时继续触发核对。
- 小体验题材料和作答条件沿用 `career-trial-20261122-audit`。保存的来源版本仍可随原稿导出，本轮没有迁移或改写账户记录。材料关联、学习及生长继续使用既有规则。

- 中国职业标准使用所列职业的政府或机构公开件。商务数据分析和人工智能中央附件仍待比对，标明实际读到的机构或政务镜像。大数据标准发布、通知与 PDF 上传日期单列。
