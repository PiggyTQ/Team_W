2026-11-26开始，2026-11-27完成本地改进。在现有dev / 867fff3及共用工作区修改上继续，不重置或覆盖其他工作。未部署、提交、推送或操作真实账户。

用户问题：代表案例中的任务、范围、说明、输入、判断与复核几乎处于同一级，左侧裸文与右侧大表缺乏组织；其他章节也缺少辨识度。本轮借鉴站内分支学习与综合项目工作区，保留六等分页签、同款报告横移指示及当前蓝黄品牌。

## 具体改变

- **任务头**：六章节共用紧凑的图标、主题、导语层级。原职业范围降低为辅助信息，主要问题与产物优先显示。
- **代表案例**：委托方、核心问题、输入限制组成任务简报；右侧为独立的产物工作纸，数据结果单独强调。判断过程和复核责任在下一级区域显示，避免正文连续平铺。
- **完整产物**：每份交付物改为可见的文件头、实际表格／代码／图／简报，旁侧独立列出交给谁、解决什么与验收条件。内容继续来自原同一案例。
- **能力准备**：方法名称、工作中的使用、产物质量三个层次横向对照；本人材料独立成依据区，不增加能力分或准备充分度。
- **成长协作**：责任路线按实际条目铺满；角色与交换内容组成协作清单，工作环境与易错点另有不同表面。
- **入门体验**：任务与产物检查分开，材料阅读、本人工作稿及后续学习行动形成工作区；保存、清空、撤销、旧稿、教学对照均保留。
- **来源档案**：来源标题、发布者与地区在摘要中可见，完整范围、核读状态、日期、版本及许可继续可展开回查。

原全局字体层曾把章节正文与控件普遍强制为17px。本轮仅在六个章节内按现有字体层定向恢复主题、问题、正文、标签与来源说明的不同字号，没有换全站字体或品牌。

两个实际发现已修复：旧表格的每列150px最小宽度会挤掉预览第四列，现在四列与全部数值完整可见；原三列责任路线对两项内容留下空位，现在两项铺满。产物定位也给吸顶导航留出空间。
