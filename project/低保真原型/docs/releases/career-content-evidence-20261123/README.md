# 线上职业探索内容核查与补全包

核查日期：2026-11-23。用途：为下一轮Codex实施提供线上基线、具体修订、十职业新增正文及主张对应来源。本轮不修改服务器正文或业务代码，不部署。

- [总审阅与补全表](核查结论与补全总表.md)：先看结论、优先级及每个方向需要补什么。
- [可直接发送给Codex的提示词](给Codex的内容完善提示词.md)：实施目标、资料采用规则、版本与验收。
- [数据分析、人工智能、数据工程补充稿](分组审阅与补充-数据与智能.md)。
- [前端、后端、通用软件、测试补充稿](分组审阅与补充-软件与测试.md)。
- [网络安全、运维、IT实施交付补充稿](分组审阅与补充-安全运维与交付.md)。
- [最小修订建议JSON](proposed-corrections.json)：从实际线上旧值到建议新值，供核对，不自动应用。
- [十方向实施映射](implementation-map.json)：将职业ID、增补目标、正文文件和证据位置关联起来。
- [来源采用与内容验收](来源采用与验收.md)：区分职业标准、职业资料、方法、原创教学及市场样本。
- baseline：线上公开资源中实际提取的10职业正文、15条来源、资源清单和逐项一致性结果；不是待实现补丁。

线上基线为`career-exploration-20261122-audit`。本轮匿名GET取得线上HTML及其实际JS资源，以AST读取静态数据，没有执行远程JS；10职业和15条来源均与当前本地JSON逐项一致。只核对公开发布内容，没有使用生产账户、读取私有数据或执行登录后业务。

分组文件包含已写好的可采用中文正文，不只是“请再研究”的任务清单。研究中打开了国内国家职业技术技能标准的政府/机构发布件，以及O*NET、BLS和专业方法原文。正文各自注明原文选读范围、地域、版本、权利和不能推导的结论。未读全文或许可待核部分不能被实现者自动改成“已核”。外部标准原文通过官方/发布机构链接访问，本包不镜像第三方课程、题库、整书或PDF。

现有AI原文/待审回答、安全最小证据、运维不同分母、前端模拟状态、工程内容重跑对照、测试独立R2、交付CSV和回退分岔等已上线改进均保留；不要照搬上一轮已修问题再实施一次。
