# 空态与比较页改进 v17

## 判断规则

用户指出比较页只显示一句限制和返回入口，无法在原位开始。此次检查页面与空态实现，区分：需要准备输入的功能空态、筛选无结果、真实数据尚未开放、权限/对象异常。只给返回或导入的功能空态补用途、准备要求、实际操作和结果出口；不为权限异常增加无关操作，也不补造真实数据。维持15主模板及现有2–3方向比较规则。

## 改动

| 页面/状态 | 原问题 | 本轮行为 |
|---|---|---|
| 职业比较 | 不足2项只有返回入口 | 本页列出10个原创方向的任务与产物，可选2–3项；0/1/2/3项有明确提示，满3项禁用额外选择，可移除或更换；保留原比较表与目标/计划出口 |
| 原文确认空队列 | 只有导入或手填跳转 | 解释候选与确认关系，分手填、模拟导入、没有经历先实践；筛选无材料时可恢复全部 |
| 成果档案 | 单个录入入口 | 解释哪些经历可复用，连接已有作品、已有行动、先做实践三条路径 |
| 复盘空记录 | 只有一段说明 | 解释关联实际行动、记录结果和保存后的用途；已有任务可关联，站外行动可补录，没有行动可先实践；原复盘表单保留 |
| 提交版本空态 | 无下一操作 | 区分保存草稿、提交版本与检查，回到同一任务的提交区或交付标准 |
| 反馈工单空态 | 只有提交按钮 | 解释对象/版本/片段/回执要求，提供提交反馈、回看评估和回看讨论 |

## 保留的合理空态

报告目录已有创建预检与缺项解释；学习收藏/无结果已有范围恢复和计划出口；地图关系未发布明确不补造连线并保留节点/内容入口；AI讨论已有问题建议与资料范围；岗位页面已有研究输入与本人机会分流。薪酬无获准来源、权限拒绝、无效任务与无效页面不补造内容或绕过角色。管理工作区的空工单不自动创建测试反馈。此次未声明这些服务已真实完成。

## 实际检查

浏览器验证比较1→2可启用查看、2项产生3列表头、3项禁止第4项、移除后可更换、0项不能查看；最后恢复测试前原有的数据分析选择，未改变主目标。四处空态读取到了对应标题及有效操作入口。提交版本空态经代码与构建检查，本轮未为它载入覆盖用户数据的S2任务场景。中英文新文案同步，390px手机选择器单列，375px内容宽度与滚动宽度一致。构建及31项现有测试通过。
