# 首页成果固定框架 v15

依据用户要求，成果区切换15个状态时不再由右侧内容撑高整体布局。

- 展示框高度按视口统一计算clamp(380px,100dvh−300px,460px)，同一视口下不随文案改变。
- 右侧使用44px头部、固定内容窗口、44px说明栏；内纸张等大，长内容允许内部滚动，不裁掉文字。
- 左侧编号、类型、标题、说明采用固定行空间；起点/整理/成果底部锚定。步骤计数44px，五类导航46px。
- 延续v14滚轮顺序，手机和短屏自然纵向阅读模式不套桌面固定高度。

浏览器核对：1280×720下中文15个状态外框高度420px，宽度742.67px；固定舞台就位后外框、左侧区域、阶段按钮和导航坐标一致。英文15个状态外框大小与位置同样一致。较长文案在内框保留滚动入口。尺寸证据见[检查记录](检查记录/成果固定框架_v15/尺寸检查.json)。本轮为CSS布局修复，构建通过。
