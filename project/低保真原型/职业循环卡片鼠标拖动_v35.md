# 职业循环卡片鼠标拖动 v35

2026-10-19。保留当前32px/秒无缝循环，增加鼠标按住拖动和松手继续播放。无新增附件，沿用灰阶低保真与现有方向内容。

鼠标主键按下时立即保存动画精确位置并暂停；横向移动超过4px后轨道按鼠标距离一比一跟随，同时捕获指针。轨道位移按十张卡片总长度取模，左右拖过首尾都能接续，不会触底。松开时从当前位置继续原有匀速循环，不吸附、不倒回、不额外加速。

鼠标拖出区域后仍能接收释放事件；指针取消或窗口失去焦点会解除拖动状态。抓取/抓紧光标提示拖动，禁止图片原生拖拽和拖动时的文字选中。纵向触摸浏览不被鼠标手势占用，键盘上下张与暂停控制保留；若用户已主动暂停，拖动不会取消该暂停选择。

卡片摘要按钮上的短点击正常打开详情；发生拖动后拦截本次点击，避免松手误开详情。点击与拖动已分别实测。
