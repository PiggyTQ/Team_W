# 学生试用记录规程（尚未执行）

招募5–8名自愿大学生，覆盖无项目经历、有课程项目、目标未定、每周时间有限等情况。不要求提交身份证、密码、完整原始文件或无关隐私。参与者可撤回；问题与明确选择的资料只有在同意DeepSeek外发范围后才送出。研究记录另行征得同意，不把站内授权当研究授权。

每人完成一次连续任务：

1. 阅读一个职业的来源与适用范围，说出“入门学习参考”和“招聘必需条件”的区别。
2. 确认或拒绝一条材料，仅选择本人愿用于本次讨论的片段；解释确认为何不等于核验。
3. 核对学习方向，找一项有关联的材料与一项未知；检查模型是否补造来源、角色、熟练度或完成状态。
4. 输入本人每周预算与一次行动预计投入；先尝试超预算，检查拒绝原因，再缩小行动范围。
5. 预览目的、产出、版本与预算，主动确认新增；核对计划中的同一任务与回执。放弃预览时不得产生任务。
6. 保存、撤回站内偏好，撤回资料授权；确认后续外发停止，旧个人回答和笔记隐藏。
7. 标记一条不相关/依据不足/不清楚的建议，解释其问题；反馈不得自动改为知识或能力结论。

每人记录：匿名参与编号、单独同意状态、任务是否完成、是否求助、观察到的误解、原引用ID/版本、问题类别、修改建议、撤回是否成功。原始个人材料不进入共享缺陷单；必要引文需单独授权并脱敏。

结果表当前留空：`participant_id,consented,career,step,completed,needed_help,issue_category,evidence_version,notes,withdrawal_verified`。禁止用合成浏览器账户填写真人测试结果。

阻断正式开放的问题：任一未经授权外发、跨账户数据泄露、用户未确认的重要写入、重复写入、虚构用户经历、把材料未知解释成不会、把历史样本解释为实时全国要求。每一问题需修复并加入可重放用例后再试。

正式开放还需：至少一次独立职业内容复核、真实学生任务结果、维护责任人、费用运营方案、备份与恢复值守、知识纠错与撤回责任人。工程测试通过不能代替这些证据。
