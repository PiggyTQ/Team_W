# 首页接近自动吸附 v27

2026-10-19。用户进一步明确：“快滑到下一个页面时自动吸附到此页面”。本轮将吸附触发点从主题末端前移到下一主题入口的接近区域。

## 当前交互

向下滚动接近下一主题时，系统自动补完余下距离，将下一主题的标题/舞台对齐并停稳。感应范围为视口高度的34%，最多320px；无需用户恰好滚到对齐坐标。一次大滚轮只吸附最近的下一主题。

短主题在吸附位置停靠，后续下滑继续采用拉扯蓄力；长主题和固定舞台先吸附到开头，允许继续阅读/浏览内部内容，在末端停靠。保留v25的较慢切换和v26的拉扯释放。反向、键盘、锚点可打断。

同时修正启用门槛：旧代码要求高度至少720px，低于此高度会退回原生滚动；现为宽度至少900px、高度至少560px、精细指针且允许动态效果。900/712/650px高的窗口均已实测；手机和减少动态效果仍采用原生滚动。

## 实测证据

在1280×712视口，初始文档位置5765px，只输入30px滚轮；最终自动到6028px，对齐目标6027.5625px。系统自动补完233px，而非滚轮直接滚到目标。位置取样见[JSON](检查记录/首页提前吸附_v27/吸附取样.json)。
