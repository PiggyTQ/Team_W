> 历史版本。后半页结构已由 [连贯叙事 v6](首页前后衔接改进说明_v6.md) 替代；本页保留 v5 来源和检查记录。

2026-10-17。范围为 U01 公开首页的剩余区域；保留已完成的首屏、成果舞台、问题卡牌、滚轮路径和十方向展廊。没有增加主模板或业务状态。

依据为最新正式规格及《12_借鉴升级_首页技能与成长闭环》：访客应能理解用途、看到产物、找到起点。参考站只影响表现，不扩充评估、数据和授权范围。

## 从说明块到可探索的示例

|区域|本次调整|操作与出口|
|---|---|---|
|学习路线|路线图与节点解释分区，明确工具可选关系，连接到任务产物|切换 SQL / 表格工具；查看原有节点弹窗；进入个人技能路线。取消弹窗保留节点|

## 参考与动效取舍

已重读 [可借鉴的交互.txt](../可借鉴网站/交互ui设计/可借鉴的交互.txt)，并查看该目录的点击卡片和滚动效果图片。图中包含教程界面，不能当作参考网站实际帧截图。

- [Dialedweb](https://www.dialedweb.com/)：借鉴清楚的区块节奏与行动入口，用于后半页分层和页尾导航。
- [mesh3d.gallery](https://mesh3d.gallery/)：结合用户文件中“点击切换、面板细节上升”的提示，将节点解释和预录答复做成主动点选后出现；未复制其 3D 展示。
- [Pier Gorelli](https://piergorelli.com/)：延续先前成果舞台的稳定画布思路，报告保持目录与纸面分离；没有再加长固定滚动段。
- [Studio Mirage / Sopra Banking](https://studiomirage.io/works/sopra-banking)：采用用户备注中的“结尾缩放”意图，改为一次轻量框体收束。原站结尾逐帧参数本轮未验证。

本轮实际查阅了前三个新增参考站的公开页面/HTML，并保存源文件；不声称完成所有原站动效的逐帧复刻。来源事实、用户偏好和本项目参数的区别见 [调研与取舍](../参考调研_20261017/首页后半段_v5/设计语言与借鉴取舍.md)。

实现参数为本项目自行选择：节点解释、答复和报告切换用 8px 上移与透明度，220ms；键盘切换直接呈现，减少动态效果仅 100ms 透明度变化。结尾进入视口一次从 0.965 缩放到 1，600ms；减少动态效果静态呈现。折叠加号旋转 160ms。统一沿用已有 ease-out 曲线。未增加自动播放、滚轮拦截、长时间固定或新依赖。

## 核对结果与边界

通过浏览器实际操作核对两条技能分支及弹窗取消、三个问题与六个方案及重置、三章报告与首尾边界及前后按钮、隐私三项与说明弹窗、四问单项展开、开始入口认证取消、七个手机锚点和菜单 Esc。取消后选择和章节保留。320 / 390 / 820px 页面宽度未出现横向溢出。运行时错误日志为空。详见 [交互证据 JSON](检查记录/首页后半页_v5/CUA检查.json)。

最终 `npm run build` 通过，62 个模块；`npm test` 23 项模型检查全部通过。两份本轮说明的 22 个本地引用均存在。本轮没有执行全站浏览器回归；原全站脚本中重复导航文字的定位已限定为首页导航。真实触屏、读屏、系统减少动态效果的运行时及性能跟踪尚未实测。真实登录、模型、招聘源、数据删除传播等服务仍未接入，不将预录或模拟流程称为真实服务。
