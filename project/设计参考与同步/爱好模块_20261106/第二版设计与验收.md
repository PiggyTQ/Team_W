### 实现

- 圆环保留 NT / NF / SJ / SP 大类；右侧四卡只显示当前大类的四个具体 MBTI 代码。
- 选中具体类型使用当前色系的深色背景和浅色文字；其余卡片保持浅色。文字与勾选标记同步表示选中状态。
- 详情从右侧卡片容器移出，成为上方左右布局的下方同级区块，横跨整行；背景固定为浅蓝渐变。
- 桌面实测模块宽 1112px，底部详情高度约 194px。兴趣方向与保存按钮紧凑排列。
- 主动保存 `preferences.interestGroup` 与 `preferences.interestType`，清除时同时清空；已有仅保存大类的记录不自动补填具体类型。既有自由文本兴趣保持。

### 验证

- 四组大类与各四个具体类型逐项对应通过；点击真实圆环弧段与键盘选择通过。
- 所有大类下底部计算背景相同；ENFP 选中为深色底、浅色字，其他三个 NF 类型为浅色底。
- 桌面几何检查通过：圆环与卡片左右排列，底部位于二者下方，左右边界与整体模块相同。
- ENFP 主动保存、刷新恢复、跨大类浏览后恢复选中、同时清空两字段通过。
- 既有兴趣文字和业务材料保持，新增字段通过服务器工作区规范化兼容检查；未启动真实账户服务或写入线上账户。
- 中英文在 390px / 320px 下无页面横向溢出，最终浏览器检查无页面脚本异常。
- `npm run build` 与双语检查通过，7771 条站点文案缺失 0。项目既有大包与混合导入提示保留。
