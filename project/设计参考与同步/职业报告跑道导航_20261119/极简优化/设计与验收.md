# 飞机跑道导航：极简优化

日期：2026-11-19。用户要求飞机只有一个朝向，整体改成极简风，提供两张单色图案作为参考。

后续更新已取消导航吸顶，并将技能卡片改为灯泡图文布局，见 [自然滚动与灯泡谱图](../../职业报告灯泡谱图_20261119/设计与验收.md)。以下保留本轮剪影与动效记录，其中吸顶相关描述为历史行为。

## 用户参考与实施前方案

- [图1：飞机剪影](用户参考/图1-飞机剪影.png)：采用单色、无描边的剪影语言和朝右上方的固定姿态，删除机窗、配色、阴影等细节。
- [图2：飞机与地面线](用户参考/图2-飞机与地面线.png)：借鉴简洁的地面横线；不增加第二种飞机姿态，也不叠加轮子等细节。

[实施前示意](设计图/极简导航.svg) 为本轮意图图，不是用户确认稿或实际截图。

方案只保留四个章节文字、一架单色飞机与一条浅灰细线。去掉深色跑道、灯点、阈值条纹、双侧线、渐变、阴影、外边框和选中胶囊。飞机朝向始终不变，仅沿水平方向平滑移动。默认导航收紧至 80px，英文手机界面为长标签保留必要空间。保留“完善能力”、原章节内容、键盘操作、深链接与减少动态效果支持。

状态：极简版本已实现，实际整体、局部和窄屏画面已保存并目视核对。本轮替代首版的多色飞机、转向和深色跑道方案。

## 实现与验证

飞机改为一个填充路径的深色剪影，固定朝向右上方。去掉全部朝向状态、旋转样式和内部装饰，仅外层沿 X 轴作 480ms 平移；向前、反向和快速重选均保持同一姿态。导航使用平面底色，吸顶时正文不会透到文字后面。

默认高度从 112px 收紧至 80px，英文手机界面从 144px 收紧至 112px。章节标签、链接、焦点和“完善能力”名称保持。滚动后切换章节时仍确保标题可见。

- [浏览器检查结果](页面检查结果.json)：12 项通过，运行时错误 0。检查了单色轮廓、装饰移除、双向移动全过程朝向不变、快速反向连续性、键盘、减少动态效果、侧栏伸缩、深链接及业务记录不变。
- 1920、1024、390、320 宽度的中英文显示均通过；1440 整体页面已核对。没有整页横向溢出或文字与跑道重叠。
- 真实滚轮和吸顶后切换章节通过，标题保持可见。
- `npm run build` 通过，双语检查 8418 条，`exactMissing=0`。已有构建提示仍在，未改动其来源。
