# 职业报告：飞机跑道章节导航

日期：2026-11-19。依据用户本轮截图和文字要求：将职业报告四章节导航改成飞机在跑道上滑行的样式及动画，并把“下一步补足”改为“完善能力”。

后续根据用户最新两张剪影参考，已改成固定朝向的极简方案，以 [极简优化](极简优化/设计与验收.md) 为准。以下保留首版设计和验证记录。

## 用户参考与先行设计

[用户原截图](用户参考/原四章节导航.png) 展示当前四个等宽页签。本图是修改对象参考，未提供飞机造型或其他功能要求。

已先保存 [跑道导航动效示意](设计图/跑道导航.svg)，用于说明本轮实施意图，不是实际截图或已确认设计稿。

- 保留四章节和原有内容：成长回顾、岗位匹配、岗位要求、完善能力。末项英文同步为 Develop skills，章节链接仍使用原有 `#projects`。
- 采用暖白背景、深蓝跑道、白色中线／边线和金色停靠点，与当前职业报告配色一致。飞机使用代码内的轻量矢量图形，不引入图片下载或新依赖。
- 四个文字按钮仍是可点击的章节入口；飞机是装饰性的当前章节指示器，不表达完成进度或岗位匹配分数。
- 切换时飞机沿直线滑到对应停靠点，向左切换时调整朝向。快速反向从当前位置继续，不先跳回旧站点；停止后保持静止。
- 首次打开、调整宽度、侧栏伸缩、键盘切换和减少动态效果直接定位，动画不延迟正文切换。保留页签角色、焦点轮廓、方向键与 Home / End 操作。
- 窄屏四项保持可达，文字允许换行，跑道不造成整页横向溢出。

状态：本地实现完成，实际导航与窄屏画面已保存并目视核对；没有部署到服务器。

## 实施结果

新组件 [ReportRunwayNavigation.jsx](../../低保真原型/src/ReportRunwayNavigation.jsx) 保留四个原有页签按钮、ID、键盘操作和章节 hash，用独立飞机图层指示选中项。飞机沿跑道移动约 0.5–0.9 秒，反向时读取当前位置接续，动画只影响装饰图层。静止后停止动画，不持续摇晃或自动轮播。

“完善能力”同步用于导航及该章节的标题，英文为 Develop skills。旧 `#projects` 深链接继续有效。导航保持吸顶；滚动后选择章节时，将被挡住的标题放到导航下方，正文不会被增高后的跑道遮盖。普通桌面和中文手机导航高度为 112px，英文窄屏增加文字空间，保留原有可读字号。
