# 职业综合报告

日期：2026-11-08。适用范围：电脑网页版职业报告。当前状态：实现完成，已核对电脑网页版中英文实际页面；未部署。

## 用户要求与参考

本轮将职业报告从材料和行动状态面板调整为综合结果页面，保留“职业报告 / 岗位简历”两项切换。正文依次为：已完成项目与能力背景、综合推荐岗位与匹配依据、岗位工作特点与能力要求、待补项目与下一步实践。保存、导出和历史版本作为低频功能继续保留。

[用户参考图：原职业报告页面](用户参考/原职业报告页面.png) 展示了修改前页面：上方为“方向选择 / 经历依据 / 行动记录 / 保存快照”四张摘要，正文顶部为阶段摘要和材料、行动状态分布图，左侧有旧报告目录。用户要求围绕最终综合结果组织报告，因此删除开屏分布图和重复摘要，将正文改为上述四章。参考图仅说明原页面与调整位置，不作为本轮设计或实现完成证据。

## 实施前设计

[职业综合报告结构图](设计图/职业综合报告.svg) 在 UI 实施前绘制，标明章节顺序与信息层级；条目为结构占位，不包含虚构的已完成项目、能力或匹配分数。该图为实施前方案，不是用户确认稿。沿用当前暖白背景、深蓝文字、浅蓝辅助区域和黄色主要行动，不进行全站视觉深化，不新增移动端工作。

1. **已完成项目与能力背景**：归纳已完成项目、本人贡献、能力依据和教育/个人背景。项目完成与能力确认分开表述，每项能力保留来源、范围与未知项。缺少教育或项目时明确暂无，不自动补造。
2. **综合推荐岗位与匹配依据**：结合项目、已确认能力、教育背景及本人工作偏好呈现岗位或候选方向，说明每项推荐的原因。性格/MBTI仅作本人偏好线索，不凭类型决定适合或不适合的职业。匹配显示可解释的要求覆盖、待补证据及资料不足；没有依据时不生成分数或百分比。
3. **岗位工作特点与能力要求**：呈现典型任务、协作方式、工作环境与岗位要求；每项要求对应已有依据、待补或未知，区分岗位信息与用户实际情况。岗位差异和来源可按需展开。
4. **待补项目与下一步实践**：将缺项与可实践项目对应，说明所补能力、交付与预计投入，并链接资源中心预览。没有可对应资源时明确暂无，不补造项目；仅预览不自动创建计划或任务。

左侧目录对应四章，主内容直接展示综合结果。报告上方不再重复展示材料和行动数量，移除材料状态及行动状态分布图。保存报告、导出和历史版本明确可达，但不抢占正文；查看页面不自动保存、提交或确认能力。

`project/AGENTS.md` 引用的 `设计参考与同步/设计参考与图片同步约定.md` 在当前仓库不存在。本轮继续依 `AGENTS.md` 的明确规则保存用户参考、先行设计、实现说明与实际截图，并区分三类材料，不另行索取例行同步确认。

## 实现与验收

新版页面按上述四章展示，左侧目录支持键盘定位和焦点提示。旧开屏数量摘要及材料/行动分布图已移除；保存、片段导出、历史版本和岗位简历入口保留。

- [ReportDecisionDesk.jsx](../../低保真原型/src/ReportDecisionDesk.jsx) 与 [career-report.css](../../低保真原型/src/career-report.css) 实现四章阅读、岗位对照、能力要求表及项目建议。
- [career-report-model.js](../../低保真原型/src/career-report-model.js) 统一汇总已确认教育/经历、能力自评、明确完成的项目、独立上传项目元数据、工作偏好和周期目标。明确完成但缺少说明的项目保留并提示补充；未提交草稿不冒充成果，不读取上传附件正文，不带入私人复盘或目标草稿。
- 新报告固定保存五章：四项主要内容及“引用与局限”。预览、正式服务保存和TXT导出共用模型；用户多行说明规范到单章内，避免拆出伪章节。旧报告、咨询摘要及岗位简历保持可用。
- 匹配程度为“技能依据覆盖”，分母为站内该方向的技能标签，要求表展示全部标签及学习层级；并列材料不强行排名，资料不足不生成最高推荐。MBTI仅用来核对工作方式，不能建立技术能力或录用概率。
- [career-report-sources.js](../../低保真原型/src/career-report-sources.js) 记录紧凑来源引用与变动签名；确认材料、教育、MBTI、自评、目标及成果变化会提示更新。教育撤回、上传删除或独立来源读取失败时，旧缓存正文与导出停止访问。正式预览与保存另用服务端SHA256摘要核对，防预览后来源变化。
- 目标计划中的周期记录按当前账号的本机保存范围载入；正式保存时只传有界目标摘要，剥离笔记、草稿和其他任务元数据。项目建议优先延续同方向已有任务；预览补充项目不自动创建任务、改变目标或预算。

### 验证结果

86项相关模型、来源撤回保护、报告编排、旧报告/简历、操作引导及HTTP预览保存测试通过；[页面检查结果](页面检查结果.json) 7组桌面检查通过，浏览器运行时异常0。覆盖四章顺序与键盘导航、真实项目及背景、技能对应与MBTI边界、只读补项目预览、上传元数据进入报告、保存刷新、导出与保存正文一致、来源删除后停止读取、资料不足、1440/1920长文本和英文页面。

`npm run build`、`npm run build:server`及8416条双语检查通过（exactMissing=0），保留既有构建分块体积和静态/动态导入提示。来源快照以100个最大合法上传元数据进行容量检查并小于80KiB，长文字尾部改变仍会提示过期；Node与真实浏览器Unicode快照一致性验证通过。

本轮未重复运行全量测试。单独尝试既有课程闭环API测试时，其课程包导入前置仍返回 `COURSE_FILE_HASH_MISMATCH`；新综合报告HTTP测试不依赖该课程包或未初始化知识库，已完整通过。没有修改课程包指纹、外部AI价格配置或绕过其校验。仅覆盖当前电脑网页版，未新增手机版工作。
