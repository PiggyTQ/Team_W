# 统一目标编辑二级页面

状态：实现完成，实际页面与全部专项回归已核对。先行线框不是用户确认稿。

本轮用户要求新增“目标编辑”二级页面：“目标与行动计划”的“编辑目标并预览”、我的目标大图标，以及周、月、年目标查看页的“去制定”均跳转至此，页面支持增删三个周期的目标。没有用户参考图片。

[先行线框](设计图/目标编辑.svg) 将全部入口统一到 `/plan/goals`，周期入口附带 `period`。采用周、月、年页签，当前周期目标清单与新增 / 编辑表单并列。删除在原目标卡片中确认，关联计划保持，解除被删目标的关联。原查看页保持只读，职业方向调整作为低频入口按需展开。

沿用现有工作台样式和本机周期记录，范围为桌面网页。`ui-ux-pro-max` 的两次设计系统匹配偏展示网站，未作为本页布局或配色依据；本页采用既有设计与一般界面规则，并使用检索中适用的删除确认和简短成功反馈建议。项目引用的 `设计参考与图片同步约定.md` 仍不存在，按 `project/AGENTS.md` 保存先行设计、实现说明和实际截图。

## 实现与实际页面

- [修改前目标入口](实际截图/修改前-目标入口.png) 与 [统一入口](实际截图/统一入口.png)：原“编辑目标并预览”改为原生导航链接，目标大图标也作为可点击、可键盘激活的链接；原尺寸与悬停效果沿用。三个查看页的“去制定”带入对应周期，五个入口统一进入二级页面。
- [1440px 周目标](实际截图/1440-week-目标编辑.png)、[月目标](实际截图/1440-month-目标编辑.png)、[年目标](实际截图/1440-year-目标编辑.png)：页头为“目标编辑”，保留父页面面包屑、返回链接和侧栏“目标计划”的选中状态。周 / 月 / 年页签显示当前自然周期的实际目标数量，左侧清单提供新增、编辑和删除，右侧表单保存目标名称、优先级、截止日期、进度、说明和年度里程碑。
- [周目标删除确认](实际截图/week-删除确认.png)、[月目标删除确认](实际截图/month-删除确认.png)、[年目标删除确认](实际截图/year-删除确认.png)：删除在当前卡片内确认；取消不会修改记录并将焦点还给原删除按钮。确认删除只移除指定目标及其关联标识，原任务、排期、行动内容、复查记录保持。
- [1024px 年目标](实际截图/1024-year-目标编辑.png)、[1920px 年目标](实际截图/1920-year-目标编辑.png)、[英文 1024px](实际截图/en-1024-目标编辑.png)：较窄电脑窗口上下排列，宽窗口双栏；检查输入和按钮的横向边界、日期字段与文本换行，没有新增手机版适配。

保存后留在目标编辑页，可连续新增或继续管理目标；“查看目标 →”返回对应周期的只读查看页，返回总览时数量同步。查看页继续隐藏新增、编辑和删除功能。各周期草稿独立保留，切换与刷新可以继续填写；取消编辑清除当前周期草稿。删除正在编辑的目标会同时清除该目标草稿，其他草稿及记录保持。

周期目标与原查看页共用本机记录和账户范围，两个页面之间导航时保留同一存储实例。不可写或原记录损坏时，临时改动在当前页面会话的编辑 / 查看往返中保留，并显示原有存储异常提示，不覆盖原始损坏记录。旧 `/plan?goalForm=...` 地址自动兼容到新页面。职业方向调整收进“职业方向与预览”，沿用原预览弹窗及明确确认流程。
