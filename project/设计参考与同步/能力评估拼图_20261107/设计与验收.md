# 能力评估拼图

最新视觉以 [轻拟物软陶升级](../能力拼图软陶_20261107/设计与验收.md) 为准；位置沿用 [左右布局调整](左右布局调整.md)：能力说明在左，拼图在右。下文保留初版布局记录。

2026-11-07。用户要求能力评估采用拼图样式：已掌握为黄色，未掌握为蓝色。沿用当前桌面蓝黄配色，完成回复不附截图。

本轮无新增用户参考图。[实施前局部设计](设计图/能力拼图.svg) 展示相互咬合的拼图与右侧能力说明；其中黄色仅为设计状态示例，不代表用户已掌握能力。

能力条目复用当前职业的既有基础、核心、进阶技能目录，每项技能为一块拼图。颜色和文字共同显示掌握状态，点击或键盘选择后在右侧记录本人自评。未标记的能力先以蓝色展示，只有主动标记才保存；不根据材料数量、技能标签或旧快照自动推断掌握。

自评放入偏好中的独立技能状态，使用技能原名称作为稳定标识，同名技能在职业切换后共享自评。职业范围、材料缺口、职业要求、模拟评估和历史快照入口保留，材料缺口改为按需展开。当前状态：实现完成，电脑网页版运行核对通过。
