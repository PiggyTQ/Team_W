# 左侧导航切页：模块依次浮现

日期：2026-11-19。依据用户文字要求：点击左侧不同导航按钮后，右侧页面的模块逐个浮现、堆砌成现有页面。没有新增用户参考图片。

本文保留初版记录。目标计划和地图的最终入场分组、加载等待，以及滚轮边界处理，以后续 [动画与滚轮修复](动画与滚轮修复.md) 为准。

## 实施前动效方案

已先保存 [模块浮现分镜](设计图/模块浮现分镜.svg)。此图为本轮动效意图示意，不是用户确认稿或实际页面截图。保留各页现有颜色、信息层级、模块位置和大小。

- 左侧导航和顶栏保持稳定；仅对目标页的标题、页签和独立内容模块应用入场动画。
- 模块从下方约 28px 的位置逐渐显现、归位，按页面阅读顺序错峰进入。每个模块约 520ms，间隔最多 72ms；一批模块的最后启动时间不超过 540ms。
- 模块始终占据最终布局位置，只改变透明度和视觉位移，不用逐个挂载、改变高度或重新初始化页面来实现“堆砌”。
- 点击当前导航不重复播放。快速点击其他导航、页面交互、滚动、窗口变化或减少动态效果偏好变化时，及时结束并清理当前动画。
- 首次直接打开页面不播放；页面内部原有芝士转场和幕布动画继续保留。异步加载的技能地图也参与本次导航的模块入场。
- 开启系统“减少动态效果”时，目标页直接完整显示。动画不锁定导航、表单或键盘焦点。

## 实施与验收

状态：实现完成，实际页面分镜与窗口截图已保存并目视核对。与现有页面布局一致，浮现中仅透明度与视觉位置发生变化。

实现集中在 [useWorkspacePageReveal.js](../../低保真原型/src/useWorkspacePageReveal.js)。左侧导航的普通点击与键盘激活标记目标路由，路由提交后在布局阶段启动动画；主区、侧栏与顶栏均不重新挂载。重复点击当前导航、首次直达和页内普通切换不启动本效果。按模块的屏幕阅读顺序错峰进入，最多约 1.06 秒完成一批内容。

动画完成或中断后取消 WAAPI 动画、移除事件监听并恢复模块原有样式，不遗留隐藏类。模块可立即操作；滚轮、触摸滑动、主区点击和键盘焦点进入页面都会结束入场。异步加载只在当前导航事务内短暂观察实际内容提交，不为之后的编辑反复播放。现有警告与加载状态直接显示，关闭的弹窗和隐藏模块不参加入场。

- 新增动效浏览器检查 15 项通过，运行时错误 0。覆盖全部九个学生导航入口、快速中断、浏览器返回、当前导航重选、键盘、滚动、窗口变化、减少动态效果，以及技能地图延迟 650ms 加载。
- 1440 分镜核对通过；1024、1920 两种桌面宽度的展开／收起侧栏，以及 390 手机宽度均无整页横向溢出。
- 实际模块在入场起点和终点的布局位置与尺寸相同。切页前后的材料、材料草稿、任务、报告、简历、复盘、教育、决策、预算、方向和阅读记录保持一致。
- 路由恢复测试 8 项通过；既有芝士匀速连续转场、模块幕布与排期入口、计划制定／执行切换 3 项浏览器回归通过。
- `npm run build` 通过，双语检查 `siteStrings=8418`、`exactMissing=0`。构建仍提示现有 JSON 导入属性不一致、静态／动态混合导入与较大分块；本轮没有改动这些来源。
- 本轮未运行全量后端测试或部署。汇总见 [页面检查结果](页面检查结果.json)。
