# 芝士匀速连续转场

日期：2026-11-08。适用阶段：电脑网页。依据用户最新文字反馈绘制，没有新增用户参考图片。

先行设计：[匀速连续芝士转场分镜](设计图/匀速连续芝士转场.svg)，已在本轮源实现前保存。该图为动画意图分镜，不是实际截图或用户已确认稿。

## 连续运动

全过程 480ms，使用单条 `linear` 平移时间轴，从内容区左上连续掠向右下。卷入和退出不分段，不在中途停顿、保持不透明帧或重新启动，不设置缓入缓出。旧页在时间轴达到中点 240ms、芝士完全覆盖内容时切换，新页随同一时间轴继续向前揭露；切页不改变图层的位置与速度。

四层采用深金最大、奶油最小的嵌套宽度，整组一起移动，速度一致。进入与退出时的四色边缘由嵌套轮廓自然形成，不通过逐层错峰或反向层序重新安排运动。保留圆润、不等长的融化波瓣、柔和边唇、稀疏细孔和更饱满的四层黄色；内层的轻微变形也沿连续线性时间轴推进。

四层实际色值保持 `#dda43a`、`#f1bf53`、`#ffdb7c`、`#ffedb3`。位移只施加在共同平面；内部仅做纵向线性变形，以免干扰斜向平移速度。平面中心使用固定像素定位，目标页重新裁切时仍保持同一视口位置，避免中点出现偏移。

## 适用范围

继续只覆盖右侧可见内容区；侧栏展开、收起和顶部导航均按实际边界裁切。仅前后路径都属于 `/plan`、`/plan/goals`、`/plan/schedule`，且实际整页内容变化时播放，包括目标编辑、排期、返回和计划制定、执行、复盘模式。

与学习、职业、工作区等其他分类之间，无论点击还是浏览器前进后退，均立即导航。周期页签、排期选中、筛选、同页定位及弹窗不触发波浪；模块内幕布保持。首次直达、刷新、减少动态效果、历史中断、窗口变化、侧栏布局与焦点恢复延续原处理。

## 实施与验收

源实现已完成，实际 25%、50%、75% 阶段截图已目视核对：四层同速前进，50% 时内容被完全覆盖，顶部与左侧导航持续可见。

- 浏览器 21 / 21 项通过，运行时错误 0，见 [页面检查结果](页面检查结果.json)。
- 连续性检查确认：480ms 单条 `linear` 位移动画在中点前后保持等增量；120 → 240 → 360ms 两段等时位移的差仅约 0.004px。始终是同一动画对象，没有保持阶段、暂停或重启；四层边界在切页时均覆盖内容。
- 分类内部模式和二级页仍播放；跨学习、职业与工作区的两向导航及浏览器历史立即切换。键盘重复激活、历史中断、侧栏布局、窗口变化、焦点和减少动态效果通过。
- 1024 / 1440 / 1920 电脑窗口下，侧栏展开与收起的六组内容区裁切检查通过，顶部与左侧导航无遮挡。
- `npm run build` 通过，仍有已有分块与导入方式提示。
- 双语检查 8136 条，`exactMissing=0`；相关目标模型与路由测试 19 项通过。

本轮未运行全量仓库测试。实际截图独立归档，不覆盖历史证据。
