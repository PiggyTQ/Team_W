# 计划排期独立页面

状态：实现、实际页面视觉核对与本轮专项验收已完成。先行设计图不是用户确认稿。

## 需求与设计来源

本轮根据文字需求将“待排期”从原模块内小页移到独立的 `/plan/schedule`“计划排期”页面。“我的计划”的去排期入口，以及周 / 月 / 年每个目标的去排期入口统一进入，目标入口自动选中对应目标。没有新增用户参考图片，沿用 [上轮实际待排期截图](../目标推荐与新增弹窗_20261108/实际截图/新建与推荐目标-待排期.png) 与现有蓝白米色样式。

[先行局部设计](设计图/计划排期独立页面.svg) 仅描述本轮桌面页面：左侧计划清单，右侧所选计划及日期安排。条目名称和日期为结构占位，不构成真实记录。`project/AGENTS.md` 所引用的 `设计参考与图片同步约定.md` 在仓库不存在，继续依现有明确约定保存设计、实现说明与后续实际截图。

## 页面与交互

- 页头显示“计划排期”、父级面包屑及返回目标与行动计划入口。
- 左侧提供可搜索的计划清单与“待排期 / 已排期”切换。目标标明周期，行动标明类型，选中行使用既有浅蓝选中态。无项目及无搜索结果有各自空状态。
- 右侧显示当前所选目标或行动的详情、执行日期、可选时间和“确认排期”，另提供“重置输入”。目标截止日期单独显示，不自动作为执行日期。没有选择时不展示无对象的可提交表单。
- 从周 / 月 / 年目标的去排期入口进入时自动定位目标；已排期目标进入可调整状态。
- 保存后给出明确反馈，并提供查看待行动 / 日历入口；更新所选项状态与清单。保留已有保存失败、排期校验和任务业务规则，不推定耗时或完成情况。
- 页面只在用户执行保存时写入安排；切换清单、搜索与直接访问不自动创建排期。

本轮以独立页面取代原内嵌待排期小页，目标制定页和查看页的其他职责沿用。范围为当前电脑网页，不新增手机版验收。
