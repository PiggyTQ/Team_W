# 蓝黄双面 3D 翻转卡片

2026-11-07。用户要求六个矩形改为独立双面卡片，左侧数量由 `...个` 改为 `0个`；默认蓝色统计正面，鼠标悬停时绕自身竖直中心轴水平翻转 180°，显示黄色操作背面，移出反向恢复。保留原模块标题、图标、底部按钮及排列尺寸。

同日后续用户否定立体与翻转，改为扁平纯色和黄色小波浪覆盖。本篇保留为历史阶段记录，当前样式和测试入口见 [扁平波浪覆盖](../扁平波浪覆盖/设计与验收.md)。

- [修改前实际页面](实际截图/修改前.png) 与 [修改前尺寸](修改前尺寸.json) 由实施前的实际运行页面保存。本轮无新增截图附件。
- [实施前翻转分镜](设计图/蓝黄翻转分镜.svg)：固定的 280px 最大宽度、48px 高度；内层 `preserve-3d` 与外层 900px 透视，绕 Y 轴旋转，600ms 缓入缓出，背面预旋转 180°并隐藏背向面。两面统一 6px 圆角、细边框与轻阴影，悬停仅上浮 2px。

正反面对应：周 / 月 / 年目标 → 查看周 / 月 / 年目标；待行动 → 去行动，待排期 → 去排期，待复查 → 去审查。计划数量沿用原实际任务统计。每张卡片使用一个原生按钮或链接，前后两面只作视觉呈现，辅助技术读取包含名称、数量和操作的单一可访问名称。键盘聚焦可查看背面；点击无需等待翻转完成。减少动态效果时直接显示操作背面，不执行空间旋转。

现有代码仅有周期目标标签，没有独立周/月/年列表、条目或数据模型。按用户要求复用现有 `DetailDrawer`，点击对应卡片打开该周期的只读空列表并显示 0 个；不把职业方向编辑冒充为周期查看，不新增编辑、保存或虚构目标内容。计划三项复用现有执行路由和未排期 / 复查锚点。

状态：实现完成，已核对电脑网页版实际页面。六卡默认浅蓝渐变统计面，目标数量显示 0 个；背面为奶油黄渐变操作面。固定外层命中框内执行 600ms 的 Y 轴旋转与 2px 上浮，并增加一条只在侧向可见的 1px 竖边，使 90° 时仍呈现细标识牌边缘。
