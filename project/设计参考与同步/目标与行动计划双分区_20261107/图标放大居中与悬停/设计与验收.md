# 图标放大、右侧居中与悬停

2026-11-07。用户指出图标过小，要求两个图标位于各自区域右侧、纵向居中，并在鼠标悬停时产生动效。本轮覆盖前版 40px 标题行图标布局。

- [修改前实际页面](实际截图/修改前.png)：原 40px 图标位于标题行右端。
- [实施前局部设计](设计图/大图标居中与悬停.svg)：电脑宽窗口图标 128px，分别位于目标和计划内容的右侧独立图标栏，纵向中心与各自区域一致；文字仍从两栏共同顶部开始。较窄桌面使用 104px，小窗口使用 80px，避免挤压内容。

悬停采用 380ms 的上浮 6px、放大到 1.08 倍及靶心向左/日历向右倾转 7 度，移出平滑复原。动画只作用于固定命中区域内的 SVG，内容、统计与分隔线不发生位移。图标继续作为装饰，不增加点击行为或键盘焦点。遵循减少动态效果偏好。

状态：实现完成，已核对实际页面。两个图标均已移出标题行，在各自内容区域右侧独立图标栏内纵向居中；左右标题仍从共同顶部开始。宽桌面为 128px，1024px 桌面为 104px，小窗口为 80px。
