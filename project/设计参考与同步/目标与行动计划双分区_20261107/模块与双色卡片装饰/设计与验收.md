## 实施前局部设计

- [背景与双色状态示意](设计图/模块与双色纹样.svg)：模块右侧图标周围以浅蓝圆面、细圆弧、虚线与少量暖黄几何点缀丰富留白；文字区域留白。六卡两态共用细线圆弧、角部色块、点阵与斜短线，蓝态使用低对比蓝纹，黄态使用奶油色与暖金纹。底部灰色按钮增加轻量角部圆线。
- [修改前实际页面](实际截图/修改前.png)与[修改前坐标](修改前尺寸.json)：1440px 电脑窗口，独立检查场景。
- 图案使用本地 SVG 或 CSS 几何形状，无渐变、投影、3D 或循环动画。模块背景独立置于内容下；卡片两态纹样在文字下，黄态随原波浪遮罩显现，动作文字保持原位。
- 图案不承载含义，隐藏于辅助技术且不接收指针；继续复用六个原生按钮/链接，不增加焦点与状态。按当前项目阶段核对电脑页面。
