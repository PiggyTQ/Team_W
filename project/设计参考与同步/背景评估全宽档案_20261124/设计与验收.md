# 背景评估全宽档案

## 用户参考与设计

用户提供的截图记录了原有双栏布局。按本轮需求，背景评估移除左侧“核对经历与个人贡献”面板及右上方的材料展开按钮。个人经历档案占满标题和说明下方的内容宽度，沿用暖白细边框、黄色档案袋、灰色新增入口、深蓝书托和右侧文具线稿。[用户参考](用户参考/原背景评估.png) · [实施前局部设计](设计图/背景评估-个人经历档案.svg)

## 交互与验收

- 有个人记录时，在档案标题行按经历状态筛选。打开对应档案即可查看原文与本人贡献，并按记录状态确认、拒绝、编辑或撤回。
- 没有个人记录时显示演示档案。灰色档案袋提供手填和导入入口，保存后生成待确认的个人档案。确认回执在档案下方提供查看和返回入口。
- 桌面浏览器验收通过。检查了档案全宽、状态筛选、手填和导入、候选确认与回执、操作引导、键盘焦点及原背景评估锚点。
- 隔离的服务端测试使用合成记录验证了档案确认、撤回及刷新后的状态。

本地演示模式，1440 像素宽的桌面视窗。[个人经历档案](实际截图/背景评估-个人经历档案.png) · [演示档案](实际截图/背景评估-演示档案.png)
