# 周、月、年目标查看与制定分离

状态：实现完成，局部实际页面已核对；先行线框不是用户确认稿。

用户文字要求：“查看周目标 / 查看月目标 / 查看年目标”进入的页面不显示新增目标功能，只显示当前指定目标；没有目标时显示“您当前没有指定目标”，并附“去制定”跳转链接。本轮没有用户参考图片。

[局部先行线框](设计图/目标查看与空状态.svg) 区分当前周期的目标清单、空状态与独立制定界面。查看页仅展示已保存目标及其说明、进度和里程碑状态，草稿不作为已制定目标；空状态不展示空进度或编辑表单。去制定链接进入对应周期的制定路由，保存与返回后进入对应周期查看页。

沿用当前桌面页面的实际样式、周期过滤和本机记录结构，保留模块外的日程与计划流程。原 `project/AGENTS.md` 引用的 `设计参考与图片同步约定.md` 未找到，依照现有协作约定保存先行设计及实际页面证据。

## 实现与实际页面

- [修改前](实际截图/修改前-周目标空状态.png) 与 [周目标空状态](实际截图/week-空状态.png)、[月目标空状态](实际截图/month-空状态.png)、[年目标空状态](实际截图/year-空状态.png)：移除新增按钮和表单。空状态仅显示目标图标、“您当前没有指定目标”及“去制定 →”，不显示空统计侧栏。
- [周目标清单](实际截图/1440-week-已制定.png)、[月目标清单](实际截图/1440-month-已制定.png)、[年目标清单](实际截图/1440-year-已制定.png)：只展示当前自然周期的已保存目标；保留优先级、截止日期、进度与展开查看说明。移除编辑、标记完成和可修改的里程碑勾选框，里程碑改为文字状态。
- [独立制定界面](实际截图/year-独立制定.png)：空状态的原生链接进入 `/plan?goalForm=week|month|year`；支持键盘激活、单独打开及刷新。保存后转到 `/plan?goalView=week|month|year`，返回总览后数量同步更新。制定界面沿用原紧凑表单及周期内日期校验，保存记录的结构没有改变。
- [1024px 查看](实际截图/1024-year-已制定.png)、[1920px 查看](实际截图/1920-year-已制定.png)、[英文制定](实际截图/en-1024-year-独立制定.png)：核对电脑窗口下的显示、内部滚动和横向溢出。未开展手机版适配。

未提交草稿仅在独立制定界面恢复，不作为已指定目标展示。返回目标保留草稿，取消编辑清除对应草稿。存储不可写或原记录损坏时，临时目标可在当前页面查看，并显示原有存储状态提示；不覆盖损坏的原记录。截图和检查数据均使用独立浏览器上下文中的合成记录。
