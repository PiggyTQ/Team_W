# 资源中心与我的资源

日期：2026-11-08。适用范围：当前电脑网页的学习与实践中心。本轮状态：界面与上传存储已实现，完成针对性测试、双模式构建和桌面实际页面核对；全量测试另有现有环境及数据前置失败，详见下文。

## 用户要求与参考

用户要求将右上方切换按钮分为“资源中心”和“我的资源”：资源中心提供网站内可实践的项目；我的资源收录用户完成平台实践后的项目，以及用户自行完成并上传的项目。适当删除无关和重复的功能。

[用户参考图：原学习与实践中心](用户参考/原学习与实践中心.png) 为用户提供的原页面截图，右上方仍为“路线与资源 / 短体验 / 综合项目”，左侧有“全部资源 / 我的学习 / 收藏”及探索范围、预计投入、成本与语言筛选。该图用于标记调整位置和原有视觉，并非本轮完成截图或新设计确认稿。

## 实施前设计

[资源中心与我的资源结构图](设计图/资源中心与我的资源.svg) 在 UI 实施前绘制，描述两个页面模式的桌面信息层级，条目名称仅作结构占位。此图为实施前方案，未经用户单独确认。

1. 右上方只保留“资源中心 / 我的资源”两项模式切换，名称与页面内容一致。
2. 资源中心以平台可实践项目为主：保留项目方向、预计投入等必要筛选；项目卡片展示名称、方向、投入、成果要求和开始实践入口，所需基础与详细说明按需查看。
3. 我的资源按“全部项目 / 平台实践 / 自主上传”区分来源，提供“上传项目”入口。平台项目仅在已有任务完成后收录；个人项目由用户上传已完成成果，保留项目说明和附件。
4. 仅阅读、收藏、恢复阅读位置及未完成任务不作为项目成果。进行中的实践仍在既有任务执行流程中继续，不伪造完成或能力确认。
5. 删除原“短体验 / 综合项目”重复模式，以及与新分区重叠的资料库集合入口；成本与语言没有实际区分时不单列无效筛选。不扩充排行榜、公开展示、协作分享和数据统计。
6. 无项目时显示真实空状态，提供去资源中心实践或上传项目的入口；筛选无结果时可清除条件，不自动补造样例成果。

保持当前页面暖白背景、深蓝文字、浅蓝辅助区域和黄色主行动按钮，不做全站视觉深化。只调整本次功能结构，不新增移动端适配。

`project/AGENTS.md` 引用的 `设计参考与同步/设计参考与图片同步约定.md` 在当前仓库中不存在。本轮继续依 `AGENTS.md` 的明确要求保存用户参考、先行结构图、实现说明和实际截图，区分三类材料。

## 实现与验收

### 最终实现

- 右上方调整为“资源中心 / 我的资源”，旧“路线与资源 / 短体验 / 综合项目”链接兼容到资源中心。资源中心保留平台实践项目、方向与预计投入筛选、阅读资料、实践范围与开始入口，移除重叠集合和无实际区分的成本语言筛选。
- 我的资源只收录 `completed === true` 且 `status === '完成'`、模板属于平台学习项目的任务，以及用户明确确认已完成后上传的项目。阅读、未完成任务和外部补录不会混入平台实践成果。
- 自主上传保留名称、方向、成果说明、本人贡献和真实成果文件；可下载、按来源筛选，并在确认后移除文件和项目。支持 PDF、ZIP、DOCX、TXT、MD、JSON、CSV、PNG、JPG/JPEG，单文件不超过 10 MB，每个账户最多 100 项、总文件容量 100 MB。
- 演示模式通过 IndexedDB 保存文件；正式账户模式通过 SQLite 保存当前账户的项目和文件，服务端检查会话、所有权、输入与配额。清除业务数据及注销账户时同步处理上传资源。
- 上传错误就地显示并保留已填写内容和所选文件；空状态以真实记录为准。没有新增移动端设计或验收。

界面与归集逻辑位于 [LearningCentre.jsx](../../低保真原型/src/LearningCentre.jsx)、[MyResources.jsx](../../低保真原型/src/MyResources.jsx)、[my-resources-model.js](../../低保真原型/src/my-resources-model.js) 和 [resource-centre.css](../../低保真原型/src/resource-centre.css)。上传与存储位于 [resource-project-client.js](../../低保真原型/src/resource-project-client.js)、[resource-project-model.js](../../低保真原型/src/resource-project-model.js)、[resource-project-store.mjs](../../低保真原型/server/resource-project-store.mjs) 及账户服务路由。
