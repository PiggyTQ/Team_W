## 实现与检查

档案由原 `claims` 生成；`BackgroundFolders` 保留侧向外观及抽出/收回动画。原经历记录渲染提取为共用函数，左侧队列和展开纸页读取同一条记录、调用同一组业务操作；没有新增接口或持久化字段。手填和导入按钮继续打开原功能组件，实践文字链接进入已有学习与实践页面。

已完成：

- 档案袋浏览器检查 8 组通过，页面脚本错误 0。覆盖空态、按钮/文字链接位置、手填草稿和保存、新经历生成档案、现有记录逐一对应、只读浏览不改变数据、单条确认同步状态、导入取消和去重、实践跳转、键盘/快速操作/焦点，以及 320/390px 中英文、长标题和多条记录。
- 原个人评估导航回归 6 组通过，背景评估区块顺序与 DOM 保持稳定，历史返回与刷新继续正常。
- 原经历填写、简历导入、评估总览与路由模型测试 28 项通过。
- `npm run build` 通过；双语检查 7831 项，缺失 0。保留项目已有分包体积和 LoginNookScene 混合导入提示。
