# 行动推进台：今日任务

状态：本地页面实现、实际截图、视觉核对与本轮专项验收已完成，未部署。先行线框、用户参考和实际页面截图分别保存；线框不是用户确认稿，验收截图中的任务均为合成测试记录，不代表用户真实数据。

## 本轮需求与设计来源

根据用户文字要求精简 `/plan?tab=执行` 的行动推进台：移除“列表 / 日程”切换与无关功能，主页面按优先级排列今日任务，展示预计用时、完成相关任务的预期能力收获，并提供跳转到“学习实践”对应部分的“去完成”。本轮维持当前电脑网页范围。

`project/AGENTS.md` 要求页面结构调整先保存设计图、实施后保存实际截图并核对；它引用的 `设计参考与同步/设计参考与图片同步约定.md` 在本轮仓库中不存在，继续依已有明确约定区分参考、线框与实图，不为例行同步另行请求确认。

## 页面与交互设计

- 保留“行动推进台”页头与“计划制定 / 计划执行”切换；主体为“今日任务”，显示当地日期、待完成任务数、合计预计用时。
- 以单列横向卡片按高 / 中 / 低 / 未排序的优先级排列任务。首任务突出显示，每项包括顺序号、已存优先级、任务名称、简短目的、预计用时、预期能力收获和“去完成”。长任务标题最多显示 3 行，目的最多显示 2 行，完整原文保留在 DOM / `title` 及学习实践的任务焦点区，避免窄桌面下单卡高度挤占整屏。
- 今日清单仅包括今天与之前已排期且尚未完成的任务；逾期项明确展示原计划日期与逾期状态。未来任务、未排期任务、已完成或暂停任务不混入今日待办；不擅自为未排期任务补今天的日期。
- 预计用时使用任务原有估计，不冒称实际耗时；无有效估计时显示“待确定”，摘要同时提示“部分任务用时待定”，不猜测分钟数或将缺失用时冒充已知合计。
- “预期能力收获”取自已关联的学习内容或任务目标，表达预计练习的技能与方法，不推定个人能力已经获得或核验。
- 每项“去完成”进入 `/learning?task=原任务标识&unit=关联模板#learning-task-原任务标识` 对应部分；有效课程模板才附加 `unit`。学习实践新增同一任务的独立焦点区，自动滚动并聚焦到所选任务，同课程多任务也按任务 ID 精确区分；没有有效课程关联时保留该外部行动的记录入口，不随意匹配其他课程。
- 跳转与返回为只读操作，不创建任务副本、标记完成或改变预算；开始 / 继续实践仍经过原有依赖、暂停恢复与完成保护。完成、暂停、受阻和失效任务直链都有对应处理，当前学习任务焦点移除了原来指向其他任务的底部流程栏。
- 页尾仅保留小号“调整任务安排”入口，使原有排期与任务管理仍可到达；移除预算栏、状态筛选、主从详情、添加表单、结果与复盘面板及重复底部流程导航。
- 没有今日任务时给出明确空状态并保留安排入口，不展示无对象的操作表单。
