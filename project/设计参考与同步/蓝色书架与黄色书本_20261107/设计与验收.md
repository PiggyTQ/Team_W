# 蓝色书架与黄色书本

后续背景与底托已按用户新要求修订，当前方案见 [书架背景与底托修订](../书架背景与底托修订_20261107/设计与验收.md)。本页保留上一版设计与截图。

2026-11-07。用户要求为个人经历档案添加蓝色书架背景，所有书本使用随机黄色，并从左侧开始排列。

本轮无新增用户参考图。[实施前局部设计](设计图/蓝色书架与黄色书本.svg) 是本次方案图；[修改前](实际截图/修改前.png) 是本地页面的实际截图。

方案：档案区使用浅蓝底，书架以蓝色背板、侧板和底托形成层次；书本保留原有白色横线标签、圆孔和尺寸，从左侧依次排放，多本仍可在书架内横向浏览。黄色深浅从同色系调色板按档案标识伪随机分配，同一本书在展开、切换视图或重新渲染时保持颜色。演示档案和本人档案采用同一规则。

当前状态：实现完成，实际页面已核对。当前范围为电脑网页版。

- [背景评估区域](实际截图/蓝色书架与黄色书本.png)：保留左侧核对区和右上角两个操作入口。
- [展开档案](实际截图/展开档案.png)：纸页沿用所选档案的黄色标记，展示原有经历内容。
- [多本档案](实际截图/桌面多本档案.png) 与 [滚动末尾](实际截图/桌面多本档案末尾.png)：1280px 桌面视口中的十本合成检查档案，在书架内横向浏览，保留侧板，滚动区域不被底托遮挡，末本可用键盘打开。
- [英文桌面书架](实际截图/英文桌面书架.png)：1440px 英文页面。

## 验证

[样式检查结果](样式检查结果.json) 记录三个桌面场景：1440px 中文、1280px 十本档案、1440px 英文。首本书距离书架舞台左侧 18px，三个场景均从左排列、无整页横向溢出，展开和收回后的配色不变。十本档案覆盖全部八种黄色，其状态文字与书脊背景的对比度最低为 4.73:1；底托层级低于滚动区域。

`tests/background-folders-browser.mjs` 最终桌面回归 5 组全部通过，页面脚本错误 0，见 [交互检查结果](交互检查结果.json)。覆盖四份演示、演示与本人档案切换、展开与收回、草稿保留、新增经历、单条确认、导入取消与去重、实践跳转、悬停、键盘、快速操作和焦点恢复；配色稳定与左右布局另由上述样式检查确认。

`npm run build` 通过，双语检查 7857 项、缺失 0。构建仅保留已有的分包体积及静态/动态混合导入提示。本轮没有执行远程发布。
