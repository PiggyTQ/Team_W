## 实施前方案

[局部布局设计图](设计图/档案袋布局.svg)。左侧约 1/3 为“核对经历与个人贡献”与处理队列，右侧约 2/3 为三个真正有前后纸层的档案袋。采用原位抽出纸页方案 B，保持暖白、深蓝、轻纸材质。

三个档案袋分别承载手填已有经历、原导入能力（演示模式仍明确模拟）、没有经历时的实践引导。纸页承载实际交互内容，保留原路由，关闭、返回与快速重入有逆向动画；草稿、确认、重复导入和取消规则继续沿用。

## 运行边界

不新增后端接口、数据模型、持久化字段或动画依赖。手填复用 ExperienceWriter，真实 PDF 复用 ResumeImport，演示导入复用原模拟操作渲染；实践跳转进入原学习资源范围预览。

- 手机：[390px 收纳](实际截图/手机侧向收纳.png)、[390px 手填](实际截图/手机手填纸页.png)、[390px 英文手填](实际截图/手机英文手填纸页.png)。为看清组件，截图时将其滚动到视口中央。

桌面左右两区保持约 1:2。档案陈列舞台由正面初版的 430px 缩为 238px；书脊为约 94×224px，露出右侧纸页厚度。背景评估整体约 503px 高，展开和收回不改变区块尺寸，手机改为上下排列。

悬停为 340ms 抬升与纸边露出，点击经 620ms 抽出纸页，收回为 400ms 逆向动画。纸页包含实际原组件，正文内部滚动。使用原生 Web Animations 和 CSS，没有新增动画依赖。

手填使用原本机草稿和保存规则；收回、切换档案保留输入。演示导入仍明确不解析真实文件，收回取消未完成作业，重开可重试，同名候选不会重复添加。真实 PDF 导入增加可见状态取消信号，复用原 AbortController 和序列校验，保留文字草稿。实践入口进入已有资源范围预览，不自动建立任务。

原处理队列筛选、材料确认/拒绝/撤回与辅助操作步骤继续可达。档案使用原生按钮、展开状态、关联标题与焦点样式；支持 Enter、Space、Escape 和收回后焦点恢复。非当前纸页隐藏，动画期间表单不可重复提交；减少动态效果设置使用即时过渡。路由变化取消待打开的档案，避免旧动作抢回页面。
