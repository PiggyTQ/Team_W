# 芝士波浪内容区优化

历史版本：本记录保存当时实现与验收证据。当前以 [融化芝士与分类内转场](../芝士融化波浪与分类内转场_20261108/设计与验收.md) 为准，旧 799ms 时长、材质及跨分类波浪不再适用；右侧内容区裁切继续沿用。

日期：2026-11-08。当前阶段：电脑网页。

## 需求与先行设计

本轮按用户最新反馈调整既有芝士转场：遮罩只卷过右侧页面内容，顶部与左侧导航保持可见；整体节奏加快；波浪改为更宽缓的流线与柔和奶油黄材质，减少密集重复波齿。

先行设计图：[芝士波浪内容区分镜](设计图/芝士波浪内容区.svg)，已在源代码实施前保存，并完成对应实现。该图仍归类为设计分镜，不作为实际截图或用户已确认稿。实际截图与浏览器检查结果已补齐。

本记录曾覆盖 [上一轮整页转场](../芝士波浪整页转场_20261108/设计与验收.md) 中整视口遮罩及约 1.20 秒节奏的规定；现与上一轮一并保留为实施历史。

## 覆盖区域

动画开始时测量当前可见 `#main` 矩形，将左右与上下边界约束在视口、侧栏右缘和顶部栏底缘内，并将独立遮罩裁切在该矩形范围。波浪从右侧内容区域的左上向右下卷过，顶部界面与左侧导航始终不被遮住。侧栏展开和收起均根据实际内容边界定位，不用固定侧栏宽度估算。新路由提交后再次测量目标页，以源、目标可见内容矩形交集重新裁切，避免新页引入侧栏或更高顶部栏时遮住外部框架。

导航开始前先结束侧栏尚未完成的布局动画，再测量内容边界，防止收起侧栏后立即点击时使用 260ms 侧栏动画中的临时位置。芝士转场期间暂停侧栏快捷键，以保持当前测量区域稳定。

源、目标页面依然在内容被完全遮住后切换，不提前露出目标内容。导航开始前结束侧栏的平移动画，避免快速收起后遮罩位置偏移；转场期间锁定侧栏快捷键。目标页出现后再次按其内容边界裁切，避免遮住新出现的导航。动画期间保持原导航锁定；浏览器历史中断、窗口调整、减少动态效果及焦点恢复沿用既有处理。原生对话框仍遵守既有顶层交互流程。

## 动画节奏与材质

总时长约 799ms，约为 0.80 秒：

| 阶段 | 单层时长与错峰 | 阶段总时长 |
| --- | --- | --- |
| 四层卷入 | 310ms，间隔 32ms | 406ms |
| 遮满并提交新页后保持不透明 | 不做淡化 | 32ms |
| 四层向右下退场 | 280ms，间隔 27ms | 361ms |

宽缓流线替代密集重复扇贝边，四层依次推进，运动方向保持从内容区左上到右下。实现采用四层颜色 `#e9bc55`、`#f3ce70`、`#f9df99`、`#ffedb8`。芝士孔仅在最上层使用六个小而稀疏的低对比哑光凹孔，移除原孔洞下缘高光，边缘线条也减细、减弱，使材质保持柔和。

移动仍使用原生 `transform` 动画，不逐帧改动布局尺寸，不增加第三方依赖。减少动态效果时立即导航，不执行大幅波浪运动。

## 保留的交互范围

计划总览、目标编辑、计划排期、计划执行和复盘等实际整页切换继续使用转场；进入学习实践及计划区域与其他整页之间的适用导航继续保留。首次直达或刷新不自动播放。

目标编辑周期页签、排期页条目选中、搜索和筛选、同页日历定位与锚点、表单保存及弹窗仍沿用原交互。`/plan` 默认、`tab=计划总览` 与 `tab=执行&view=calendar` 属于相同内容，互相定位不触发整页转场。周 / 月 / 年目标、待行动与待复查详情保留模块内原幕布。

## 实施与验收状态

已完成实现并目视核对：顶部与左侧导航始终可见，右侧内容中的波浪更宽缓，奶油黄层次与孔洞更柔和。原总时长约 1.20 秒，现为 799ms。

- 浏览器检查 18 / 18 通过，运行时错误 0，见 [页面检查结果](页面检查结果.json)。

- 四层动画声明时序为 406 + 32 + 361 = 799ms；遮满后才提交路由。
- 快速收起后立即跳转、动画期间侧栏快捷键、浏览器历史中断、窗口调整、目标标题焦点与减少动态效果均通过。
