# 六个详情右侧紧凑布局

状态：实现完成，已核对实际页面；设计图先于实现制作，不是用户确认稿。

[用户参考](用户参考/新增表单需要滚动.png)指出目标编辑表单纵向过长、保存按钮离开可见区。[修改前页面](实际截图/修改前-新增周目标.png)与[布局坐标](修改前布局.json)保留为对照。

[先行局部设计](设计图/清单与同屏编辑.svg)：右侧采用清单 / 编辑两种状态。清单使用紧凑卡片和横向操作；进入编辑后，表单占用整个右侧，不在清单中继续向下堆叠。操作栏独立于字段滚动区，保存、取消、排期、复查和任务流程按钮始终可见。目标四个基础字段横排，说明与年度里程碑并排；排期按日期、时间和耗时横排，行动记录、贡献与目标关联并排，复查三项内容并排。

外部模块、舞台幕布、左侧统计、详情页头、现有数据、保存条件与草稿保留逻辑延续。较长文字在字段内部滚动，异常提示和较窄电脑窗口允许字段区独立滚动，操作栏保持可见。原任务说明按需展开，避免占用常用输入空间。本轮优化已有新增与编辑入口，不改变计划创建的预算预检流程。

## 实际页面与实现

- [周目标新增](实际截图/1440-week-新增.png)、[月目标新增](实际截图/1440-month-新增.png)、[年度目标新增](实际截图/1440-year-新增.png)：名称、优先级、截止日期与进度在同一行；说明与年度里程碑并排。保存与取消固定在编辑区上栏，填写常用字段不需要滚动表单。
- [待排期编辑](实际截图/1440-undated-编辑.png)：标题、日期、时间和预计耗时横排；行动目的、补充交付说明与周期目标关联分组排在下一行。确认排期和返回清单始终可见。
- [待行动记录](实际截图/1440-actions-记录.png)：产物、贡献与目标关联并排，提交、自检、完成和安排等按钮集中在底部独立操作栏。自检标签精简为“已核对原交付标准（本人自检）”，辅助技术仍读取原完整说明，确认逻辑保持。
- [待复查](实际截图/1440-review-复查.png)：结果、原因与下一步三栏排列，通过、重新调整和返回清单固定在上栏。原任务目的、交付标准、完成时间和流程说明可通过“任务说明”查看，支持 Escape 关闭。
- [1024px 年目标](实际截图/1024-year-新增.png)、[1024px 计划编辑](实际截图/1024-undated-编辑.png)、[英文 1024px](实际截图/en-1024-actions.png)、[900px 窄窗口](实际截图/zh-900-year.png)：原有窄窗口堆叠方式延续，常用控件可见，没有横向溢出。英文动作按钮允许折行并均分操作栏宽度。

右侧清单使用紧凑多列卡片，进度和行操作集中排列。进入编辑时由统一 `DetailEditor` 接管右侧可用高度，字段区与操作区分别布局；较长文本可在文本框内滚动，用户手动拉高文本框或出现错误时仅字段区调整，主要操作不会跟着滑出视口。成功反馈显示在编辑上栏，不额外占用一整行。

`useEditorListScroll` 在结束编辑后恢复清单滚动并将焦点交还原记录；总览往返仍保留未提交内容。六个内部视图、幕布、外部模块与保存逻辑保持。新增计划仍沿用现有预算预检入口，本轮没有新增未经过预检的创建流程。
