# 职业报告：自然滚动与灯泡技能卡片

日期：2026-11-19。用户要求：飞机章节导航随页面滚走；职业技能谱图的小卡片左侧为灯泡图片、右侧为文字；删除“指标口径”模块及底部“报告依据与匹配方式说明”。经用户明确补充，“指标口径”只指谱图中的小卡片，保留其他技能的详情区域。

## 用户参考与实施前方案

[用户截图](用户参考/导航遮挡谱图.png) 展示章节导航吸顶后遮住技能内容。本图是问题参考，不作为新设计稿。

已先保存 [局部设计示意](设计图/自然滚动与灯泡卡片.svg)。

- 飞机导航改为普通文档流中的相对定位，飞机仍固定朝向并水平滑动。取消吸顶和对应的占位补偿，随报告内容自然移出视口。
- 技能卡片保留原状态配色与点击操作，改为左侧简洁灯泡 SVG 图片、右侧技能名称，窄屏自然换行与重排。
- 仅从此谱图隐藏数据分析方向的 `metric-definition` 卡片。可见卡片计数随展示同步；职业技能目录、材料、检验记录和岗位匹配计算不改动。
- 删除当前报告底部的“报告依据与匹配方式说明”折叠区域。历史保存报告、其他就地来源和错误提示保持原功能。
- 保留“完善能力”、章节深链接、键盘与减少动态效果支持。滚动后通过内容中的链接切换章节时，将新章节带入可见位置。

状态：本地实现完成，实际页面与中英文窄屏画面已保存并目视核对。

## 实施与验证

三层报告导航样式均取消吸顶，导航和飞机以普通文档流布局一起滚动。移除旧吸顶补偿，改按视口位置检查章节标题；从正文中的入口切换章节时，新标题仍可见。

技能卡片使用 [灯泡 SVG](../../低保真原型/public/icons/roundline/lightbulb.svg)，左侧固定图片、右侧文字，并保留状态配色、选择状态和详情入口。数据分析谱图只移除“指标口径”卡片，当前样本显示 12 张卡片；图内计数按可见卡片计算。全量技能目录、材料关联、检验记录和岗位匹配算法保持原样。

底部说明折叠区已从页面结构移除，没有遗留空白占位。其他就地来源、服务错误提示与保存报告入口仍保持原功能。

- [浏览器检查结果](页面检查结果.json)：13 项通过，运行时错误 0。包含真实滚轮、导航完全离开视口、滚回顶部、灯泡图片加载和左图右文位置、技能选择、职业切换、四章节、深链接与键盘操作。
- 1440 桌面及 1024、390、320 中英文布局核对通过，未发生整页横向溢出；英文窄屏为长技能名称使用更宽的单列卡片。
- 操作引导测试 11 项通过。用户业务记录在界面操作前后相同。
- `npm run build` 通过，双语检查 8417 条，`exactMissing=0`。已有构建提示仍保留，本轮没有改动其来源。
