# 灰色新增文件夹

最新细节以 [尺寸与提示微调](尺寸与提示微调.md) 为准：悬停文字已取消，灰色与黄色主体尺寸统一。本页保留上一版设计与验证记录。

2026-11-07。用户要求将“手填已有经历”和“导入文件”收进一本浅灰色文件夹：位于黄色文件夹右侧并保持斜靠姿态，悬停提示“添加相关经历”，点击后虚化整个书架，显示两个入口，分别打开对应详情。

[用户参考](用户参考/斜靠文件夹.jpg) 借鉴书脊、纸标签、圆孔和斜靠姿态。新增入口采用浅灰色，并按用户补充放在黄色文件夹右侧，既有文件夹保持黄色。[实施前局部设计](设计图/灰色新增文件夹.svg) 展示悬停和选择方式两个状态；[修改前](实际截图/修改前.png) 是上一版实际页面截图。

黄色经历保持从左向右排列，灰色新增文件夹接在最后一本黄色文件夹右侧，一起在书架内横向浏览。新增方式使用书架内居中的选择面板，背景仅虚化当前书架，不新增蓝色背板。点击空白处、关闭按钮或 Esc 取消，焦点回到灰色文件夹。进入详情继续使用原手填、导入表单及其数据规则，关闭详情后也回到新增入口。

状态：实现与电脑网页版运行核对完成。按用户补充，完成后不向聊天附截图，截图仅用于内部核对与设计同步。
