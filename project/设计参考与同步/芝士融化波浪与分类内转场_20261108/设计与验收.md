# 芝士融化波浪与分类内转场

日期：2026-11-08。适用阶段：电脑网页。本轮依据用户文字反馈绘制，没有新增用户参考图片。

先行设计：[融化芝士转场分镜](设计图/融化芝士转场.svg)，已在本轮源实现前保存。该图属于动画设计分镜，不是实际截图或用户已确认稿。前两轮分镜和记录已标为历史版本。

## 材质与时序

波浪边缘使用不等长、圆润的融化波瓣，避免尖角或均匀齿边；四层黄色比上一轮更饱满，以柔和边唇、暗缘和少量细小低对比孔洞区分厚度。内层形体轻微变形，随向右下运动呈现融化与牵拉感。退场顺序反转为奶油层先退、深金层后退，使两侧过程均保留分层边缘。

实现四层色值依次为 `#dda43a`、`#f1bf53`、`#ffdb7c`、`#ffedb3`。边缘以连续曲线生成，双侧细奶油亮边与低对比金色暗缘构成柔和边唇；最上层保留六处细小孔洞。内层变形与图层位移分开使用 `transform`，不逐帧更改布局尺寸。

| 阶段 | 单层时长与错峰 | 总时长 |
| --- | --- | --- |
| 四层从左上向右下卷入 | 230ms，间隔 36ms | 338ms |
| 完全遮满后切页并保持不透明 | 不做淡化 | 16ms |
| 四层继续向右下退场 | 205ms，反向层序间隔 27ms | 286ms |
| 全过程 | 338 + 16 + 286 | 640ms |

只在所有卷入层完全遮住内容后提交路由。继续采用右侧可见 `#main` 的实际边界，顶部与左侧导航不被波浪覆盖；侧栏展开、收起及中途布局动画沿用现有处理。

## 分类边界

仅当导航前后路径都属于 `/plan`、`/plan/goals`、`/plan/schedule`，且实际整页内容变化时播放。包括目标编辑、排期、返回父页以及计划制定、计划执行、复盘之间的工作模式切换。浏览器前进与后退采用同一条件。

`/plan` 与 `/learning`、`/careers`、`/app` 等其他分类之间，无论前往还是返回均立即导航，不显示芝士波浪。首次直达、刷新、减少动态效果时立即展示页面。

同页周期页签、排期选中、搜索与筛选、日历日期及锚点定位、表单保存和弹窗不触发整页波浪。`/plan` 默认、`tab=计划总览`、`tab=执行&view=calendar` 都是同一总览内容，互相定位不触发；原模块内部详情继续使用幕布。历史中断、重复导航保护、窗口变化、减少动态偏好切换与焦点恢复沿用既有处理。

- 浏览器检查 21 / 21 通过，运行时错误 0，见 [页面检查结果](页面检查结果.json)。

- 分类内部工作模式和二级页切换播放；前往学习、职业和工作区，其他分类进入计划，以及跨分类浏览器历史均立即切换、无波浪且不加锁。
